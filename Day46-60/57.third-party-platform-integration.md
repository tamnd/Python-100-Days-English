## Integrating Third-Party Platforms

Some tasks in web projects are better handled by specialized third-party services. For example:

- real-name identity verification
- payment
- SMS delivery
- cloud storage

There are two common integration styles:

1. API integration: call a third-party URL and use the returned data.
2. SDK integration: install a library and use its classes and functions.

The lesson uses concrete examples for both styles.

### SMS Gateway Integration

SMS services are useful for:

- mobile verification codes
- important notifications
- marketing messages

The original lesson uses Luosimao as an example.

Example function for sending a verification code:

```python
def send_mobile_code(tel, code):
    """Send an SMS verification code."""
    resp = requests.post(
        url='http://sms-api.luosimao.com/v1/send.json',
        auth=('api', 'key-your-api-key'),
        data={
            'mobile': tel,
            'message': f'Your SMS verification code is {code}. Do not share it with anyone. [Python Mini Course]'
        },
        verify=False
    )
    return resp.json()
```

Supporting utilities:

```python
import random
import re

TEL_PATTERN = re.compile(r'1[3-9]\d{9}')


def check_tel(tel):
    return TEL_PATTERN.fullmatch(tel) is not None


def random_code(length=6):
    return ''.join(random.choices('0123456789', k=length))
```

View for sending mobile verification codes:

```python
@api_view(('GET', ))
def get_mobilecode(request, tel):
    if check_tel(tel):
        redis_cli = get_redis_connection()
        if redis_cli.exists(f'vote:block-mobile:{tel}'):
            data = {'code': 30001, 'message': 'Please do not request another SMS code within 60 seconds'}
        else:
            code = random_code()
            send_mobile_code(tel, code)
            redis_cli.set(f'vote:block-mobile:{tel}', 'x', ex=60)
            redis_cli.set(f'vote2:valid-mobile:{tel}', code, ex=600)
            data = {'code': 30000, 'message': 'The SMS code has been sent'}
    else:
        data = {'code': 30002, 'message': 'Please enter a valid mobile number'}
    return Response(data)
```

Redis is used here for:

- a 60-second resend block
- a 10-minute verification-code TTL

In other words, Redis is handling two small but very practical pieces of state here: rate limiting for repeated SMS sends and the limited validity window of the verification code itself.

### Cloud Storage Integration

Static assets, especially user-uploaded files, are often better stored in cloud storage instead of on local disks.

Benefits:

- lower operational cost
- easier scaling
- CDN acceleration

The original lesson uses Qiniu Cloud as an example.

Install the SDK:

```bash
pip install qiniu
```

Basic upload helpers:

```python
import qiniu

AUTH = qiniu.Auth('your-access-key', 'your-secret-key')
BUCKET_NAME = 'myvote'


def upload_file_to_qiniu(key, file_path):
    token = AUTH.upload_token(BUCKET_NAME, key)
    return qiniu.put_file(token, key, file_path)


def upload_stream_to_qiniu(key, stream, size):
    token = AUTH.upload_token(BUCKET_NAME, key)
    return qiniu.put_stream(token, key, stream, None, size)
```

Simple upload form:

```html
<form action="/upload/" method="post" enctype="multipart/form-data">
    <div>
        <input type="file" name="photo">
        <input type="submit" value="Upload">
    </div>
</form>
```

Upload view:

```python
from django.views.decorators.csrf import csrf_exempt


@csrf_exempt
def upload(request):
    photo = request.FILES.get('photo')
    _, ext = os.path.splitext(photo.name)
    filename = f'{uuid.uuid1().hex}{ext}'
    upload_stream_to_qiniu(filename, photo.file, photo.size)
    return redirect('/static/html/upload.html')
```

This example uses `csrf_exempt` so the form can be submitted without a CSRF token, and generates a unique file name with `uuid`. In the original lesson, there is also a note that smaller uploaded files are usually represented as in-memory upload objects while larger ones may be stored temporarily on disk first, which is why both stream upload and file-path upload helpers are prepared.
