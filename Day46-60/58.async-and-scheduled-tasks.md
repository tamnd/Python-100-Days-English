## Asynchronous Tasks and Scheduled Tasks

If a web request triggers a slow operation or an operation with unpredictable completion time, and the user only needs confirmation that the request was accepted, that work should usually be handled asynchronously.

If caching is the first major principle of web-performance optimization, then moving slow or uncertain work into asynchronous execution is the second.

Examples from the previous lesson:

- sending SMS messages
- uploading files to cloud storage

Both are good candidates for asynchronous processing.

In Python projects, a common tool for asynchronous tasks and scheduled tasks is Celery. The original lesson points readers to [Using Django for Commercial Projects](../Day91-100/95.django-for-commercial-projects.md) for the full discussion.
