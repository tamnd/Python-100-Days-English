## Frontend-Backend Separation

In traditional web development, many teams treated the browser as the dividing line between frontend and backend. The frontend displayed pages to users, while the backend handled business logic and data preparation.

With frontend-backend separation, frontend and backend engineers agree on data APIs and work in parallel:

- the backend provides data
- the frontend renders the page
- communication happens over HTTP

### Benefits

1. Higher development efficiency through parallel work.
2. Better maintainability because frontend and backend code are decoupled.
3. Easier support for multiple clients such as web, mobile, and service-based systems.

### Returning JSON Data

In a separated architecture, the backend usually returns JSON data. In Django, a simple example looks like this:

```python
def show_subjects(request):
    queryset = Subject.objects.all()
    subjects = []
    for subject in queryset:
        subjects.append({
            'no': subject.no,
            'name': subject.name,
            'intro': subject.intro,
            'isHot': subject.is_hot
        })
    return JsonResponse(subjects, safe=False)
```

Because the response is a list rather than a dictionary, `safe=False` is required.

### Using `bpmappers`

Writing manual object-to-dict conversion becomes tedious as models grow. The original lesson introduces `bpmappers` to simplify serialization:

```bash
pip install bpmappers
```

Example mapper:

```python
from bpmappers.djangomodel import ModelMapper

from poll2.models import Subject


class SubjectMapper(ModelMapper):
    class Meta:
        model = Subject
```

This can then be used in the view:

```python
def show_subjects(request):
    queryset = Subject.objects.all()
    subjects = [SubjectMapper(subject).as_dict() for subject in queryset]
    return JsonResponse(subjects, safe=False)
```

### Rendering with Vue.js

The lesson then rewrites `subjects.html` using Vue.js. The page fetches `/api/subjects/` and binds the returned JSON data into the DOM.

This is the main pattern:

- backend exposes JSON endpoints
- frontend uses `fetch` or Ajax to get data
- frontend framework such as Vue renders the UI

In production, the frontend pages are usually deployed as static assets on Nginx or Apache, while Python dynamic content runs on uWSGI or Gunicorn.
