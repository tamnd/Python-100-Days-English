## Static Assets and Ajax Requests

### Loading Static Assets

To use static resources in a Django project, create a directory for them. In the `vote` project, static files are stored under a `static` directory with subdirectories such as:

- `css`
- `js`
- `images`

Then update `settings.py`:

```python
STATICFILES_DIRS = [os.path.join(BASE_DIR, 'static'), ]
STATIC_URL = '/static/'
```

During development, this allows Django to find and serve static files. In production, static files are usually handled by a dedicated web server such as Nginx or Apache, not by the Python application server.

### What Ajax Is

To implement "upvote" and "downvote" for teachers, it is better to avoid refreshing the entire page after every click. Ajax lets the browser request data asynchronously and update part of the page without reloading everything.

Traditional web requests replace the whole page. Ajax requests fetch only the necessary data, and JavaScript updates the DOM in place.

![](res/synchronous-web-request.png)

![](res/asynchronous-web-request.png)

Data exchanged between browser and server is typically XML or JSON. JSON is now far more common because it is more compact and easier to work with in JavaScript.

XML example:

```XML
<?xml version="1.0" encoding="utf-8"?>
<message>
	<from>Alice</from>
    <to>Bob</to>
    <content>Dinner is on me!</content>
</message>
```

JSON example:

```JSON
{
    "from": "Alice",
    "to": "Bob",
    "content": "Dinner is on me!"
}
```

### Implement Voting with Ajax

Update `urls.py`:

```python
from django.contrib import admin
from django.urls import path

from polls import views

urlpatterns = [
    path('', views.show_subjects),
    path('teachers/', views.show_teachers),
    path('praise/', views.praise_or_criticize),
    path('criticize/', views.praise_or_criticize),
    path('admin/', admin.site.urls),
]
```

Create the voting view:

```python
def praise_or_criticize(request):
    """Handle upvote/downvote."""
    try:
        tno = int(request.GET.get('tno'))
        teacher = Teacher.objects.get(no=tno)
        if request.path.startswith('/praise'):
            teacher.good_count += 1
            count = teacher.good_count
        else:
            teacher.bad_count += 1
            count = teacher.bad_count
        teacher.save()
        data = {'code': 20000, 'mesg': 'Operation succeeded', 'count': count}
    except (ValueError, Teacher.DoesNotExist):
        data = {'code': 20001, 'mesg': 'Operation failed'}
    return JsonResponse(data)
```

Then update the template that displays teacher information. Import the jQuery library and use it to handle click events, send Ajax requests, and update the DOM.

```html

            clear: both;

<body>
    <div id="container">
        <h1>Teacher information for {{ subject.name }}</h1>

            <div class="photo">
                <img src="/static/images/{{ teacher.photo }}" height="140" alt="">
            </div>
            <div class="info">

                    <span><strong>Name: {{ teacher.name }}</strong></span>

                    <a href="/criticize/?tno={{ teacher.no }}">Downvote</a>&nbsp;&nbsp;

                </div>
            </div>
        </div>

        $(() => {
            $('.comment>a').on('click', (evt) => {
                evt.preventDefault()
                let url = $(evt.target).attr('href')
                $.getJSON(url, (json) => {
                    if (json.code == 20000) {
                        $(evt.target).next().text(json.count)
                    } else {
                        alert(json.mesg)
                    }
                })
            })
        })
    </script>
</body>
</html>
```

The frontend code above uses jQuery's `getJSON` method to send an asynchronous request to the server. If you are not familiar with jQuery, you can refer to its API documentation for more details.
