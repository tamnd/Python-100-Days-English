## Getting Started with Django

In the early days of web development, developers often had to hand-write every page. For a small site that might be acceptable, but once a site grows, manually editing HTML becomes an obvious problem. The solution was to let programs generate dynamic content for web servers instead of maintaining every page by hand.

The earliest mainstream solution was CGI. Later, more practical web development technologies such as PHP, ASP, and JSP appeared. Modern web applications are still built around the same core idea: the browser requests resources, and the server prepares and returns content.

### Web Application Basics

Common web terms:

| Term | Meaning |
| --- | --- |
| URL / URI | The unique address or identifier of a network resource |
| Domain name | A human-readable name mapped to a server address |
| DNS | Resolves a domain name to an IP address |
| IP address | The network identity of a host |
| HTTP | The application-layer protocol used for web communication |
| Reverse proxy | A server that forwards requests to backend services |
| Web server | A server that accepts HTTP requests and returns resources |
| Nginx | A high-performance web server that can also act as a reverse proxy, load balancer, and cache |

### HTTP

HTTP is an application-layer protocol built on top of TCP. It was originally designed for publishing and retrieving HTML pages, but it has become the general transport mechanism for web applications.

An HTTP request typically contains:

- request line
- headers
- blank line
- optional body

An HTTP response typically contains:

- status line
- headers
- blank line
- body

You can observe these structures using browser developer tools or packet-capture tools such as Wireshark.

### Django Overview

Python has many web frameworks, including Django, Flask, Tornado, Sanic, Pyramid, Bottle, Web2py, and others. A web framework is essentially infrastructure for building server-side web applications.

Django is one of the best-known full-featured frameworks in Python. It helps developers build reliable web applications quickly by reducing repetitive work and by packaging many common design and development patterns.

Django follows the MTV pattern:

- `M`: Model, representing data
- `T`: Template, responsible for presentation
- `V`: View, the logic that connects templates and models

This corresponds closely to the more general MVC pattern.

Django was born in 2003 inside a real content-management system used by a newspaper company. It was open-sourced in 2005 and named after Django Reinhardt. One of Django’s strengths is that it lets developers focus on core business logic instead of repetitive plumbing, which is a good example of the DRY principle.

### Your First Django Project

1. Check your Python version.

Different Django versions require different Python versions. For example:

- Django 1.11 requires Python 2.7 or Python 3.4+
- Django 2.2 requires Python 3.5+
- Django 3.0 requires Python 3.6+

Check your interpreter:

```bash
python3 --version
```

You can also inspect it from Python itself:

```python
import sys
sys.version
sys.version_info
```

2. Install Django.

```bash
pip3 install -U pip
pip3 install django==2.2.13
```

3. Create a project:

```bash
django-admin --version
django-admin startproject hellodjango
```

4. Open the project in PyCharm or another IDE and create a virtual environment if needed.

Important project files:

- `hellodjango/__init__.py`: marks the directory as a Python package
- `hellodjango/settings.py`: project configuration
- `hellodjango/urls.py`: URL routing
- `hellodjango/wsgi.py`: WSGI entry point
- `manage.py`: management script

5. Install project dependencies inside the virtual environment if necessary:

```bash
pip install django==2.2.13
```

6. Run the development server:

```bash
python manage.py runserver
```

Visit `http://127.0.0.1:8000` in a browser.

Notes:

- Django’s built-in server is only for development and testing.
- Code changes are usually reloaded automatically.
- You can inspect available management commands with `python manage.py help`.
- The default server runs on port `8000`, but you can specify another IP or port.

### Configure Language and Time Zone

Django supports internationalization and localization. In `settings.py`, change:

```python
LANGUAGE_CODE = 'en-us'
TIME_ZONE = 'UTC'
```

to:

```python
LANGUAGE_CODE = 'zh-hans'
TIME_ZONE = 'Asia/Chongqing'
```

Refreshing the browser will show the localized Django welcome page.
