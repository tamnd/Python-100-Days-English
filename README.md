## Python - 100 Days from Beginner to Master

This repository is a long-form Python learning project covering:

- Python fundamentals
- practical Python applications
- web development
- databases
- crawlers
- data analysis
- machine learning
- project engineering

### Why Python

Python is widely used because it is:

- approachable for beginners
- expressive and readable
- supported by a large ecosystem
- useful in many career paths

Typical application areas:

- backend development
- DevOps and automation
- data collection
- quantitative analysis
- data science
- machine learning
- automated testing

### Suggested Advice for Learners

- Make English part of your working language.
- Practice consistently.
- Learn from mistakes.
- Share what you learn.
- Use AI tools to improve productivity, but do not outsource thinking.

### Course Structure

The project is organized into day-based sections:

- `Day01-20`: Python language basics
- `Day21-30`: Python applications
- `Day31-45`: advanced language, frontend, Linux, databases
- `Day46-60`: Django and web engineering
- `Day61-65`: web crawling
- `Day66-80`: data analysis
- `Day81-90`: machine learning
- `Day91-100`: project, deployment, testing, architecture

There are also supplemental materials:

- `public-lectures`: public-class notes
- `extras`: extra essays and references
- `res`: images and supporting assets

This repository is meant to be studied progressively, but it is also useful as a reference collection.
