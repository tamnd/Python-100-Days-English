## The k-Nearest Neighbors Algorithm

k-nearest neighbors, or kNN, is a non-parametric statistical method used for classification and regression. It was proposed in 1951 by the American statisticians Evelyn Fix and Joseph Hodges Jr. The basic idea of kNN is to find the $\small{k}$ historical instances closest to a new input instance, and then classify the new instance according to the majority label among those neighbors or output a target value according to those neighbors. We already gave a simple demonstration of this in the previous lesson.

Different from many mainstream machine-learning algorithms, kNN does not have an explicit learning and training process. It follows a simple and plain idea: a thing is affected by the things closest to it. There are two key questions in kNN. The first is how to choose the value of $\small{k}$, that is, how many nearest neighbors we should use. The second is how to judge whether two instances are near or far, which leads to the problem of distance measurement.

### Distance Measurement

We can use distance to measure the similarity between two instances in feature space. Common distance measures include Minkowski distance, Mahalanobis distance, cosine distance, edit distance, and so on. For two $\small{n}$-dimensional vectors $\small{\mathbf{x}=(x_{1}, x_{2}, \cdots, x_{n})}$ and $\small{\mathbf{y}=(y_{1}, y_{2}, \cdots, y_{n})}$, Minkowski distance is defined as:

$$
d(\mathbf{x}, \mathbf{y}) = (\sum_{i=1}^{n}{\vert x_{i} - y_{i} \rvert}^{p})^{\frac{1}{p}}
$$

When $\small{p = 1}$, this becomes **Manhattan distance**:

$$
d(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^{n} \lvert x_{i} - y_{i} \rvert
$$

When $\small{p = 2}$, it becomes **Euclidean distance**:

$$
d(\mathbf{x}, \mathbf{y}) = \sqrt{\sum_{i=1}^{n}(x_{i} - y_{i})^{2}}
$$

When $\small{p \to \infty}$, it becomes **Chebyshev distance**:

$$
d(\mathbf{x}, \mathbf{y}) = \underset{i}{max}(\lvert x_{i} - y_{i} \rvert)
$$

For kNN classification on numeric data, Euclidean distance is often a good default choice.

```python
data = np.hstack((X, y.reshape(-1, 1)))
```

### Implementing kNN Classification

To better understand the principle, let us first implement kNN with NumPy and SciPy instead of directly using scikit-learn.

#### NumPy-based implementation

kNN needs distance calculation. So first, let us write a function for Euclidean distance:

```python
import numpy as np


def euclidean_distance(u, v):
    """Calculate the Euclidean distance between two n-dimensional vectors."""
    return np.sqrt(np.sum(np.abs(u - v) ** 2))
```

Next, let us design a function that generates a label for new data according to neighbor labels.

```python
from scipy import stats


def make_label(X_train, y_train, X_one, k):
    """
    Generate a label for new data according to k nearest neighbors.
    """
    distes = [euclidean_distance(X_one, X_i) for X_i in X_train]
    labels = y_train[np.argpartition(distes, k - 1)[:k]]
    return stats.mode(labels).mode
```

> **Note**: `np.argpartition` puts the indexes of the `k` smaller elements on the left side of the array. Then, through the `[:k]` slice and fancy indexing on `y_train`, we get the labels of the `k` samples whose distance from the new data is smaller. At the end, we use the `mode` function in the `stats` module of SciPy to get the mode of the labels and use it as the predicted class label for the new data.

Then the prediction function becomes straightforward:

```python
def predict_by_knn(X_train, y_train, X_new, k=5):
    """
    KNN algorithm.
    """
    return np.array([make_label(X_train, y_train, X, k) for X in X_new])
```

### Model Evaluation

Of course, to judge whether a classifier performs well, we cannot only look at accuracy, because under class imbalance, accuracy can easily mislead us. So we also need to examine precision, recall, F1 score, and other metrics. The **confusion matrix** is a tool used to show the performance of a classification model in detail.

For a binary classification problem, the confusion matrix is:

|      | Predicted Positive | Predicted Negative |
| ---- | ------------------ | ------------------ |
| Actual Positive | True Positive (TP) | False Negative (FN) |
| Actual Negative | False Positive (FP) | True Negative (TN) |

The common metrics are:

1. Accuracy
2. Precision
3. Recall
4. F1 Score
5. Specificity and False Positive Rate
6. ROC and AUC

Let us use an example to show how to use a confusion matrix and compute the evaluation metrics of a classification model. Suppose a medical test system predicts whether a person has a certain disease. The "positive class" means "has the disease", and the "negative class" means "does not have the disease". The test results of 1000 samples are shown below.

|      | Predicted Sick | Predicted Not Sick |
| ---- | -------------- | ------------------ |
| Actual Sick | 80 (TP) | 20 (FN) |
| Actual Not Sick | 30 (FP) | 870 (TN) |

1. **Accuracy**.

$$
\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{FP} + \text{FN} + \text{TN}}
$$

In the example above, the model accuracy is: $\frac{80 + 870}{80 + 30 + 20 + 870} = \frac{950}{1000} = 0.95$ .

2. **Precision**. Precision measures the proportion of samples that are actually positive among all samples predicted as positive.

$$
\text{Precesion} = \frac{\text{TP}}{\text{TP} + \text{FP}}
$$

In the example above, precision is: $\frac{80}{80 + 30} = \frac{80}{110} = 0.73$ .

3. **Recall**. Recall measures the proportion of samples correctly predicted as positive among all actually positive samples.

$$
\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}
$$

In the example above, recall is: $\frac{80}{80 + 20} = \frac{80}{100} = 0.8$ .

4. **F1 Score**. F1 score is the harmonic mean of precision and recall.

$$
\text{F1 Score} = \frac{2}{\frac{1}{\text{Precision}} + \frac{1}{\text{Recall}}} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precesion} + \text{Recall}}
$$

In the example above, the F1 score is about `0.76`.

5. **Specificity** and **False Positive Rate**.

$$
\text{Specificity} = \frac{\text{TN}}{\text{TN} + \text{FP}} \\\\
\text{FPR} = 1 - \text{Specificity}
$$

In the example above, specificity is: $\frac{870}{870 + 30} = \frac{870}{900} = 0.97$ .

6. **ROC** and **AUC**.

ROC draws the relationship between recall and false positive rate, as shown below.

<img src="res/02_ROC_curve.png" style="zoom:38%;">

AUC is the area under the ROC curve. It measures the model's ability to distinguish positive and negative classes.
