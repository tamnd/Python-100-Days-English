## Talking Briefly About Machine Learning

Artificial intelligence is without doubt one of the hottest words in recent years. From AlphaGo defeating top human Go players in 2016, to NLP models based on the Transformer architecture in 2017, to ChatGPT based on GPT-4 in 2023, and then to the deeper use of AI in medicine, autonomous driving, and other fields, the AI wave has reached a height not seen since the Dartmouth Conference in 1956. It can be said that almost everyone's life has been affected by artificial intelligence in one way or another.

Artificial intelligence is an important branch of computer science. It involves the ability of computers to simulate intelligent behavior and the ability of machines to imitate human intelligent behavior. The main goal of AI research is to develop systems that can make decisions independently, so that they can help humans work more efficiently in medicine, engineering, finance, education, research, public service, and many other fields. The English name of artificial intelligence is *artificial intelligence*, so it is usually shortened to *AI*. AI contains many things. Machine learning, deep learning, natural language processing, computer vision, reinforcement learning, data mining, expert systems, industrial robots, and autonomous driving all belong to the scope of AI.

Narrow artificial intelligence usually can only do specific tasks. An AI that can chat usually cannot drive, and an AI that can drive usually cannot play chess. General artificial intelligence needs to have general intelligence and be able to do any task that human intelligence can do. Going one step further, AI that can go beyond human intelligence is called superintelligence.

This lesson mainly discusses machine learning. Machine learning is a subfield of artificial intelligence. It focuses on how to make computer systems learn from experience through data and algorithms and then make predictions or decisions. Simply speaking, machine learning is one way to realize artificial intelligence, and many AI systems are developed through machine learning technology. In some situations, people also use the term data mining to refer to machine learning. Data mining means extracting useful information and knowledge from data, analyzing and explaining patterns and trends in data, and finally achieving the goal of predicting future trends and behavior. Still, the focus of these two terms is a little different. Data mining pays more attention to knowledge discovery, while machine learning pays more attention to building and optimizing predictive models. At present, another very hot concept is deep learning, which is a subfield of machine learning. It especially focuses on using multi-layer neural networks to process and learn from data.

Deep learning does especially well when handling complex data such as images, speech, and natural language. It can automatically learn layered features from data, so the need for manual intervention becomes smaller. Of course, deep learning models are usually more complex than traditional machine-learning models, and they need more data and computing resources.

### What Machine Learning Is

Humans learn mainly through memory and induction. With memory we accumulate single facts, and with induction we derive new facts from old facts. Machine learning gives machines the ability to learn knowledge from data. This process does not require humans to give explicit rules. In other words, machine learning focuses on learning a pattern from data, even when the data itself contains noise. This is also the most fundamental difference between machine learning algorithms and traditional algorithms.

Traditional algorithms require humans to first know the best solution and then tell the computer how to find the answer. Machine learning algorithms do not need humans to tell the model the best solution. Instead, we provide sample data related to the problem.

We can divide the problems that computers need to solve into four kinds. The division depends on whether the input is exact or fuzzy, and whether the output is optimal or satisfactory. From that view, traditional algorithms are mainly good at the first kind of problem, while machine learning is better at the third and fourth kinds. The second kind is usually NP problems, such as the traveling salesman problem, graph coloring, and set cover. We often solve those with heuristic algorithms or approximation algorithms, although machine learning can also give satisfactory solutions there.

<img src="res/01_four_kinds_problems.png" style="zoom:45%;">

Of course, machine learning is not perfect. When we train a model with data, we still need preprocessed and cleaned data. If the quality of the data itself is very poor, it is hard to train a good model. This is what people often call GIGO, garbage in garbage out. We also need to determine whether there is some kind of relationship among variables. Machine learning cannot deal with data that has no relationship at all. Most of the time, a machine learning model outputs a series of numbers and metrics, and humans still need to interpret those numbers, decide whether the model is good, and decide how to put it into an actual business scenario.

### The First Machine Learning Example

Below, we use a very simple example to begin the first machine-learning trip. We collected 50 samples about the relationship between monthly income and monthly online-shopping expense for a type of consumers in a certain city. These historical data are stored in two lists:

```python
x = [9558, 8835, 9313, 14990, 5564, 11227, 11806, 10242, 11999, 11630,

     1674, 5045, 1617, 1707, 3096, 3407, 4674, 361, 3599, 6584,
     6356, 3859, 4519, 3352, 1634, 1032, 1106, 4951, 5309, 3800,

     3867, 2962,  882, 5435, 4174, 4948, 2376, 4987, 3329, 5002]
```

If we assume both monthly income and monthly shopping expense come from normal populations, then we can calculate the Pearson correlation coefficient to judge whether there is a relationship between them.

```python
import numpy as np

np.corrcoef(x, y)
```

Output:

```

       [0.94862936, 1.        ]])
```

We can also use `stats.pearsonr` from SciPy.

```python

```

Output:

```

```

From the output above, we can see that monthly income and monthly online-shopping expense have a strong positive correlation in this city and for this type of consumers. The correlation coefficient is `0.94862936`.

Once we know there is a strong positive correlation, a natural idea is to use monthly income to predict monthly shopping expense. We can call `X` the feature and `y` the target. **The key of machine learning is to learn how to map from feature to target through historical data.**

#### The kNN idea

One of the simplest ideas is to make the historical data into a dictionary, using monthly income as the key and monthly online-shopping expense as the value.

```python
sample_data = {key: value for key, value in zip(x, y)}
```

But the input monthly income may not exactly match a key in the dictionary. If there is no key, we cannot get a value directly. Then we can find the `k` keys that are closest to the input monthly income, take the average of the values corresponding to those `k` keys, and use that average as the prediction of monthly online-shopping expense. This is the simplest k-nearest neighbors algorithm, or kNN. It is a non-parametric statistical method used for classification and regression.

```python
import heapq
import statistics


def predict_by_knn(history_data, param_in, k=5):
    """Use kNN to make a prediction."""
    neighbors = heapq.nsmallest(k, history_data, key=lambda x: (x - param_in) ** 2)
    return statistics.mean([history_data[neighbor] for neighbor in neighbors])
```

Now we can use the function above to predict monthly online-shopping expense.

```python
incomes = [1800, 3500, 5200, 6600, 13400, 17800, 20000, 30000]
for income in incomes:
    print(f'Monthly income: {income:>5d} yuan, Monthly online-shopping expense: {predict_by_knn(sample_data, income):>6.1f} yuan')
```

Output:

```
Monthly income:  1800 yuan, Monthly online-shopping expense:  712.6 yuan
Monthly income:  3500 yuan, Monthly online-shopping expense:  712.6 yuan
Monthly income:  5200 yuan, Monthly online-shopping expense:  936.0 yuan
Monthly income:  6600 yuan, Monthly online-shopping expense: 1487.0 yuan
Monthly income: 13400 yuan, Monthly online-shopping expense: 5148.6 yuan
Monthly income: 17800 yuan, Monthly online-shopping expense: 6044.4 yuan
Monthly income: 20000 yuan, Monthly online-shopping expense: 6044.4 yuan
Monthly income: 30000 yuan, Monthly online-shopping expense: 6044.4 yuan
```

From the output above, we can see one drawback of the kNN algorithm. Missing or unbalanced sample data can make the prediction result very bad. The predicted expenses for incomes of `17800`, `20000`, and `30000` yuan are all `6044.4` yuan, because the largest monthly income in the historical data is only `19880`, so the nearest `k` neighbors for those inputs are exactly the same. In the same way, the predicted expenses for `1800` yuan and `3500` yuan are also the same. Also, there is another problem in the simple implementation above: every time we look for the nearest `k` neighbors, we need to go through the whole historical dataset once. If the dataset is very large, this part becomes expensive.

#### Regression model

Let us change to another idea to predict online-shopping expense. We use monthly income and monthly online-shopping expense as the horizontal and vertical axes and draw a scatter plot. Since there is a strong positive correlation between online-shopping expense and monthly income, this means we can find a straight line to fit these historical data points. We call the equation of this straight line $\small{y = aX + b}$ a regression equation or regression model.

<img src="res/01_regression_model.png" style="zoom:50%;">

To evaluate the quality of the regression model, we can use mean squared error:

$$
MSE = \frac{1}{n}{\sum_{i=1}^{n}(y_{i} - \hat{y_{i}})^{2}}
$$

The values of $\small{a}$ and $\small{b}$ that minimize the MSE are called the least-squares solution of the regression equation.

According to the formula above, we can write a function to compute mean squared error. It is usually called the loss function.

```python
import statistics


def get_loss(X_, y_, a_, b_):
    """Loss function."""
    y_hat = [a_ * x + b_ for x in X_]
    return statistics.mean([(v1 - v2) ** 2 for v1, v2 in zip(y_, y_hat)])
```

The next step is to find the least-squares solution. Simply speaking, we need to put possible values of `a` and `b` into the loss function and see which values make the loss function smallest. If we know nothing about the values of `a` and `b`, we can try to find them by generating random numbers again and again. This method is called Monte Carlo simulation.

```python
import random

min_loss, a, b = 1e12, 0, 0

for _ in range(100000):
    _a, _b = random.random(), random.uniform(-2000, 2000)
    curr_loss = get_loss(x, y, _a, _b)
    if curr_loss < min_loss:
        min_loss = curr_loss
        a, b = _a, _b

print(f'MSE = {min_loss}')
print(f'{a = }, {b = }')
```

Output:

```
MSE = 270690.1419424315
a = 0.4824040159203802, b = -1515.0162977046068
```

If you know more mathematics, then we can put the regression model into the loss function. Since `X` and `y` are known historical data, the loss function is actually a binary function about `a` and `b`.

$$
MSE = f(a, b) = \frac{1}{n}{\sum_{i=1}^{n}(y_{i} - (ax_{i} + b))^{2}}
$$

According to the extremum theorem in calculus, we can take partial derivatives of $\small{f(a, b)}$ and set them equal to `0`. Then we can compute the values of `a` and `b` that make $\small{f(a, b)}$ smallest.

$$
\frac{\partial{f(a, b)}}{\partial{a}} = -\frac{2}{n}\sum_{i=1}^{n}x_{i}(y_{i} - x_{i}a - b) = 0
$$

$$
\frac{\partial{f(a, b)}}{\partial{b}} = -\frac{2}{n}\sum_{i=1}^{n}(y_i - x_{i}a - b) = 0
$$

Solving the equations above gives:

$$
a = \frac{\sum(x_{i} - \bar{x})(y_{i} - \bar{y})}{\sum(x_{i} - \bar{x})^{2}}
$$

$$
b = \bar{y} - a\bar{x}
$$

We can compute `a` and `b` with the formulas above. For convenience, we directly use NumPy functions below.

```python
import numpy as np

x_bar, y_bar = np.mean(x), np.mean(y)
a = np.dot((x - x_bar), (y - y_bar)) / np.sum((x - x_bar) ** 2)
b = y_bar - a * x_bar
print(f'{a = }, {b = }')
```

Output:

```
a = 0.482084452824066, b = -1515.2028590756745
```

In fact, NumPy also has ready-made functions that can help us fit the parameters. We can use `polyfit`, or the `fit` method of the `Polynomial` type, to get the least-squares solution.

```python
a, b = np.polyfit(x, y, deg=1)
print(f'{a = }, {b = }')
```

or

```python
from numpy.polynomial import Polynomial

b, a = Polynomial.fit(x, y, deg=1).convert().coef
print(f'{a = }, {b = }')
```

> **Note**: The `deg` parameter in the code above means the highest-order term of the polynomial. `deg=1` means we are using a linear regression model.
