## Regression Models

Regression models are basic models in machine learning and statistics, used to predict continuous output variables. Simply speaking, given a group of input variables and the corresponding output variable, a regression model tries to find the mapping between them. Regression models may look simple, but they contain one of the main modeling ideas in machine learning.

Usually, we build regression models for two main goals:

1. **Describe the relationship between data.**
2. **Make predictions for unknown data.**

Regression models are widely used. For example:

1. In retail, companies use regression models to predict future demand.
2. In the automobile industry, regression models can be used to predict remaining battery life.
3. In real estate, regression models can be used to predict house prices.

### Categories of Regression Models

According to complexity and assumptions, regression models can be divided into several kinds:

1. **Linear regression**

For simple linear regression:

$$
y = \beta_0 + \beta_1 x + \varepsilon
$$

For multiple linear regression:

$$
y = \beta_{0} + \beta_{1} x_{1} + \beta_{2} x_{2} + \cdots + \beta_{n} x_{n} + \varepsilon
$$

This can also be written in vector form as:

$$
y = \mathbf{x}^{T} \mathbf{\beta} + \varepsilon
$$

2. **Polynomial regression**
3. **Nonlinear regression**
4. **Ridge, Lasso, and Elastic Net regression**
5. **Logistic regression**

Although logistic regression has the word "regression" in its name, it is mainly used for classification problems.

$$
P(y=1 \vert x) = \frac{1}{1 + e^{-(\beta_{0} + \beta_{1} x_{1} + \cdots + \beta_{n} x_{n})}}
$$

### Calculating Regression Coefficients

The key to building a regression model is finding the best regression coefficients $\small{\mathbf{\beta}}$. By "best", we mean the model parameters that make the model fit the data as well as possible. For that, we define the following loss function:

$$
L(\mathbf{\beta}) = \sum_{i=1}^{m}(y_{i} - \hat{y_{i}})^{2}
$$

In matrix form:

$$
L(\mathbf{\beta}) = (\mathbf{y} - \mathbf{X\beta})^{T}(\mathbf{y} - \mathbf{X\beta})
$$

By minimizing this loss function, we obtain the analytical solution of linear regression:

$$
\mathbf{\beta} = (\mathbf{X}^{T}\mathbf{X})^{-1}\mathbf{X}^{T}\mathbf{y}
$$

When $\small{\mathbf{X}^{T}\mathbf{X}}$ is not invertible, regularization can be added:

$$
\mathbf{\beta} = (\mathbf{X}^{T}\mathbf{X} + \mathbf{\lambda \mit{I}})^{-1}\mathbf{X}^{T}\mathbf{y}
$$

For large-scale datasets or more complex optimization problems, we can use **gradient descent** to iteratively approach the best solution.

### New Dataset Introduction

The iris dataset is not suitable for explaining regression, so here we introduce another classic dataset, the Auto MPG dataset. It can be used to predict vehicle fuel efficiency, that is, miles per gallon.

We can load it with the following code:

```python
import ssl
import pandas as pd

ssl._create_default_https_context = ssl._create_unverified_context
df = pd.read_csv('https://archive.ics.uci.edu/static/public/9/data.csv')
df.info()
```

This dataset has 9 fields. The first 8 are input variables, and the last one is the target variable.

Before modeling, we first delete the `car_name` column and use the `corr` method to check the correlation between features and the target value.

```python
df.drop(columns=['car_name'], inplace=True)
df.corr()
```

Before using this dataset, we still need to do some preprocessing. First remove missing values in `horsepower`, then treat `origin` as one-hot encoded data.

```python
df.dropna(inplace=True)
df['origin'] = df['origin'].astype('category')
df = pd.get_dummies(df, columns=['origin'], drop_first=True)
df
```

Then split the dataset into training and test sets:

```python
from sklearn.model_selection import train_test_split

X, y = df.drop(columns='mpg').values, df['mpg'].values
X_train, X_test, y_train, y_test = train_test_split(X, y, train_size=0.8, random_state=3)
```

### Linear Regression Code Example

Now use `LinearRegression` from scikit-learn's `linear_model` module:

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

If we want to see the regression coefficients and intercept:

```python
print('Coefficients:', model.coef_)
print('Intercept:', model.intercept_)
```

### Evaluation of Regression Models

We can evaluate a regression model through the following indicators:

1. Mean Squared Error (MSE)

$$
\text{MSE} = \frac{1}{m} \sum_{i=1}^{m}(y_{i} - \hat{y_{i}})^{2}
$$

2. Root Mean Squared Error (RMSE)

$$
\text{RMSE} = \sqrt{\text{MSE}}
$$

3. Mean Absolute Error (MAE)

$$
\text{MAE} = \frac{1}{m} \sum_{i=1}^{m} \lvert y_{i} - \hat{y_{i}} \rvert
$$

4. Coefficient of Determination $\small{R^{2}}$

$$
R^{2} = 1 - \frac{SS_{res}}{{SS}_{tot}}
$$

<img src="res/05_regression_r2.png" style="zoom:40%;">

We can calculate these metrics with scikit-learn:

```python
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

mse = mean_squared_error(y_test, y_pred)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

print(f'MSE: {mse:.4f}')
print(f'MAE: {mae:.4f}')
print(f'R-squared: {r2:.4f}')
```

### Adding Regularization

Ridge regression adds an $\small{L2}$ regularization term to linear regression. Its purpose is to prevent overfitting, especially when there are many features or strong collinearity among features.

$$
L(\beta) = \sum_{i=1}^{m}{(y_{i} - \hat{y_{i}})^{2}} + \lambda \cdot \sum_{j=1}^{n}{\beta_{j}^{2}}
$$

We can implement Ridge regression with `Ridge` from scikit-learn:

```python
from sklearn.linear_model import Ridge

model = Ridge()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print('Coefficients:', model.coef_)
print('Intercept:', model.intercept_)
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
print(f'MSE: {mse:.4f}')
print(f'R-squared: {r2:.4f}')
```

Lasso regression adds an $\small{L1}$ regularization term. It not only helps prevent overfitting but also has the effect of feature selection.

$$
L(\mathbf{\beta}) = \sum_{i=1}^{m}{(y_{i} - \hat{y_i})^{2}} + \lambda \cdot \sum_{j=1}^{n}{\lvert \beta_{j} \rvert}
$$

We can implement Lasso with `Lasso` from scikit-learn:

```python
from sklearn.linear_model import Lasso

model = Lasso()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print('Coefficients:', model.coef_)
print('Intercept:', model.intercept_)
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
print(f'MSE: {mse:.4f}')
print(f'R-squared: {r2:.4f}')
```

> **Notice**: In the Lasso result, some coefficients may become 0, which means the model has effectively selected important features.
