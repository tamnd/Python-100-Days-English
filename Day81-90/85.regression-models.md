## Regression Models

Regression is used when the target is numeric rather than categorical.

### Linear Regression

Basic idea:

- model the relationship between features and a numeric target
- fit a line or hyperplane

Typical topics:

- coefficients
- residuals
- least squares
- goodness of fit

### Logistic Regression

Despite the name, logistic regression is mainly used for classification. It estimates class probabilities using a logistic function.

Common ideas discussed with regression models:

- train/test split
- error metrics
- regularization
- interpretation of coefficients

Regression models are foundational because they are simple, explainable, and often work surprisingly well.
