## K-Means Clustering

K-Means is an unsupervised learning algorithm used to group similar samples together.

Core loop:

1. choose `k` cluster centers
2. assign each sample to the nearest center
3. recompute the centers
4. repeat until convergence

Use cases:

- customer segmentation
- document grouping
- exploratory clustering

Limitations:

- must choose `k` in advance
- sensitive to initialization
- assumes roughly spherical clusters
