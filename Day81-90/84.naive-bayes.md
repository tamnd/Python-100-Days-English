## Naive Bayes

We continue to introduce algorithms for classification tasks. This lesson introduces the Bayesian classifier, a probabilistic model. Bayesian classifiers are a family of classification algorithms based on Bayes' theorem.

### Bayes' Theorem

Bayes' theorem is an important theorem in probability theory. It describes how we can start from prior experience or known facts and then update our understanding of the probability of an event after collecting sample data as evidence.

Its formula is:

$$
P(A \vert B) = \frac{P(B \vert A)}{P(B)} \cdot P(A)
$$

Here:

- $\small{P(A)}$ is the **prior probability**
- $\small{P(B \vert A)}$ is the likelihood
- $\small{P(B)}$ is the total probability of event $\small{B}$
- $\small{P(A \vert B)}$ is the **posterior probability**

Bayes' theorem tells us an important fact: we can start from known facts or prior belief, collect evidence, and then update our understanding of the probability of an event.

### Naive Bayes

Naive Bayes is a classification algorithm based on Bayes' theorem and the conditional independence assumption of features. The key is the word "naive". It assumes that under a given class, the features used for classification are independent of each other. This assumption greatly simplifies computation.

Suppose we have a feature set $\small{X = \{x_1, x_2, \ldots, x_n\}}$ and a class $\small{C}$. Naive Bayes assumes:

$$
P(X \vert C) = P(x_1 \vert C) \cdot P(x_2 \vert C) \cdot \ldots \cdot P(x_n \vert C)
$$

### Algorithm Principle

#### Training stage

In the training stage, Naive Bayes first needs to calculate the prior probability of each class and the conditional probability of each feature under each class.

1. Prior probability:

$$
P(C_{i}) = \frac{n_{i}}{n}
$$

2. Conditional probability:

$$
P(x_{j} \vert C_{i}) = \frac{n_{i,j}}{n_{i}}
$$

#### Prediction stage

Given a sample $\small{X}$ to classify, Naive Bayes computes the posterior probability for each class:

$$
P(C_{i} \vert X) = \frac{P(X \vert C_{i})}{P(X)} \cdot P(C_{i})
$$

Since $\small{P(X)}$ is a constant across classes, we can ignore it during comparison:

$$
P(C_{i} \vert X) \propto P(C_{i}) \cdot P(x_1 \vert C_{i}) \cdot P(x_2 \vert C_{i}) \cdot \ldots \cdot P(x_n \vert C_{i})
$$

Then we choose the class with the highest posterior probability as the prediction result.

#### Code implementation

We still use the iris dataset as an example. According to the principle above, let us implement a Naive Bayes classifier with NumPy.

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split

iris = load_iris()
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, train_size=0.8, random_state=3)
```

During training, we need class labels, prior probabilities, and likelihood values. Here, we do a simple discretization of the continuous iris features.

```python
import numpy as np
import pandas as pd


def naive_bayes_fit(X, y):
    clazz_labels, clazz_counts = np.unique(y, return_counts=True)
    prior_probs = pd.Series({k: v / y.size for k, v in zip(clazz_labels, clazz_counts)})
    X = np.copy(X)
    likelihoods = {}
    for j in range(X.shape[1]):
        X[:, j] = pd.cut(X[:, j], bins=5, labels=np.arange(1, 6))
        for i in prior_probs.index:
            x_prime = X[y == i, j]
            x_values, x_counts = np.unique(x_prime, return_counts=True)
            for k, value in enumerate(x_values):
                likelihoods[(i, j, value)] = x_counts[k] / x_prime.size
    return prior_probs, likelihoods
```

Then use those probabilities to predict labels:

```python
def naive_bayes_predict(X, p_ci, p_x_ci):
    X = np.copy(X)
    for j in range(X.shape[1]):
        X[:, j] = pd.cut(X[:, j], bins=5, labels=np.arange(1, 6))
    results = np.zeros((X.shape[0], p_ci.size))
    clazz_labels = p_ci.index.values
    for k in range(X.shape[0]):
        for i, label in enumerate(clazz_labels):
            prob = p_ci.loc[label]
            for j in range(X.shape[1]):
                prob *= p_x_ci.get((i, j, X[k, j]), 0)
            results[k, i] = prob
    return clazz_labels[results.argmax(axis=1)]
```

We can apply the function to the test set:

```python
p_ci, p_x_ci = naive_bayes_fit(X_train, y_train)
y_pred = naive_bayes_predict(X_test, p_ci, p_x_ci)
y_pred == y_test
```

In actual work, we still recommend directly using scikit-learn. The `naive_bayes` module in scikit-learn provides several variants:

- `BernoulliNB`
- `CategoricalNB`
- `ComplementNB`
- `GaussianNB`
- `MultinomialNB`

For the iris dataset, because its features are continuous values, we can use `GaussianNB`:

```python
from sklearn.naive_bayes import GaussianNB

model = GaussianNB()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

Look at the evaluation result:

```python
from sklearn.metrics import classification_report

print(classification_report(y_test, y_pred))
```

If we want to see the probabilities assigned by the Naive Bayes model to each class for each sample, we can use:

```python
model.predict_proba(X_test).round(2)
```

### Advantages and Disadvantages

The main advantages of Naive Bayes are:

1. simple logic and easy implementation
2. low computational cost
3. small influence from noise and irrelevant attributes

Its biggest weakness is also obvious: it assumes that features are independent of each other. In real applications, that assumption is usually not fully true. When feature correlation is strong, the classification effect can become poor.

### Summary

Naive Bayes has wide applications in many fields, such as:

- text classification
- spam filtering
- recommendation systems
- medical diagnosis
