## Decision Trees and Random Forests

A decision tree repeatedly splits data according to features in order to separate classes or predict values.

Key ideas:

- split criteria such as information gain or Gini impurity
- tree depth
- leaf nodes
- pruning

Advantages:

- interpretable
- handles nonlinear boundaries
- works with mixed features

Disadvantages:

- easy to overfit
- unstable if used alone

Random forest improves on a single tree by:

- training many trees
- using random feature subsets
- aggregating predictions

This usually improves robustness and generalization.
