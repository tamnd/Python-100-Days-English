## Decision Trees and Random Forests

A decision tree is a supervised learning algorithm based on a tree structure. It can be used for both **classification** and **regression** tasks. It predicts by splitting the dataset step by step into different subsets until some stopping conditions are met. In daily life, we also make decisions in a similar way, and the prediction process of a decision tree is very much like executing a series of `if...else...` branches.

In a decision tree, nodes are divided into two kinds: internal nodes and leaf nodes. Internal nodes correspond to feature tests, and leaf nodes represent final decision results, that is, class labels or regression targets.

### Building a Decision Tree

There are three core steps in training a decision-tree model:

1. feature selection
2. tree construction
3. tree pruning

#### Feature selection

Feature selection decides which features should be used to make splits. If a feature can make the resulting child nodes belong as much as possible to the same class, that means the node has high **purity**, and that feature has strong classification ability.

In decision-tree models, three common standards are used to choose strong features:

1. information gain
2. information gain ratio
3. Gini index

To explain information gain, we first need the idea of **information entropy**. Entropy measures uncertainty. The higher the entropy, the greater the uncertainty of the dataset. The lower the entropy, the purer the data.

The entropy formula is:

$$
H(D) = -\sum_{i = 1}^{k} P(x_i)log_2P(x_i)
$$

After we know the entropy of the original dataset and the entropy after a split, we can define **information gain**:

$$
g(D, A) = E(D) - E(D \vert A)
$$

The larger the information gain, the stronger the feature's classification ability.

The functions for entropy and information gain can be written as follows:

```python
import numpy as np


def entropy(y):
    _, counts = np.unique(y, return_counts=True)
    prob = counts / y.size
    return -np.sum(prob * np.log2(prob))


def info_gain(x, y):
    values, counts = np.unique(x, return_counts=True)
    new_entropy = 0
    for i, value in enumerate(values):
        prob = counts[i] / x.size
        new_entropy += prob * entropy(y[x == value])
    return entropy(y) - new_entropy
```

The classic ID3 algorithm selects features according to information gain.

Because information gain tends to prefer features with many values, people later introduced **information gain ratio**:

$$
R(D, A) = \frac{g(D, A)}{E_{A}(D)}
$$

The classic C4.5 algorithm selects features according to information gain ratio.

Besides those two, the **Gini index** is also a good feature-selection standard. It is also called Gini impurity. Its value is between 0 and 1. The purer the dataset, the closer the Gini index is to 0.

$$
G(D) = 1 - \sum_{k=1}^{n}{p_{k}}^{2}
$$

The classic CART decision-tree algorithm selects features according to the Gini index.

#### Data splitting

The process of building a decision tree is recursive. After a feature is chosen, the data is split into two or more subsets according to that feature. Then the same process is repeated on each subset until a stopping condition is reached.

Common stopping conditions include:

1. the tree reaches a preset depth
2. the number of samples at the current node is smaller than a threshold
3. all samples at the node belong to the same class
4. the change in information gain or Gini index is smaller than a threshold

#### Tree pruning

Pruning a complex decision tree is often necessary. Pruning can reduce model complexity and lower the risk of overfitting.

Common pruning strategies include:

1. post-pruning
2. pre-pruning

### Implementing a Decision Tree Model

We can use `DecisionTreeClassifier` and `DecisionTreeRegressor` from scikit-learn's `tree` module. Here we focus on classification.

```python
from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

Then compare the prediction and the true value, and look at the evaluation report:

```python
from sklearn.metrics import classification_report

print(y_test)
print(y_pred)
print(classification_report(y_test, y_pred))
```

We can also visualize the decision tree:

```python
import matplotlib.pyplot as plt
from sklearn.tree import plot_tree

plt.figure(figsize=(12, 10))
plot_tree(
    decision_tree=model,
    feature_names=iris.feature_names,
    class_names=iris.target_names,
    filled=True
)
plt.show()
```

The parameters of `DecisionTreeClassifier` are the hyperparameters of the model. Some important ones are:

1. `criterion`
2. `max_depth`
3. `min_samples_split`
4. `min_samples_leaf`
5. `max_features`
6. `class_weight`
7. `splitter`
8. `max_leaf_nodes`
9. `min_impurity_decrease`
10. `ccp_alpha`

### Overview of Random Forest

A random forest is an ensemble-learning algorithm based on decision trees. Ensemble learning means combining the prediction results of multiple models to improve overall performance. The core idea is that a combination of models is often better than a single model. Random forest builds many decision trees and then combines their predictions through voting for classification or averaging for regression. This improves the accuracy and robustness of the model.
