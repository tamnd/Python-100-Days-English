## Ensemble Learning Algorithms

In the previous lessons we mainly introduced single-model machine learning methods. In fact, combining several single models into one composite model has already become a mainstream idea in modern machine learning. This method is called **ensemble learning**. The goal of ensemble learning is to combine multiple weak learners into a strong learner so that the final model can overcome the limitations of any one model and achieve **better generalization ability**. It is usually used in problems where high prediction accuracy is especially important.

### Main Categories

Ensemble-learning algorithms are mainly divided into the following kinds:

1. **Bagging**. Multiple subsets are created by random sampling from the training data. A model is trained on each subset, and then their results are combined. The most typical example is the random forest that we discussed earlier.
2. **Boosting**. Multiple models are trained iteratively. In each round, the algorithm pays more attention to the samples that were predicted incorrectly in the previous round. Classic algorithms include AdaBoost, Gradient Boosting, and XGBoost.
3. **Stacking**. Several first-level models are trained, then their predictions are used as new features and passed into another model, which makes the final prediction.

Put simply, Boosting trains a sequence of weak learners in series so that the samples misclassified by earlier learners receive more attention later, and then combines those weak learners into a stronger classifier.

### AdaBoost

AdaBoost, short for Adaptive Boosting, was proposed by Yoav Freund and Robert Schapire in 1996. It is a classic ensemble method. Its idea is simple:

- increase the weight of the samples misclassified in the previous round;
- give higher weight to the weak learners that perform better.

Its training process is iterative:

1. **Initialize sample weights.** Each training sample starts with the same weight. If there are `N` samples, the initial weight is:

$$
w_{i}^{(1)} = \frac{1}{N}, \ i = 1, 2, \cdots, N
$$

2. **Train a weak learner.** At each round, AdaBoost trains a weak classifier according to the current sample weights and computes its weighted error:

$$
\varepsilon_{t} = \sum_{i=1}^{N} w_{i}^{(t)} \cdot I(y_{i} \neq h_{t}(x_{i}))
$$

3. **Update the classifier weight.** The weight of the `t`-th weak learner is:

$$
\alpha_{t} = \frac{1}{2} ln \left( \frac{1 - \varepsilon_{t}}{\varepsilon_{t}} \right)
$$

When the classifier makes fewer mistakes, `\alpha_t` becomes larger, which means that classifier matters more.

4. **Update sample weights.** Samples classified incorrectly get larger weights, while correctly classified samples get smaller weights:

$$
w_{i}^{(t + 1)} = w_{i}^{(t)} \cdot e^{-\alpha_{t} y_{i} h_{t}(x_{i})}
$$

5. **Normalize the weights.** Make the sum of all sample weights equal to `1`.
6. **Build the final classifier.** The final result is the weighted combination of all weak learners:

$$
H(x) = \text{sign} \left( \sum_{t=1}^{T} \alpha_{t} h_{t}(x) \right)
$$

We can still use the iris dataset to build a classifier with AdaBoost.

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import AdaBoostClassifier
from sklearn.metrics import classification_report

iris = load_iris()
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, train_size=0.8, random_state=3)

base_estimator = DecisionTreeClassifier(max_depth=1)
model = AdaBoostClassifier(base_estimator, n_estimators=50)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print(classification_report(y_test, y_pred))
```

Important hyperparameters include:

1. `n_estimators`: the number of weak learners to train.
2. `learning_rate`: the contribution of each weak learner to the final model.
3. `algorithm`: the AdaBoost training mode, such as `'SAMME'` or `'SAMME.R'`.
4. `base_estimator`: the weak learner used in each round. By default it is a depth-1 decision tree.

If you increase `n_estimators`, performance may improve, but the model may also overfit. A larger `learning_rate` can speed training up, but it can also make the model unstable. In practice, cross-validation is usually needed to find a better combination.

### GBDT

GBDT, short for Gradient Boosting Decision Trees, is another very powerful ensemble method, and it is used even more widely than AdaBoost in real work. It is based on the idea of **gradient boosting**. Instead of only adjusting sample weights, it keeps fitting the residual errors left by the previous model.

For classification, a common loss function is log loss. If the current model output is `F(x)`, and `p(x)` is the probability after the sigmoid transform:

$$
p(x) = \frac{1}{1 + e^{-F(x)}}
$$

then the gradient of the loss with respect to `F(x)` is:

$$
\frac{\partial{L(y, F(x))}}{\partial{F(x)}} = p(x) - y
$$

That gradient tells us the difference between the current prediction and the true label. In each round:

- we compute the residuals;
- we train a new decision tree to fit those residuals;
- we update the model with the new tree:

$$
F_{m + 1}(x) = F_{m}(x) + \eta h_{m}(x)
$$

Here, `\eta` is the learning rate and `h_m(x)` is the weak learner trained in the current round.

Using `GradientBoostingClassifier` in `scikit-learn` is straightforward:

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import classification_report

iris = load_iris()
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, train_size=0.8, random_state=3)

model = GradientBoostingClassifier(n_estimators=32)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print(classification_report(y_test, y_pred))
```

Some important hyperparameters are:

1. `loss`: the loss function. The default is log loss.
2. `learning_rate`: how much each tree contributes to the final result.
3. `n_estimators`: the number of trees.
4. `subsample`: the fraction of samples used when training each tree.
5. `criterion`: the rule used to evaluate splits.
6. `validation_fraction`: the size of the validation set used for early stopping.

Usually, when you increase `n_estimators`, you also decrease `learning_rate` so the model does not overfit too easily.

### XGBoost and LightGBM

Even though GBDT is already strong, there is still room to improve accuracy, speed, and generalization. XGBoost, proposed by Tianqi Chen, is one of the best-known gradient-boosting frameworks. Compared with plain GBDT, it improves optimization, adds regularization, handles sparse data better, and makes training faster through engineering optimizations.

To use it, install the package first:

```bash
pip install xgboost
```

Then the code can look like this:

```python
import matplotlib.pyplot as plt
import xgboost as xgb
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

iris = load_iris()
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, train_size=0.8, random_state=3)

dm_train = xgb.DMatrix(X_train, y_train)
dm_test = xgb.DMatrix(X_test)

params = {
    'booster': 'gbtree',
    'objective': 'multi:softmax',
    'num_class': 3,
    'gamma': 0.1,
    'max_depth': 6,
    'lambda': 2,
    'subsample': 0.8,
    'colsample_bytree': 0.8,
    'eta': 0.001,
    'seed': 10,
    'nthread': 16,
}

model = xgb.train(params, dm_train, num_boost_round=200)
y_pred = model.predict(dm_test)
print(classification_report(y_test, y_pred))
xgb.plot_importance(model)
plt.grid(False)
plt.show()
```

Some XGBoost parameters that deserve attention are `booster`, `objective`, `eta` or `learning_rate`, `alpha`, `lambda`, `scale_pos_weight`, `gamma`, `num_class`, and the feature-sampling parameters such as `colsample_bytree`.

LightGBM is another top Boosting framework. It was open-sourced by Microsoft in 2017. It is still based on GBDT, but it is designed for large-scale datasets and high efficiency. It uses tricks such as histogram-based splitting, gradient-based one-side sampling, exclusive feature bundling, and leaf-wise tree growth. These choices make the framework lighter and faster.

```bash
pip install lightgbm
```

```python
import lightgbm as lgb
import numpy as np
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

iris = load_iris()
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, train_size=0.8, random_state=3)

train_data = lgb.Dataset(X_train, label=y_train)
test_data = lgb.Dataset(X_test, label=y_test, reference=train_data)

params = {
    'objective': 'multiclass',
    'num_class': 3,
    'metric': 'multi_logloss',
    'boosting_type': 'gbdt',
    'num_leaves': 31,
    'learning_rate': 0.05,
    'feature_fraction': 0.75,
    'early_stopping_rounds': 10,
}
model = lgb.train(params=params, train_set=train_data, num_boost_round=200, valid_sets=[test_data])
y_pred = model.predict(X_test, num_iteration=model.best_iteration)
y_pred_max = np.argmax(y_pred, axis=1)
print(classification_report(y_test, y_pred_max))
```

### Summary

Ensemble learning reduces bias and variance by combining multiple models, so it often predicts better than a single model. It is usually more stable and more resistant to noise, but the cost is higher computation, weaker interpretability, and harder hyperparameter tuning. Even now, when deep learning gets most of the attention, Boosting methods such as XGBoost, LightGBM, and CatBoost still have very broad practical use.
