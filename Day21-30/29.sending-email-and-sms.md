## Sending Email and SMS with Python

In earlier lessons, we learned how to generate Excel, Word, and PDF documents automatically. The next step is to send those documents to recipients by email, and even notify them by SMS. Python can handle both tasks quite well.

### Sending Email

Even in the age of instant messaging, email remains one of the most widely used internet applications. Job offers, account activation links, and product promotions are often delivered by email, and these tasks are usually automated.

Sending email commonly uses the **SMTP** protocol. Python simplifies SMTP operations through the `smtplib` module.

Below is a simple example of sending a plain text email:

```python
import smtplib
from email.header import Header
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText

email = MIMEMultipart()
email['From'] = 'xxxxxxxxx@126.com'
email['To'] = 'yyyyyy@qq.com;zzzzzz@1000phone.com'
email['Subject'] = Header('Work Report for the First Half of the Year', 'utf-8')

content = """According to German media reports, the German train drivers' union
voted on the 9th local time and decided to launch a nationwide strike..."""
email.attach(MIMEText(content, 'plain', 'utf-8'))

smtp_obj = smtplib.SMTP_SSL('smtp.126.com', 465)
smtp_obj.login('xxxxxxxxx@126.com', 'mail-server-authorization-code')
smtp_obj.sendmail(
    'xxxxxxxxx@126.com',
    ['yyyyyy@qq.com', 'zzzzzz@1000phone.com'],
    email.as_string()
)
```

If you want to send attachments, the attachment content needs to be encoded, commonly with Base64.

```python
import smtplib
from email.header import Header
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from urllib.parse import quote

email = MIMEMultipart()
email['From'] = 'xxxxxxxxx@126.com'
email['To'] = 'zzzzzzzz@1000phone.com'
email['Subject'] = Header('Please Check the Attached Resignation Certificate', 'utf-8')

content = """<p>Dear former colleague:</p>
<p>Your resignation certificate is attached. Please check it.</p>
<br>
<p>Best regards!</p>
<hr>
<p>Sun Meili</p>"""
email.attach(MIMEText(content, 'html', 'utf-8'))

with open('resources/Wang_Dachui_Resignation_Certificate.docx', 'rb') as file:
    attachment = MIMEText(file.read(), 'base64', 'utf-8')
    attachment['content-type'] = 'application/octet-stream'
    filename = quote('Wang_Dachui_Resignation_Certificate.docx')
    attachment['content-disposition'] = f'attachment; filename="{filename}"'
    email.attach(attachment)

smtp_obj = smtplib.SMTP_SSL('smtp.126.com', 465)
smtp_obj.login('xxxxxxxxx@126.com', 'mail-server-authorization-code')
smtp_obj.sendmail(
    'xxxxxxxxx@126.com',
    'zzzzzzzz@1000phone.com',
    email.as_string()
)
```

For convenience, here is a reusable function:

```python
import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from urllib.parse import quote

EMAIL_HOST = 'smtp.126.com'
EMAIL_PORT = 465
EMAIL_USER = 'xxxxxxxxx@126.com'
EMAIL_AUTH = 'mail-server-authorization-code'


def send_email(*, from_user, to_users, subject='', content='', filenames=[]):
    """Send an email."""
    email = MIMEMultipart()
    email['From'] = from_user
    email['To'] = to_users
    email['Subject'] = subject

    message = MIMEText(content, 'plain', 'utf-8')
    email.attach(message)
    for filename in filenames:
        with open(filename, 'rb') as file:
            pos = filename.rfind('/')
            display_filename = filename[pos + 1:] if pos >= 0 else filename
            display_filename = quote(display_filename)
            attachment = MIMEText(file.read(), 'base64', 'utf-8')
            attachment['content-type'] = 'application/octet-stream'
            attachment['content-disposition'] = f'attachment; filename="{display_filename}"'
            email.attach(attachment)

    smtp = smtplib.SMTP_SSL(EMAIL_HOST, EMAIL_PORT)
    smtp.login(EMAIL_USER, EMAIL_AUTH)
    smtp.sendmail(from_user, to_users.split(';'), email.as_string())
```

### Sending SMS

Sending SMS messages also usually relies on a third-party platform. The exact service can vary, but the pattern is usually similar: send an HTTP request to the provider's SMS gateway.

Example:

```python
import random

import requests


def send_message_by_luosimao(tel, message):
    """Send SMS via the Luosimao SMS gateway."""
    resp = requests.post(
        url='http://sms-api.luosimao.com/v1/send.json',
        auth=('api', 'key-your-platform-key'),
        data={
            'mobile': tel,
            'message': message
        },
        timeout=10,
        verify=False
    )
    return resp.json()


def gen_mobile_code(length=6):
    """Generate a numeric mobile verification code."""
    return ''.join(random.choices('0123456789', k=length))


def main():
    code = gen_mobile_code()
    message = f'Your SMS verification code is {code}. Do not share it with anyone! [Python Mini Course]'
    print(send_message_by_luosimao('13500112233', message))


if __name__ == '__main__':
    main()
```

If the returned JSON is `{'error': 0, 'msg': 'OK'}`, the message was sent successfully.

### Summary

In real-world projects, both email and SMS are often sent through third-party services. For production use, self-hosting or using a reliable paid service is usually the better choice.
