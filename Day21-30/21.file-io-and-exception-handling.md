## File Reading/Writing and Exception Handling

In real development, we often need to **persist data**, meaning we move data from temporary storage such as memory to longer-lived storage such as a hard disk. The simplest way to do that is through the **file system**, by saving data into **files**.

A computer **file system** is a way to store and organize data so that access and lookup are convenient. It uses the logical concepts of **files** and **tree-structured directories** instead of exposing raw disk blocks directly.

### Opening and Closing Files

In Python, file operations are straightforward. We use the built-in `open` function to open a file. Its most common parameters specify:

- the file name
- the mode
- the encoding

Common file modes:

| Mode | Meaning |
| --- | --- |
| `'r'` | read (default) |
| `'w'` | write, truncating existing content |
| `'x'` | create for writing, fail if file exists |
| `'a'` | append to the end of the file |
| `'b'` | binary mode |
| `'t'` | text mode (default) |
| `'+'` | update mode (read and write) |

If you open a text file, you can specify the encoding with the `encoding` parameter. If the file was saved using a different encoding, decoding may fail.

When `open` succeeds, it returns a file object. After you finish using it, call `close` to release the resource.

### Reading and Writing Text Files

To read a text file, use mode `'r'`:

```python
file = open('ToTheOakTree.txt', 'r', encoding='utf-8')
print(file.read())
file.close()
```

You can also read line by line or read all lines into a list:

```python
file = open('ToTheOakTree.txt', 'r', encoding='utf-8')
for line in file:
    print(line, end='')
file.close()

file = open('ToTheOakTree.txt', 'r', encoding='utf-8')
lines = file.readlines()
for line in lines:
    print(line, end='')
file.close()
```

To write to a file, use mode `'w'` or `'a'`:

```python
file = open('ToTheOakTree.txt', 'a', encoding='utf-8')
file.write('\nTitle: To The Oak Tree')
file.write('\nAuthor: Shu Ting')
file.write('\nDate: March 1977')
file.close()
```

### Exception Handling

If a file does not exist or cannot be opened, `open` raises an exception. To make code more robust, Python provides an exception handling mechanism based on the keywords:

- `try`
- `except`
- `else`
- `finally`
- `raise`

Example:

```python
file = None
try:
    file = open('ToTheOakTree.txt', 'r', encoding='utf-8')
    print(file.read())
except FileNotFoundError:
    print('Cannot open the specified file!')
except LookupError:
    print('Unknown encoding specified!')
except UnicodeDecodeError:
    print('Decoding error while reading the file!')
finally:
    if file:
        file.close()
```

In Python, the code that might fail goes inside the `try` block. One or more `except` blocks can then catch and handle specific exceptions. The `finally` block always executes and is a good place to release resources.

Python includes many built-in exception types. All exceptions ultimately derive from `BaseException`, while most ordinary exceptions derive from `Exception`.

You can also define your own exception types and raise them with `raise`.

```python
class InputError(ValueError):
    """Custom exception type."""
    pass


def fac(num):
    """Compute factorial."""
    if num < 0:
        raise InputError('Factorial can only be computed for non-negative integers')
    if num in (0, 1):
        return 1
    return num * fac(num - 1)
```

Handling it:

```python
flag = True
while flag:
    num = int(input('n = '))
    try:
        print(f'{num}! = {fac(num)}')
        flag = False
    except InputError as err:
        print(err)
```

### Context Manager Syntax

Instead of manually closing a file, you can use `with`. The file object automatically closes when the block ends.

```python
try:
    with open('ToTheOakTree.txt', 'r', encoding='utf-8') as file:
        print(file.read())
except FileNotFoundError:
    print('Cannot open the specified file!')
except LookupError:
    print('Unknown encoding specified!')
except UnicodeDecodeError:
    print('Decoding error while reading the file!')
```

Only objects that follow the **context manager protocol** can be used with `with`.

### Reading and Writing Binary Files

Binary file operations are similar, but use `'rb'` for reading and `'wb'` for writing. For binary files, `read` returns bytes and `write` expects bytes.

```python
try:
    with open('guido.jpg', 'rb') as file1:
        data = file1.read()
    with open('Guido.jpg', 'wb') as file2:
        file2.write(data)
except FileNotFoundError:
    print('Cannot open the specified file.')
except IOError:
    print('An error occurred while reading/writing the file.')
print('Program finished.')
```

If the file is large, reading it all at once may use too much memory. Instead, read it in chunks:

```python
try:
    with open('guido.jpg', 'rb') as file1, open('Guido.jpg', 'wb') as file2:
        data = file1.read(512)
        while data:
            file2.write(data)
            data = file1.read(512)
except FileNotFoundError:
    print('Cannot open the specified file.')
except IOError:
    print('An error occurred while reading/writing the file.')
print('Program finished.')
```

### Summary

By reading and writing files, we can persist data. In Python, the `open` function gives us a file object, and the file object's `read` and `write` methods perform file operations. Runtime problems can be handled with Python's exception mechanism. The core keywords are `try`, `except`, `else`, `finally`, and `raise`.

One final reminder: **do not use exceptions to handle normal business logic or control normal program flow**. That is a common beginner mistake.
