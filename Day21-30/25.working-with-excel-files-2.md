## Reading and Writing Excel Files in Python, Part 2

### Introduction to Excel

Excel is Microsoft's spreadsheet application for Windows and macOS. It remains one of the most widely used personal data-processing tools. Learning how to operate Excel files with Python is extremely useful for office automation and for import/export features in business software.

In this lesson, we continue with another third-party library: `openpyxl`.

Install it with:

```bash
pip install openpyxl
```

The main advantages of `openpyxl` are:

- it can read and write the same workbook
- it is more convenient than `xlrd`/`xlwt` in many cases
- it handles styles and formulas more easily
- it supports charts and pivot-related features

However, it does **not** support Excel files from versions before Office 2007.

### Reading Excel Files

Suppose we have an Excel file named `Alibaba_2020_Stock_Data.xlsx`. We can read it like this:

```python
import datetime

import openpyxl

wb = openpyxl.load_workbook('Alibaba_2020_Stock_Data.xlsx')
print(wb.sheetnames)
sheet = wb.worksheets[0]
print(sheet.dimensions)
print(sheet.max_row, sheet.max_column)

print(sheet.cell(3, 3).value)
print(sheet['C3'].value)
print(sheet['G255'].value)

print(sheet['A2:C5'])

for row_ch in range(2, sheet.max_row + 1):
    for col_ch in 'ABCDEFG':
        value = sheet[f'{col_ch}{row_ch}'].value
        if type(value) == datetime.datetime:
            print(value.strftime('%Y-%m-%d'), end='\t')
        elif type(value) == int:
            print(f'{value:<10d}', end='\t')
        elif type(value) == float:
            print(f'{value:.4f}', end='\t')
        else:
            print(value, end='\t')
    print()
```

There are two common ways to access cells:

- `sheet.cell(row, col)`, where indices start at `1`
- `sheet['C3']`, using Excel-style coordinates

You can also access ranges such as `sheet['A2:C5']`, which returns nested tuples.

### Writing Excel Files

Here is a simple example of writing an Excel file with `openpyxl`.

```python
import random

import openpyxl

wb = openpyxl.Workbook()

sheet = wb.active
sheet.title = 'Final Scores'

titles = ('Name', 'Chinese', 'Math', 'English')
for col_index, title in enumerate(titles):
    sheet.cell(1, col_index + 1, title)

names = ('Guan Yu', 'Zhang Fei', 'Zhao Yun', 'Ma Chao', 'Huang Zhong')
for row_index, name in enumerate(names):
    sheet.cell(row_index + 2, 1, name)
    for col_index in range(2, 5):
        sheet.cell(row_index + 2, col_index, random.randrange(50, 101))

wb.save('Exam_Scores.xlsx')
```

### Styling Cells and Using Formulas

When working with `openpyxl`, we can style cells directly through attributes of the `Cell` object, such as:

- `font`
- `alignment`
- `border`

Example:

```python
import openpyxl
from openpyxl.styles import Font, Alignment, Border, Side

alignment = Alignment(horizontal='center', vertical='center')
side = Side(color='ff7f50', style='mediumDashed')

wb = openpyxl.load_workbook('Exam_Scores.xlsx')
sheet = wb.worksheets[0]

sheet.row_dimensions[1].height = 30
sheet.column_dimensions['E'].width = 120

sheet['E1'] = 'Average'
sheet.cell(1, 5).font = Font(size=18, bold=True, color='ff1493', name='STKaiti')
sheet.cell(1, 5).alignment = alignment
sheet.cell(1, 5).border = Border(left=side, top=side, right=side, bottom=side)
for i in range(2, 7):
    sheet[f'E{i}'] = f'=average(B{i}:D{i})'
    sheet.cell(i, 5).font = Font(size=12, color='4169e1', italic=True)
    sheet.cell(i, 5).alignment = alignment

wb.save('Exam_Scores.xlsx')
```

### Generating Charts

With `openpyxl`, we can also insert charts into Excel files. The basic process is:

1. create a chart object
2. define the data range
3. define the category range
4. add the chart to the worksheet

Example:

```python
from openpyxl import Workbook
from openpyxl.chart import BarChart, Reference

wb = Workbook(write_only=True)
sheet = wb.create_sheet()

rows = [
    ('Category', 'Sales Team A', 'Sales Team B'),
    ('Phones', 40, 30),
    ('Tablets', 50, 60),
    ('Laptops', 80, 70),
    ('Accessories', 20, 10),
]

for row in rows:
    sheet.append(row)

chart = BarChart()
chart.type = 'col'
chart.style = 10
chart.title = 'Sales Statistics'
chart.y_axis.title = 'Sales'
chart.x_axis.title = 'Product Category'
data = Reference(sheet, min_col=2, min_row=1, max_row=5, max_col=3)
cats = Reference(sheet, min_col=1, min_row=2, max_row=5)
chart.add_data(data, titles_from_data=True)
chart.set_categories(cats)
chart.shape = 4
sheet.add_chart(chart, 'A10')

wb.save('demo.xlsx')
```
