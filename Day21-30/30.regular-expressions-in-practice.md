## Applications of Regular Expressions

### Regular Expression Basics

When writing programs that process strings, we often need to find text matching certain rules. A **regular expression** is the tool used to describe those rules. In other words, regular expressions define **patterns** for matching, extracting, or replacing parts of strings.

If you have ever used wildcards like `*` and `?` when searching for files in Windows, regular expressions are similar in spirit, but much more powerful and more precise.

For example, suppose we have a block of text and want to extract mobile phone numbers and landline numbers from it. Doing this without regular expressions would be awkward. Today, almost every mainstream programming language supports regex. In Python, regex support comes from the standard-library `re` module.

Below is a brief summary of common regex symbols:

| Symbol | Meaning | Example | Notes |
| --- | --- | --- | --- |
| `.` | match any character | `b.t` | matches `bat`, `but`, etc. |
| `\w` | match letters, digits, underscore | `b\wt` | |
| `\s` | match whitespace | `love\syou` | |
| `\d` | match digits | `\d\d` | |
| `\b` | word boundary | `\bThe\b` | |
| `^` | start of string | `^The` | |
| `$` | end of string | `.exe$` | |
| `\W` | non-word character | `b\Wt` | |
| `\S` | non-whitespace | `love\Syou` | |
| `\D` | non-digit | `\d\D` | |
| `[]` | character class | `[aeiou]` | |
| `[^]` | negated character class | `[^aeiou]` | |
| `*` | 0 or more | `\w*` | |
| `+` | 1 or more | `\w+` | |
| `?` | 0 or 1 | `\w?` | |
| `{N}` | exactly N times | `\w{3}` | |
| `{M,}` | at least M times | `\w{3,}` | |
| `{M,N}` | between M and N times | `\w{3,6}` | |
| `\|` | alternation | `foo\|bar` | |
| `(exp)` | capture group | | |
| `(?:exp)` | non-capturing group | | |
| `(?=exp)` | positive lookahead | | |
| `(?<=exp)` | positive lookbehind | | |
| `(?!exp)` | negative lookahead | | |
| `(?<!exp)` | negative lookbehind | | |

> **Note**: If you want to match a special regex character literally, escape it with `\`. For example, use `\.` to match a period.

### Python Support for Regular Expressions

Python's `re` module provides core regex functions:

| Function | Description |
| --- | --- |
| `compile(pattern, flags=0)` | compile a regex and return a pattern object |
| `match(pattern, string, flags=0)` | match from the start of a string |
| `search(pattern, string, flags=0)` | search for the first occurrence |
| `split(pattern, string, maxsplit=0, flags=0)` | split a string with a regex separator |
| `sub(pattern, repl, string, count=0, flags=0)` | replace matched substrings |
| `fullmatch(pattern, string, flags=0)` | full-string match |
| `findall(pattern, string, flags=0)` | find all matches and return a list |
| `finditer(pattern, string, flags=0)` | find all matches and return an iterator |

If a regex will be reused many times, compiling it first with `compile` is usually a better choice.

### Example 1: Validate a Username and QQ Number

```python
"""
Requirement:
The username must consist of letters, digits, or underscores, and be 6 to 20 characters long.
The QQ number must be 5 to 12 digits and cannot start with 0.
"""
import re

username = input('Enter username: ')
qq = input('Enter QQ number: ')
m1 = re.match(r'^[0-9a-zA-Z_]{6,20}$', username)
if not m1:
    print('Please enter a valid username.')
m2 = re.fullmatch(r'[1-9]\d{4,11}', qq)
if not m2:
    print('Please enter a valid QQ number.')
if m1 and m2:
    print('Your input is valid!')
```

> **Tip**: The regexes above are written as raw strings, prefixed with `r`. This avoids the need to double-escape backslashes.

### Example 2: Extract Mobile Phone Numbers

```python
import re

pattern = re.compile(r'(?<=\D)1[34578]\d{9}(?=\D)')
sentence = '''Let me say this 8130123456789 times: my phone number is 13512346789,
not 15600998765, and certainly not 110 or 119. Wang Dachui's real number is 15600998765.'''

tels_list = re.findall(pattern, sentence)
for tel in tels_list:
    print(tel)
print('-------- separator --------')

for temp in pattern.finditer(sentence):
    print(temp.group())
print('-------- separator --------')

m = pattern.search(sentence)
while m:
    print(m.group())
    m = pattern.search(sentence, m.end())
```

### Example 3: Replace Offensive Content

```python
import re

sentence = 'Oh, shit! Are you stupid? Fuck you.'
purified = re.sub('fuck|shit', '*', sentence, flags=re.IGNORECASE)
print(purified)  # Oh, *! Are you stupid? * you.
```

### Example 4: Split a Long String

```python
import re

poem = 'Bright moonlight before my bed, I suspect it is frost on the ground. I raise my head to gaze at the moon, then lower it and think of home.'
sentences_list = re.split(r'[,.]', poem)
sentences_list = [sentence for sentence in sentences_list if sentence]
for sentence in sentences_list:
    print(sentence)
```

### Summary

Regular expressions are extremely powerful for matching and processing strings. Writing them well takes practice, but they are an essential tool for many real-world text-processing tasks.
