## Working with PDF Files in Python

PDF stands for **Portable Document Format**. Files of this type usually use the `.pdf` extension. In day-to-day development, the most common PDF-related tasks are:

- extracting text from PDFs
- creating PDFs from existing content

### Extracting Text from PDFs

In Python, we can use the third-party library `PyPDF2` to read PDF files.

Install it with:

```bash
pip install PyPDF2
```

`PyPDF2` cannot extract images, charts, or other media from a PDF, but it can extract text and return it as a Python string.

```python
import PyPDF2

reader = PyPDF2.PdfReader('test.pdf')
for page in reader.pages:
    print(page.extract_text())
```

Keep in mind that PDF text extraction is not perfect. Some PDFs, especially those containing Chinese text or scanned content, may not yield clean text.

You can also use a command-line tool such as `pdfminer.six`:

```bash
pip install pdfminer.six
pdf2text.py test.pdf
```

### Rotating Pages

With `PyPDF2`, each page is represented as a page object. We can rotate pages and then write the result into a new PDF.

```python
import PyPDF2

reader = PyPDF2.PdfReader('XGBoost.pdf')
writer = PyPDF2.PdfWriter()

for no, page in enumerate(reader.pages):
    if no % 2 == 0:
        new_page = page.rotate(-90)
    else:
        new_page = page.rotate(90)
    writer.add_page(new_page)

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

### Encrypting PDF Files

`PyPDF2.PdfWriter` can also encrypt PDF documents. This is especially useful when you need to apply the same password to multiple PDF files.

```python
import PyPDF2

reader = PyPDF2.PdfReader('XGBoost.pdf')
writer = PyPDF2.PdfWriter()

for page in reader.pages:
    writer.add_page(page)

writer.encrypt('foobared')

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

### Adding Watermarks in Batch

Page objects also support merging. This makes it easy to add watermarks to a PDF by overlaying a watermark page on top of each page of the original document.

```python
import PyPDF2

reader1 = PyPDF2.PdfReader('XGBoost.pdf')
reader2 = PyPDF2.PdfReader('watermark.pdf')
writer = PyPDF2.PdfWriter()
watermark_page = reader2.pages[0]

for page in reader1.pages:
    page.merge_page(watermark_page)
    writer.add_page(page)

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

You could also use different watermarks for odd and even pages if needed.

### Creating PDF Files

To create PDFs, we can use the third-party library `reportlab`.

Install it with:

```bash
pip install reportlab
```

Example:

```python
from reportlab.lib.pagesizes import A4
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont
from reportlab.pdfgen import canvas

pdf_canvas = canvas.Canvas('resources/demo.pdf', pagesize=A4)
width, height = A4

image = canvas.ImageReader('resources/guido.jpg')
pdf_canvas.drawImage(image, 20, height - 395, 250, 375)

pdf_canvas.showPage()

pdfmetrics.registerFont(TTFont('Font1', 'resources/fonts/Vera.ttf'))
pdfmetrics.registerFont(TTFont('Font2', 'resources/fonts/CustomChineseFont.ttf'))

pdf_canvas.setFont('Font2', 40)
pdf_canvas.setFillColorRGB(0.9, 0.5, 0.3, 1)
pdf_canvas.drawString(width // 2 - 120, height // 2, 'Hello, world in Chinese!')
pdf_canvas.setFont('Font1', 40)
pdf_canvas.setFillColorRGB(0, 1, 0, 0.5)
pdf_canvas.rotate(18)
pdf_canvas.drawString(250, 250, 'hello, world!')

pdf_canvas.save()
```

If this code is not fully clear yet, that is fine. When you actually need to generate PDF files in Python, the `reportlab` documentation is the right reference.
