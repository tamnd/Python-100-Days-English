## Working with Word and PowerPoint Files in Python

In daily work, many repetitive tasks can be automated with Python. For example, we can generate many Word or PowerPoint files from templates in batches.

Word is Microsoft's word-processing program, and modern Word files usually use the `.docx` extension. PowerPoint is Microsoft's presentation software, also known as slide software. In Python, we commonly use:

- `python-docx` for Word files
- `python-pptx` for PowerPoint files

### Working with Word Documents

Install `python-docx`:

```bash
pip install python-docx
```

According to the official documentation, we can generate a simple Word document like this:

```python
from docx import Document
from docx.shared import Cm, Pt

from docx.document import Document as Doc

document = Document()  # type: Doc
document.add_heading('Learn Python Happily', 0)
p = document.add_paragraph('Python is a very popular programming language. It is ')
run = p.add_run('simple')
run.bold = True
run.font.size = Pt(18)
p.add_run(' and ')
run = p.add_run('elegant')
run.font.size = Pt(18)
run.underline = True
p.add_run('.')

document.add_heading('Heading, level 1', level=1)
document.add_paragraph('Intense quote', style='Intense Quote')
document.add_paragraph('first item in unordered list', style='List Bullet')
document.add_paragraph('second item in unordered list', style='List Bullet')
document.add_paragraph('first item in ordered list', style='List Number')
document.add_paragraph('second item in ordered list', style='List Number')

document.add_picture('resources/guido.jpg', width=Cm(5.2))
document.add_section()

records = (
    ('Luo Hao', 'Male', '1995-5-5'),
    ('Sun Meili', 'Female', '1992-2-2')
)
table = document.add_table(rows=1, cols=3)
table.style = 'Dark List'
hdr_cells = table.rows[0].cells
hdr_cells[0].text = 'Name'
hdr_cells[1].text = 'Gender'
hdr_cells[2].text = 'Date of Birth'
for name, sex, birthday in records:
    row_cells = table.add_row().cells
    row_cells[0].text = name
    row_cells[1].text = sex
    row_cells[2].text = birthday

document.add_page_break()
document.save('demo.docx')
```

For an existing Word file, we can iterate through its paragraphs:

```python
from docx import Document
from docx.document import Document as Doc

doc = Document('resources/resignation_certificate.docx')  # type: Doc
for no, p in enumerate(doc.paragraphs):
    print(no, p.text)
```

This naturally leads to a useful automation scenario: prepare a Word template with placeholders, replace the placeholders with real information, and generate customized documents in batches.

```python
from docx import Document
from docx.document import Document as Doc

employees = [
    {
        'name': 'Luo Hao',
        'id': '100200198011280001',
        'sdate': 'March 1, 2008',
        'edate': 'February 29, 2012',
        'department': 'Product R&D',
        'position': 'Architect',
        'company': 'Chengdu Huawei Technologies Co., Ltd.'
    },
    {
        'name': 'Wang Dachui',
        'id': '510210199012125566',
        'sdate': 'January 1, 2019',
        'edate': 'April 30, 2021',
        'department': 'Product R&D',
        'position': 'Python Engineer',
        'company': 'Chengdu Gudao Technology Co., Ltd.'
    },
]

for emp_dict in employees:
    doc = Document('resources/resignation_template.docx')  # type: Doc
    for p in doc.paragraphs:
        if '{' not in p.text:
            continue
        for run in p.runs:
            if '{' not in run.text:
                continue
            start, end = run.text.find('{'), run.text.find('}')
            key, place_holder = run.text[start + 1:end], run.text[start:end + 1]
            run.text = run.text.replace(place_holder, emp_dict[key])
    doc.save(f'{emp_dict["name"]}_resignation_certificate.docx')
```

The key detail is that we replace text in runs rather than replacing the whole paragraph, so formatting is preserved.

### Generating PowerPoint Files

Install `python-pptx`:

```bash
pip install python-pptx
```

Here is a simple example based on the official documentation:

```python
from pptx import Presentation

pres = Presentation()

title_slide_layout = pres.slide_layouts[0]
slide = pres.slides.add_slide(title_slide_layout)
title = slide.shapes.title
subtitle = slide.placeholders[1]
title.text = "Welcome to Python"
subtitle.text = "Life is short, I use Python"

bullet_slide_layout = pres.slide_layouts[1]
slide = pres.slides.add_slide(bullet_slide_layout)
shapes = slide.shapes
title_shape = shapes.title
body_shape = shapes.placeholders[1]
title_shape.text = 'Introduction'
tf = body_shape.text_frame
tf.text = 'History of Python'
p = tf.add_paragraph()
p.text = 'X\'mas 1989'
p.level = 1
p = tf.add_paragraph()
p.text = 'Guido began to write the interpreter for Python.'
p.level = 2

pres.save('test.pptx')
```
