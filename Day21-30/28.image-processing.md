## Image Processing in Python

### Basic Concepts

1. **Color**. In computer systems, colors are usually represented using RGB or RGBA values. The `A` stands for alpha, which controls transparency.

   | Name | RGB |
   | --- | --- |
   | White | `(255, 255, 255)` |
   | Red | `(255, 0, 0)` |
   | Green | `(0, 255, 0)` |
   | Blue | `(0, 0, 255)` |
   | Gray | `(128, 128, 128)` |
   | Yellow | `(255, 255, 0)` |
   | Black | `(0, 0, 0)` |
   | Purple | `(128, 0, 128)` |

2. **Pixel**. The smallest unit in a digital image is a single colored square at a fixed position. These squares are called pixels, and together they determine the final appearance of the image.

### Processing Images with Pillow

Pillow is a fork of the well-known PIL library. It supports image compression, image transformation, and many other operations.

Install it with:

```bash
pip install pillow
```

The most important class in Pillow is `Image`.

#### 1. Read and Display an Image

```python
from PIL import Image

image = Image.open('guido.jpg')
print(image.format)
print(image.size)
print(image.mode)
image.show()
```

#### 2. Crop an Image

```python
image.crop((80, 20, 310, 360)).show()
```

#### 3. Generate a Thumbnail

```python
image.thumbnail((128, 128))
image.show()
```

#### 4. Resize and Paste

```python
luohao_image = Image.open('luohao.png')
guido_image = Image.open('guido.jpg')
guido_head = guido_image.crop((80, 20, 310, 360))
width, height = guido_head.size
luohao_image.paste(guido_head.resize((int(width / 1.5), int(height / 1.5))), (172, 40))
luohao_image.show()
```

#### 5. Rotate and Flip

```python
image = Image.open('guido.jpg')
image.rotate(45).show()
image.transpose(Image.FLIP_TOP_BOTTOM).show()
```

#### 6. Manipulate Pixels

```python
for x in range(80, 310):
    for y in range(20, 360):
        image.putpixel((x, y), (128, 128, 128))
image.show()
```

#### 7. Apply Filters

```python
from PIL import ImageFilter

image.filter(ImageFilter.CONTOUR).show()
```

### Drawing with Pillow

Pillow also provides the `ImageDraw` module. With an `ImageDraw` object, we can draw arcs, lines, rectangles, ellipses, polygons, and text on an image.

Example:

```python
import random

from PIL import Image, ImageDraw, ImageFont


def random_color():
    red = random.randint(0, 255)
    green = random.randint(0, 255)
    blue = random.randint(0, 255)
    return red, green, blue


width, height = 800, 600
image = Image.new(mode='RGB', size=(width, height), color=(255, 255, 255))
drawer = ImageDraw.Draw(image)
font = ImageFont.truetype('Kongxin.ttf', 32)
drawer.text((300, 50), 'Hello, world!', fill=(255, 0, 0), font=font)
drawer.line((0, 0, width, height), fill=(0, 0, 255), width=2)
drawer.line((width, 0, 0, height), fill=(0, 0, 255), width=2)
xy = width // 2 - 60, height // 2 - 60, width // 2 + 60, height // 2 + 60
drawer.rectangle(xy, outline=(255, 0, 0), width=2)
for i in range(4):
    left, top, right, bottom = 150 + i * 120, 220, 310 + i * 120, 380
    drawer.ellipse((left, top, right, bottom), outline=random_color(), width=8)
image.show()
image.save('result.png')
```

### Summary

Besides Pillow, Python also has stronger libraries such as OpenCV for image processing and computer vision. But for many everyday tasks such as resizing, cropping, filtering, and drawing, Pillow is already a very practical tool.
