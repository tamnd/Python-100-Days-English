## Object Serialization and Deserialization

### An Overview of JSON

We already know how to save text and binary data to files. But what if we want to save a list or dictionary? In Python, we can store program data using **JSON**.

JSON stands for **JavaScript Object Notation**. It originally came from JavaScript object literal syntax, but it is now widely used for cross-language, cross-platform data exchange. JSON became popular because it is compact and plain text, and every operating system and programming language can handle plain text.

Today, JSON has largely replaced XML as the de facto standard for data exchange between heterogeneous systems.

Example JSON:

```javascript
{
    name: "Luo Hao",
    age: 40,
    friends: ["Wang Dachui", "Bai Yuanfang"],
    cars: [
        {"brand": "BMW", "max_speed": 240},
        {"brand": "Benz", "max_speed": 280},
        {"brand": "Audi", "max_speed": 280}
    ]
}
```

JSON looks very much like a Python dictionary and supports nested structures.

The mapping between JSON and Python types is straightforward:

| JSON | Python |
| --- | --- |
| `object` | `dict` |
| `array` | `list` |
| `string` | `str` |
| `number` | `int` / `float` |
| `boolean` | `bool` |
| `null` | `None` |

### Reading and Writing JSON Data

In Python, use the `json` module. To convert a dictionary into a JSON string, use `json.dumps`.

```python
import json

my_dict = {
    'name': 'Luo Hao',
    'age': 40,
    'friends': ['Wang Dachui', 'Bai Yuanfang'],
    'cars': [
        {'brand': 'BMW', 'max_speed': 240},
        {'brand': 'Audi', 'max_speed': 280},
        {'brand': 'Benz', 'max_speed': 280}
    ]
}
print(json.dumps(my_dict))
```

To write JSON directly to a file, use `json.dump`:

```python
import json

my_dict = {
    'name': 'Luo Hao',
    'age': 40,
    'friends': ['Wang Dachui', 'Bai Yuanfang'],
    'cars': [
        {'brand': 'BMW', 'max_speed': 240},
        {'brand': 'Audi', 'max_speed': 280},
        {'brand': 'Benz', 'max_speed': 280}
    ]
}
with open('data.json', 'w') as file:
    json.dump(my_dict, file)
```

The four most important functions in the `json` module are:

- `dump`: serialize a Python object to JSON and write it to a file
- `dumps`: convert a Python object to a JSON string
- `load`: deserialize JSON from a file into a Python object
- `loads`: deserialize a JSON string into a Python object

**Serialization** means converting an object or data structure into a form that can be stored or transmitted. **Deserialization** means reconstructing the object from that stored representation.

To read the JSON file back into a dictionary:

```python
import json

with open('data.json', 'r') as file:
    my_dict = json.load(file)
    print(type(my_dict))
    print(my_dict)
```

### The Package Manager `pip`

The standard-library `json` module is convenient, but it is not always the fastest option. For better performance, you can use third-party libraries such as `ujson`.

Third-party libraries are packages not included in the standard library. Python's ecosystem is one of its strengths, and `pip` is the package manager used to install, update, and remove packages.

To check whether `pip` is installed:

```bash
pip --version
```

To install `ujson`:

```bash
pip install ujson
```

If the default package index is slow, you can switch to a mirror and then install:

```bash
pip config set global.index-url https://pypi.doubanio.com/simple
pip install ujson
```

Some useful `pip` commands:

- `pip search <name>`: search for packages
- `pip list`: list installed packages
- `pip install -U <name>`: upgrade a package
- `pip uninstall <name>`: uninstall a package

### Fetching Data from Network APIs

If we want our own programs to display data such as weather, traffic, or flight information, we usually need to obtain that data from a network service. Most modern APIs deliver JSON over HTTP or HTTPS.

Python can send HTTP requests to an API URL, receive an HTTP response, and then parse the JSON response body into Python objects.

We recommend the third-party library `requests` for this:

```bash
pip install requests
```

Example: fetch domestic news using an API and print the title and link.

```python
import requests

resp = requests.get('http://api.tianapi.com/guonei/?key=APIKey&num=10')
if resp.status_code == 200:
    data_model = resp.json()
    for news in data_model['newslist']:
        print(news['title'])
        print(news['url'])
        print('-' * 60)
```

If the request succeeds, `resp.status_code` will usually be `200` or another `2xx` code. The `json()` method of the response object converts the JSON body directly into a Python dictionary.

> **Tip**: Replace `APIKey` in the example above with your own API key from the service provider.

### Summary

In Python, serialization and deserialization can be handled with the `json` module, and also with modules like `pickle` or `shelve`. However, JSON is especially important because it is the common format used by both clients and servers when working with web APIs. Handling JSON is a core skill for modern programmers.
