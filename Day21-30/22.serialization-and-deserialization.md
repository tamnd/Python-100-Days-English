## Object Serialization and Deserialization

### An Overview of JSON

From the previous lesson, we already know how to save text data and binary data into files. But there is another question here: if we want to save the data in a list or a dictionary into a file, what should we do? In Python, we can save program data in **JSON** format. JSON is short for "JavaScript Object Notation". It originally started as the literal syntax for creating objects in JavaScript, but it is now widely used for cross-language and cross-platform data exchange. The reason JSON became so popular is very simple: it is compact and it is plain text, and any operating system and programming language can handle plain text. This is the prerequisite for **cross-language, cross-platform data exchange**. At present, JSON has basically replaced XML, the eXtensible Markup Language, as the **de facto standard for data exchange between heterogeneous systems**. You can find more information about JSON on [the official JSON website](https://www.json.org/json-en.html), which also lists tools and third-party libraries for handling JSON in many languages.

```javascript
{
    name: "Luo Hao",
    age: 40,
    friends: ["Wang Dachui", "Bai Yuanfang"],
    cars: [
        {"brand": "BMW", "max_speed": 240},
        {"brand": "Benz", "max_speed": 280},
        {"brand": "Audi", "max_speed": 280}
    ]
}
```

The example above is a simple piece of JSON data. You may have already noticed that it is very similar to a Python dictionary and also supports nested structures, just like the values in a Python dictionary can themselves be dictionaries. We can try entering the following code into a browser console. In Chrome, for example, you can open the console through the "Developer Tools" submenu. The browser console provides an interactive environment for running JavaScript code, similar to Python's interactive environment. The following code creates a JavaScript object and assigns it to a variable named `obj`.

```javascript
let obj = {
    name: "Luo Hao",
    age: 40,
    friends: ["Wang Dachui", "Bai Yuanfang"],
    cars: [
        {"brand": "BMW", "max_speed": 240},
        {"brand": "Benz", "max_speed": 280},
        {"brand": "Audi", "max_speed": 280}
    ]
}
```

The `obj` above is a JavaScript object. We can retrieve the value corresponding to `name` through either `obj.name` or `obj["name"]`, as shown below. You can see that `obj["name"]` works exactly like indexing into a Python dictionary by key. Python also provides a module named `json` that supports converting between dictionaries and JSON in both directions.

### Reading and Writing JSON Data

In Python, if we want to turn a dictionary into JSON format, in other words, make it exist as a string, we can use the `dumps` function from the `json` module, as shown below.

```python
import json

my_dict = {
    'name': 'Luo Hao',
    'age': 40,
    'friends': ['Wang Dachui', 'Bai Yuanfang'],
    'cars': [
        {'brand': 'BMW', 'max_speed': 240},
        {'brand': 'Audi', 'max_speed': 280},
        {'brand': 'Benz', 'max_speed': 280}
    ]
}
print(json.dumps(my_dict))
```

When the code above runs, the output is shown below. Notice that the Chinese characters in the original data are displayed using Unicode escapes.

```json
{"name": "\u9a86\u660a", "age": 40, "friends": ["\u738b\u5927\u9524", "\u767d\u5143\u82b3"], "cars": [{"brand": "BMW", "max_speed": 240}, {"brand": "Audi", "max_speed": 280}, {"brand": "Benz", "max_speed": 280}]}
```

If we want to turn a dictionary into JSON format and write it into a text file, we only need to replace `dumps` with `dump` and pass in a file object, as shown below.

```python
import json

my_dict = {
    'name': 'Luo Hao',
    'age': 40,
    'friends': ['Wang Dachui', 'Bai Yuanfang'],
    'cars': [
        {'brand': 'BMW', 'max_speed': 240},
        {'brand': 'Audi', 'max_speed': 280},
        {'brand': 'Benz', 'max_speed': 280}
    ]
}
with open('data.json', 'w') as file:
    json.dump(my_dict, file)
```

After running the code above, a file named `data.json` is created, and its contents are the same as the output shown earlier.

There are four especially important functions in the `json` module:

- `dump`: serialize a Python object to a file in JSON format
- `dumps`: turn a Python object into a JSON-formatted string
- `load`: deserialize JSON data from a file into an object
- `loads`: deserialize the contents of a string into a Python object

Two concepts appear here: serialization and deserialization. Wikipedia explains them this way: serialization is the process of converting a data structure or object state into a form that can be stored or transmitted, so that it can later be restored to its original state, and deserialization is the reverse process of extracting a data structure from that stored representation.

We can use the following code to read the `data.json` file created above and restore the JSON data into a Python dictionary.

```python
import json

with open('data.json', 'r') as file:
    my_dict = json.load(file)
    print(type(my_dict))
    print(my_dict)
```

### The Package Management Tool `pip`

The `json` module in Python's standard library is not especially ideal in terms of performance during serialization and deserialization. To solve that problem, we can use a third-party library such as `ujson` to replace `json`. A third-party library is a Python module that is neither developed internally inside your own company nor provided by the official standard library. Such modules are typically developed by other companies, organizations, or individuals, which is why they are called third-party libraries. Although Python's standard library already provides many modules that make development convenient, a powerful language also depends on a thriving ecosystem.

When you installed the Python interpreter earlier, the option to install `pip` was checked by default. You can verify whether `pip` is available by running `pip --version` in a terminal or command prompt. Pip is Python's package management tool. Through pip, we can search for, install, uninstall, and update third-party libraries or tools. For example, if we want to install `ujson` as a replacement for the `json` module, we can run the following command.

```bash
pip install ujson
```

By default, pip accesses `https://pypi.org/simple/` to retrieve data about third-party packages. For users in mainland China, access to that site is often not ideal, so users there can use mirrors provided by Douban or Tsinghua University instead, and then install packages as usual.

```bash
pip config set global.index-url https://pypi.doubanio.com/simple
pip install ujson
```

We can use `pip search` to look for packages by name, `pip list` to see packages that are already installed, `pip install -U` or `pip install --upgrade` to update a package, and `pip uninstall` to remove one.

### Getting Data Through Network APIs

If we want to display information such as weather, traffic conditions, or flight status in our own programs, we usually cannot provide that data ourselves, so we need to use network data services instead. At present, the vast majority of network data services, also called network APIs, provide JSON data over HTTP or HTTPS. A Python program can send an HTTP request to a specified URL, the so-called network API, and if the request succeeds it will return an HTTP response whose message body contains the JSON data we need. For background on HTTP, you can read Ruan Yifeng's article *Introduction to the HTTP Protocol*.

There are many websites in China that provide network API services, such as Juhe Data and Baidu AI Cloud. These sites offer both free and paid data interfaces. Outside China, the site [{API}Search](http://apis.io/) provides similar services. If you are interested, you can explore them on your own. The following example demonstrates how to use the third-party library [`requests`](http://docs.python-requests.org/zh_CN/latest/) to access a network API, fetch domestic news, and display the news titles and links. In this example, we use the domestic-news API provided by Tian API. Its identity credential, the API key, must be requested by registering on the website. After registering, an API key is assigned automatically, but to access the API you still need to verify your email or phone and then apply for the specific interface you want to use.

<img src="res/20210820151134.png" alt="image-20210820151134034" width="100%">

When using Python to access network resources through a URL, we recommend the third-party library `requests`. It is simple and powerful, but it needs to be installed separately.

```bash
pip install requests
```

Fetch domestic news and display the title and link.

```python
import requests

resp = requests.get('http://api.tianapi.com/guonei/?key=APIKey&num=10')
if resp.status_code == 200:
    data_model = resp.json()
    for news in data_model['newslist']:
        print(news['title'])
        print(news['url'])
        print('-' * 60)
```

The code above sends a request to Tian API's domestic-news interface through the `get` function in the `requests` module. If no problem occurs during the request, `get` returns a `Response` object. The `status_code` attribute of that object represents the HTTP response status code. If you are not familiar with HTTP yet, that is fine. You only need to watch its value. If the value is `200` or another `2xx` code, then the request succeeded. The `json()` method of the `Response` object can turn the returned JSON data directly into a Python dictionary, which is very convenient. A sample of the JSON returned by the Tian API domestic-news endpoint is shown below.

> **Tip**: Replace `APIKey` in the code above with the API key you applied for from the Tian API website. The site also provides many other interesting APIs, such as garbage classification and dream interpretation. You can call those interfaces by following the same pattern as above. Each API has its own documentation explaining how to use it in detail.

### Summary

In Python, besides the `json` module, we can also use modules such as `pickle` and `shelve` to perform serialization and deserialization. However, those two modules use Python-specific serialization protocols, so the data they produce can only be recognized by Python. Handling JSON data is clearly a skill every programmer must master, because whether you are calling a network API or providing one for others, you need to understand how to work with JSON.
