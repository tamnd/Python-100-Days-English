## Reading and Writing CSV Files in Python

### What Is a CSV File?

CSV stands for **Comma-Separated Values**. It is a simple and widely used file format for importing and exporting data between applications such as databases and spreadsheets, and for exchanging data between heterogeneous systems.

CSV files have several key characteristics:

1. They are plain text, encoded with some character set such as ASCII, Unicode, or GB2312.
2. They are made up of records, typically one per line.
3. Each record is split into fields by a delimiter such as a comma, semicolon, or tab.
4. Each record follows the same field order.

Because CSV is plain text, it can be handled on any operating system and in any programming language. It can also be opened with a text editor or spreadsheet tools like Excel.

### Writing Data to a CSV File

Suppose we want to save the scores of five students in three courses into a CSV file. We can use Python's standard-library `csv` module. The `writer` function returns a `csvwriter` object, and its `writerow` or `writerows` methods write records into the file.

```python
import csv
import random

with open('scores.csv', 'w') as file:
    writer = csv.writer(file)
    writer.writerow(['Name', 'Chinese', 'Math', 'English'])
    names = ['Guan Yu', 'Zhang Fei', 'Zhao Yun', 'Ma Chao', 'Huang Zhong']
    for name in names:
        scores = [random.randrange(50, 101) for _ in range(3)]
        scores.insert(0, name)
        writer.writerow(scores)
```

The resulting file might look like this:

```text
Name,Chinese,Math,English
Guan Yu,98,86,61
Zhang Fei,86,58,80
Zhao Yun,95,73,70
Ma Chao,83,97,55
Huang Zhong,61,54,87
```

The `writer` function also accepts additional parameters such as:

- `dialect`: CSV dialect, default is `excel`
- `delimiter`: field separator, default is a comma
- `quotechar`: character used to quote values, default is `"`
- `quoting`: quoting strategy

For example:

```python
writer = csv.writer(file, delimiter='|', quoting=csv.QUOTE_ALL)
```

This would produce output like:

```text
"Name"|"Chinese"|"Math"|"English"
"Guan Yu"|"88"|"64"|"65"
"Zhang Fei"|"76"|"93"|"79"
"Zhao Yun"|"78"|"55"|"76"
"Ma Chao"|"72"|"77"|"68"
"Huang Zhong"|"70"|"72"|"51"
```

### Reading Data from a CSV File

To read the CSV file we just created, use `csv.reader`. It returns a `csvreader` object, which is an iterator.

```python
import csv

with open('scores.csv', 'r') as file:
    reader = csv.reader(file, delimiter='|')
    for data_list in reader:
        print(reader.line_num, end='\t')
        for elem in data_list:
            print(elem, end='\t')
        print()
```

> **Note**: In a `for` loop, each iteration returns one row as a list containing all fields in that row.

### Summary

If you later use Python for data analysis, you will likely work with the third-party library `pandas`. It provides `read_csv` and `to_csv`, which are much more powerful than the low-level `csvreader` and `csvwriter` tools in the standard library. `read_csv` produces a `DataFrame`, one of the most important data structures in `pandas`.
