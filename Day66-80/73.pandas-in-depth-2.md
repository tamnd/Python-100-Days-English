## pandas from the Ground Up, Part 2

### Reading and Writing Data

pandas supports many file formats, including:

- CSV
- Excel
- JSON
- SQL query results

Examples:

```python
df = pd.read_csv('data.csv')
df = pd.read_excel('data.xlsx')
df.to_csv('output.csv', index=False)
```

### Indexing and Filtering

Filter rows:

```python
df[df['age'] > 18]
```

Select columns:

```python
df[['name', 'age']]
```

Boolean logic:

```python
df[(df['age'] > 18) & (df['score'] >= 90)]
```

This lesson mainly focuses on loading structured data and selecting the part you want to analyze.
