## pandas from the Ground Up, Part 3

### Data Cleaning

Real-world data is messy. pandas provides tools to handle:

- missing values
- duplicate rows
- incorrect data types
- invalid values

Common operations:

```python
df.isna()
df.dropna()
df.fillna(0)
df.drop_duplicates()
df.astype({'age': 'int64'})
```

### Value Transformation

Useful transformations include:

- string cleanup
- categorical conversion
- date parsing
- custom mapping

Examples:

```python
df['date'] = pd.to_datetime(df['date'])
df['gender'] = df['gender'].map({'M': 'Male', 'F': 'Female'})
```

Cleaning is often the most time-consuming part of analysis, but it is also one of the most important.
