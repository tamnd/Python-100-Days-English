## NumPy in Practice, Part 3

### Array Operations

One of NumPy’s biggest advantages is vectorization: operations automatically apply element by element without explicit Python loops.

### Array and Scalar Operations

```python
array1 = np.arange(1, 10)
print(array1 + 10)
print(array1 * 10)
```

Comparison operations also work elementwise:

```python
print(array1 > 5)
print(array1 % 2 == 0)
```

### Array and Array Operations

Arrays of the same shape can be combined:

```python
array2 = np.array([1, 1, 1, 2, 2, 2, 3, 3, 3])
print(array1 + array2)
print(array1 * array2)
print(array1 ** array2)
```

### Universal Functions

NumPy provides many ufuncs that act on every element:

- `sqrt`
- `log`
- `log2`
- `exp`
- `sin`
- `cos`
- `abs`

These functions are one reason NumPy is much faster and cleaner than pure Python loops for numerical work.
