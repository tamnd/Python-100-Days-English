## Environment Setup

If you want to start working with Python for data analysis quickly, the simplest option is to install Anaconda and use its bundled notebook tools. This avoids manually installing Python and many scientific dependencies one by one.

### Anaconda

Anaconda includes:

- Python
- a package/environment manager named `conda`
- notebook tools such as JupyterLab
- many common data-science packages

For beginners, this is usually the easiest setup path.

### Common `conda` Commands

Version and help:

- `conda -V`
- `conda --help`

Environment management:

- `conda env list`
- `conda create --name venv`
- `conda create --name venv python=3.7`
- `conda create --name venv python=3.7 numpy pandas`
- `conda activate venv`
- `conda deactivate`
- `conda remove --name venv --all`

Package management:

- `conda list`
- `conda search matplotlib`
- `conda install matplotlib`
- `conda update matplotlib`
- `conda remove matplotlib`

### JupyterLab

JupyterLab is a browser-based environment for:

- writing code
- running code interactively
- mixing code with Markdown notes
- displaying plots and outputs inline

Install with `pip` if you are not using Anaconda:

```bash
pip install jupyterlab
pip install numpy pandas matplotlib
jupyter lab
```

JupyterLab is especially useful for exploratory data work and teaching because code, notes, and results all live in one place.
