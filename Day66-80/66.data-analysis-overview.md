## Introduction to Data Analysis

Modern industries depend more and more on information technology, which means data volumes keep growing. The hard part is not collecting data, but extracting useful information from it. Data analysis is the process of turning raw data into information that supports decisions.

### What Data Analysis Means

Data analysis generally involves:

1. collecting data
2. cleaning and organizing it
3. exploring and summarizing it
4. visualizing and explaining it
5. supporting decisions with the results

In practice, data analysis sits inside the broader field of data science.

### What a Data Analyst Does

In many companies, "data analyst" can refer to several related roles:

- business data analyst
- BI engineer
- data operations analyst
- commercial analyst
- data product manager
- data-mining or algorithm roles

The business-facing analyst role usually includes:

1. producing reports
2. building and improving metrics
3. monitoring anomalies and fluctuations
4. explaining problems in business terms
5. finding growth opportunities

### Skill Set

A practical data-analysis skill set includes:

1. computer tools: Python, SQL, databases, notebooks
2. math and statistics
3. basic machine learning awareness
4. business understanding
5. communication and reporting ability

For beginners, tools are usually easier to learn than data thinking. Business context, statistical reasoning, and analytical framing take longer to build.

### General Workflow

Typical analysis workflow:

1. define the goal and business question
2. acquire data
3. clean and preprocess data
4. aggregate and reshape data
5. visualize and report
6. explain patterns and propose actions

Broader data-mining workflow:

1. define the target
2. prepare data
3. transform data
4. build models
5. evaluate models
6. deploy or operationalize results

### Important Python Libraries

Core "three great tools":

1. `NumPy`: numerical arrays and matrix-style computation
2. `pandas`: labeled tables and time series
3. `matplotlib`: plotting and charting

Other useful libraries:

- `SciPy`
- `Polars`
- machine-learning libraries introduced later in the course
