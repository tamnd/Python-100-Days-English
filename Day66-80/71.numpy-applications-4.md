## NumPy in Practice, Part 4

### Vectors

A vector has magnitude and direction. In data analysis and machine learning, vectors are often represented as NumPy arrays.

Common vector operations:

- addition and subtraction
- scalar multiplication
- dot product
- norm

Example:

```python
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])
print(v1 + v2)
print(np.dot(v1, v2))
print(np.linalg.norm(v1))
```

### Matrices

Matrices can also be represented with two-dimensional `ndarray` objects.

Common matrix operations:

- transpose
- reshape
- matrix multiplication
- inverse
- determinant

Examples:

```python
m = np.array([[1, 2], [3, 4]])
print(m.T)
print(np.linalg.det(m))
print(np.linalg.inv(m))
```

### Linear Algebra Utilities

NumPy and `numpy.linalg` provide many tools for:

- solving linear systems
- eigenvalues and eigenvectors
- decomposition-based operations

These ideas become important later in machine learning and numerical modeling.
