## Data Visualization, Part 1

Data visualization helps transform analysis results into something people can quickly understand.

Common chart types:

- line chart
- bar chart
- pie chart
- scatter plot
- histogram

With `matplotlib`, a simple plot looks like:

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [2, 4, 6])
plt.title('Demo')
plt.show()
```

Key concepts:

- figure
- axes
- labels
- legend
- color and style

Good visualization is not just about drawing charts. It is about choosing the right chart for the question being asked.
