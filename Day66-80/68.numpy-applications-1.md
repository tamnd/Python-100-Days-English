## NumPy in Practice, Part 1

NumPy is the core numerical-computing library in Python. Its central data type is `ndarray`, which supports fast one-dimensional, two-dimensional, and higher-dimensional arrays.

Compared with Python lists, NumPy arrays are:

- faster
- more memory-efficient
- better for vectorized math

### Setup

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
```

### Creating Arrays

Common creation methods:

1. `np.array`

```python
array1 = np.array([1, 2, 3, 4, 5])
array2 = np.array([[1, 2, 3], [4, 5, 6]])
```

2. `np.arange`

```python
array3 = np.arange(0, 20, 2)
```

3. `np.linspace`

```python
array4 = np.linspace(-1, 1, 11)
```

4. random arrays

```python
np.random.randint(1, 10, 5)
np.random.rand(3, 4)
```

5. arrays filled with fixed values

```python
np.zeros((2, 3))
np.ones((2, 3))
np.full((2, 3), 7)
```

6. identity matrices

```python
np.eye(3)
```

### Basic Array Properties

Useful properties:

- `shape`
- `ndim`
- `size`
- `dtype`

Example:

```python
array = np.array([[1, 2, 3], [4, 5, 6]])
print(array.shape)
print(array.ndim)
print(array.size)
print(array.dtype)
```

### Indexing and Slicing

NumPy supports:

- scalar indexing
- slicing
- multi-axis indexing
- boolean indexing
- fancy indexing

Examples:

```python
array = np.arange(10)
array[2]
array[2:6]
array[array % 2 == 0]
```

These operations make NumPy the foundation for the rest of the data-analysis stack.
