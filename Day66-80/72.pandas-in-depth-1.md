## pandas from the Ground Up, Part 1

pandas is the most important tabular-data library in Python. Its two core structures are:

- `Series`: one-dimensional labeled data
- `DataFrame`: two-dimensional labeled table

### Creating `Series`

```python
import pandas as pd

s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
```

Useful attributes:

- `index`
- `values`
- `dtype`

### Creating `DataFrame`

```python
df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cindy'],
    'age': [18, 20, 19]
})
```

Common inspection methods:

- `head()`
- `tail()`
- `info()`
- `describe()`

### Basic Selection

Label-based:

```python
df.loc[0]
df.loc[:, 'name']
```

Position-based:

```python
df.iloc[0]
df.iloc[:, 0]
```

This structure makes pandas much more suitable than NumPy for heterogeneous table-like data.
