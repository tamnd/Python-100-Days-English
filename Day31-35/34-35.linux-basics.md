# Getting Comfortable with Linux

> **Note**: The Linux commands in this lesson are explained using CentOS as the reference distribution. Different distributions may vary slightly, but the differences are usually small.

## A Brief History of Operating Systems

A computer system with hardware only and no software is often called a "bare machine". To make a computer practically useful, we need software that manages hardware resources. The most important piece of system software is the **operating system**.

An operating system manages hardware and software resources, handles task scheduling and allocation, and provides an environment and interfaces for users and applications.

### Early Stages

- **No operating system**: users loaded programs manually using paper tape or cards; the CPU often waited for manual actions.
- **Batch systems**: jobs were processed automatically in batches, increasing hardware utilization.
- **Time-sharing systems**: CPU time was divided into time slices and shared among users.
- **Real-time systems**: designed to respond to external events within strict timing constraints.

### General-Purpose Operating Systems

Some major milestones:

1. 1960s: IBM System/360 had a unified operating system, OS/360.
2. 1965: Bell Labs, GE, and MIT started work on MULTICS.
3. 1969: Ken Thompson developed Unics on a PDP-7.
4. 1970-1971: Ken Thompson and Dennis Ritchie rewrote it and renamed it Unix.
5. 1972-1973: Dennis Ritchie created C and Unix was rewritten in C.
6. 1974: Unix version 5 was almost entirely implemented in C.
7. 1979: AT&T privatized Unix.
8. 1987: Andrew S. Tanenbaum created Minix for educational purposes.
9. 1991: Linus Torvalds began building what became the Linux kernel.

## Linux Overview

Linux is a general-purpose operating system. An operating system is responsible for scheduling tasks, allocating memory, and handling I/O for hardware devices.

Linux consists of:

- the **kernel**
- system programs such as drivers, libraries, shells, and services

The Linux kernel was created by Linus Torvalds and released in 1991. Linux as an operating system is the result of collaboration by developers around the world.

### Advantages of Linux

1. It is a general-purpose operating system and not tied to one hardware platform.
2. It is written in C and is highly portable.
3. It supports multi-user and multi-tasking operation.
4. It offers many practical tools and strong networking support.
5. It is stable, secure, and developer-friendly.

## Basic Commands

Most Linux commands follow this pattern:

```bash
command [options] [target]
```

Examples:

1. View login information: `w`, `who`, `last`, `lastb`
2. Check your current shell: `ps`
3. Learn about commands: `whatis`, `which`, `whereis`
4. Clear the screen: `clear`
5. View help: `man`, `info`, `--help`, `apropos`
6. Check system and hostname: `uname`, `hostname`
7. View date and calendar: `date`, `cal`
8. Reboot and shut down: `reboot`, `shutdown`
9. Exit the current shell: `exit`, `logout`
10. View command history: `history`

## Common Utilities

### File and Directory Operations

1. Create/remove directories: `mkdir`, `rmdir`
2. Create/remove files: `touch`, `rm`
3. Change and print the current directory: `cd`, `pwd`
4. List directory contents: `ls`
5. View file contents: `cat`, `tac`, `head`, `tail`, `more`, `less`, `rev`, `od`
6. Copy and move files: `cp`, `mv`
7. Rename files: `rename`
8. Find files and search text: `find`, `grep`
9. Create links and inspect them: `ln`, `readlink`
10. Compress and decompress: `gzip`, `gunzip`, `xz`
11. Archive and extract: `tar`
12. Convert standard input into command-line arguments: `xargs`
13. Show filename or directory name: `basename`, `dirname`
14. Other useful tools:
   - `sort`
   - `uniq`
   - `tr`
   - `cut`
   - `paste`
   - `split`
   - `file`
   - `wc`
   - `iconv`

### Pipes and Redirection

1. Pipes: `|`

   Example: count files in the current directory tree:

   ```bash
   find ./ | wc -l
   ```

   Example: number the output of `ls`:

   ```bash
   ls | cat -n
   ```

2. Output and error redirection:

- `>`
- `>>`
- `2>`

These let you redirect standard output and standard error into files.

## Summary

Linux is an essential environment for modern development. Beyond just knowing the operating system conceptually, being comfortable with command-line tools, file operations, process inspection, pipes, and redirection is a core practical skill.
