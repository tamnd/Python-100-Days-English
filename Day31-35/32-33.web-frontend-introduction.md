## Introduction to Web Frontend

> **Note**: Some of the illustrations in this lesson come from Jon Duckett's *HTML and CSS: Design and Build Websites*, which is an excellent beginner-friendly frontend book.

HTML stands for **HyperText Markup Language**. It is the language used to describe webpages. The text, buttons, images, and videos you see in a browser are rendered from HTML.

### A Brief History of HTML

1. October 1991: an informal CERN document introduced 18 HTML tags.
2. November 1995: HTML 2.0 was published as RFC 1866.
3. January 1997: HTML 3.2 became a W3C recommendation.
4. December 1997: HTML 4.0 became a W3C recommendation.
5. December 1999: HTML 4.01 became a W3C recommendation.
6. January 2008: HTML5 was published as a W3C working draft.
7. May 2011: HTML5 advanced to Last Call.
8. December 2012: HTML5 became a Candidate Recommendation.
9. October 2014: HTML5 became an official W3C recommendation.

#### New Features in HTML5

1. Native multimedia support: `audio`, `video`
2. Programmable graphics: `canvas`
3. Semantic tags: `article`, `aside`, `details`, `figure`, `footer`, `header`, `nav`, `section`, `summary`
4. New form controls: calendars, email fields, search boxes, sliders, etc.
5. Better offline storage support: `localStorage`, `sessionStorage`
6. Support for geolocation, drag-and-drop, WebSocket, background tasks, and more

### Frontend Frameworks

#### A Progressive Framework: Vue.js

For frontend rendering in a frontend-backend separated architecture, Vue.js is a strong option.

##### Quick Start

1. Include Vue from a CDN:

   ```html
   <script src="https://cdn.jsdelivr.net/npm/vue"></script>
   ```

2. Data binding:

   ```html
   <div id="app">
       <h1>{{ product }} inventory information</h1>
   </div>

   <script src="https://cdn.jsdelivr.net/npm/vue"></script>
   <script>
       const app = new Vue({
           el: '#app',
           data: {
               product: 'iPhone X'
           }
       });
   </script>
   ```

3. Conditions and loops:

   ```html
   <div id="app">
       <h1>Inventory Information</h1>
       <hr>
       <ul>
           <li v-for="product in products">
               {{ product.name }} - {{ product.quantity }}
               <span v-if="product.quantity === 0">
                   Sold out
               </span>
           </li>
       </ul>
   </div>
   ```

4. Computed properties:

   ```html
   <h2>Total inventory: {{ totalQuantity }} items</h2>
   ```

5. Event handling:

   ```html
   <button @click="product.quantity += 1">
       Increase inventory
   </button>
   ```

Vue continues far beyond these basics, but this is enough to get started.
