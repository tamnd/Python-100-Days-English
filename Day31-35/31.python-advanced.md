- The `collections` module

  Common utility classes:

  - `namedtuple`: a named tuple, essentially a class factory that accepts a type name and an attribute list to create a class.
  - `deque`: a double-ended queue and an alternative implementation of a list. Python lists are array-based, while `deque` is backed by a doubly linked list, so it has better asymptotic performance, `O(1)`, when adding and removing elements at both ends.
  - `Counter`: a subclass of `dict` in which keys are elements and values are their counts. Its `most_common()` method helps us find the most frequent elements.
  - `OrderedDict`: a subclass of `dict` that records insertion order. It behaves partly like a dictionary and partly like a linked structure.
  - `defaultdict`: similar to a dictionary, but it can obtain default values through a factory function. Compared with `setdefault()`, this is usually more efficient.

  ```python
  """
  Find the most common elements in a sequence.
  """
  from collections import Counter

  words = [
      'look', 'into', 'my', 'eyes', 'look', 'into', 'my', 'eyes',
      'the', 'eyes', 'the', 'eyes', 'the', 'eyes', 'not', 'around',
      'the', 'eyes', "don't", 'look', 'around', 'the', 'eyes',
      'look', 'into', 'my', 'eyes', "you're", 'under'
  ]
  counter = Counter(words)
  print(counter.most_common(3))
  ```

### Data Structures and Algorithms

- An algorithm is the method and sequence of steps used to solve a problem.

- To judge the quality of an algorithm, we usually look at asymptotic time complexity and asymptotic space complexity.

- Big-O notation for asymptotic time complexity:
  - `O(c)` - constant time complexity - Bloom filters / hash storage
  - `O(log_2n)` - logarithmic time complexity - binary search
  - `O(n)` - linear time complexity - sequential search / counting sort
  - `O(n * log_2n)` - log-linear time complexity - advanced sorting algorithms such as merge sort and quicksort
  - `O(n^2)` - quadratic time complexity - simple sorting algorithms such as selection sort, insertion sort, and bubble sort
  - `O(n^3)` - cubic time complexity - Floyd's algorithm / matrix multiplication
  - `O(2^n)` - exponential time complexity - the Tower of Hanoi
  - `O(n!)` - factorial time complexity - the traveling salesman problem / NPC-style exhaustive search

- Sorting algorithms, selection sort, bubble sort, and merge sort, together with searching algorithms, sequential search and binary search

  ```python
  def select_sort(items, comp=lambda x, y: x < y):
      """Simple selection sort"""
      items = items[:]
      for i in range(len(items) - 1):
          min_index = i
          for j in range(i + 1, len(items)):
              if comp(items[j], items[min_index]):
                  min_index = j
          items[i], items[min_index] = items[min_index], items[i]
      return items
  ```

  ```python
  def bubble_sort(items, comp=lambda x, y: x > y):
      """Bubble sort"""
      items = items[:]
      for i in range(len(items) - 1):
          swapped = False
          for j in range(len(items) - 1 - i):
              if comp(items[j], items[j + 1]):
                  items[j], items[j + 1] = items[j + 1], items[j]
                  swapped = True
          if not swapped:
              break
      return items
  ```

  ```python
  def bubble_sort(items, comp=lambda x, y: x > y):
      """Cocktail sort (an upgraded bubble sort)"""
      items = items[:]
      for i in range(len(items) - 1):
          swapped = False
          for j in range(len(items) - 1 - i):
              if comp(items[j], items[j + 1]):
                  items[j], items[j + 1] = items[j + 1], items[j]
                  swapped = True
          if swapped:
              swapped = False
              for j in range(len(items) - 2 - i, i, -1):
                  if comp(items[j - 1], items[j]):
                      items[j], items[j - 1] = items[j - 1], items[j]
                      swapped = True
          if not swapped:
              break
      return items
  ```

  ```python
  def merge(items1, items2, comp=lambda x, y: x < y):
      """Merge two sorted lists into one sorted list"""
      items = []
      index1, index2 = 0, 0
      while index1 < len(items1) and index2 < len(items2):
          if comp(items1[index1], items2[index2]):
              items.append(items1[index1])
              index1 += 1
          else:
              items.append(items2[index2])
              index2 += 1
      items += items1[index1:]
      items += items2[index2:]
      return items


  def merge_sort(items, comp=lambda x, y: x < y):
      return _merge_sort(list(items), comp)


  def _merge_sort(items, comp):
      """Merge sort"""
      if len(items) < 2:
          return items
      mid = len(items) // 2
      left = _merge_sort(items[:mid], comp)
      right = _merge_sort(items[mid:], comp)
      return merge(left, right, comp)
  ```

  ```python
  def seq_search(items, key):
      """Sequential search"""
      for index, item in enumerate(items):
          if item == key:
              return index
      return -1
  ```

  ```python
  def bin_search(items, key):
      """Binary search"""
      start, end = 0, len(items) - 1
      while start <= end:
          mid = (start + end) // 2
          if key > items[mid]:
              start = mid + 1
          elif key < items[mid]:
              end = mid - 1
          else:
              return mid
      return -1
  ```

- Common algorithmic strategies:

  - Brute force, also called exhaustive search. Verify every possibility until the correct answer is found.
  - Greedy methods. When solving a problem, always make the choice that looks best at the current moment. They do not guarantee an optimal solution, but they can often find a satisfactory one quickly.
  - Divide and conquer. Break a complex problem into two or more identical or similar subproblems, continue splitting them until they can be solved directly, and then combine their solutions to obtain the solution to the original problem.
  - Backtracking. Also called trial-and-error search. Proceed forward according to the selection conditions, but when a choice turns out not to be good enough or cannot reach the goal, step back and choose again.
  - Dynamic programming. The core idea is also to break the problem into subproblems, solve and store those subproblem results first, and avoid a large amount of repeated computation.

  Example of brute force: the hundred chickens problem and the five fishermen dividing fish problem.

  ```python
  # Roosters cost 5, hens cost 3, chicks cost 1 for every 3.
  # Use 100 units of money to buy 100 chickens. How many of each?
  for x in range(20):
      for y in range(33):
          z = 100 - x - y
          if 5 * x + 3 * y + z // 3 == 100 and z % 3 == 0:
              print(x, y, z)

  # Five people, A, B, C, D, and E, caught fish together one night and fell asleep.
  # The next morning A woke first, divided the fish into five portions, threw away one extra fish,
  # and took one portion. B woke next and did the same. Then C, D, and E did the same in turn.
  # What is the minimum number of fish they must have caught?
  fish = 6
  while True:
      total = fish
      enough = True
      for _ in range(5):
          if (total - 1) % 5 == 0:
              total = (total - 1) // 5 * 4
          else:
              enough = False
              break
      if enough:
          print(fish)
          break
      fish += 5
  ```

  Example of a greedy method: suppose a thief has a backpack that can hold at most 20 kilograms of stolen goods. He breaks into a house and finds the following items. Clearly, he cannot carry all of them, so he must decide which ones to take and which to leave.

  | Name | Price (USD) | Weight (kg) |
  | :----: | :----------: | :--------: |
  | Computer | 200 | 20 |
  | Radio | 20 | 4 |
  | Clock | 175 | 10 |
  | Vase | 50 | 2 |
  | Book | 10 | 1 |
  | Oil Painting | 90 | 9 |

  ```python
  """
  Greedy method: when solving a problem, always make the choice that appears
  best at the current moment, without insisting on the optimal answer.
  Input:
  20 6
  Computer 200 20
  Radio 20 4
  Clock 175 10
  Vase 50 2
  Book 10 1
  OilPainting 90 9
  """
  class Thing(object):
      """Item"""

      def __init__(self, name, price, weight):
          self.name = name
          self.price = price
          self.weight = weight

      @property
      def value(self):
          """Price-to-weight ratio"""
          return self.price / self.weight


  def input_thing():
      """Input item information"""
      name_str, price_str, weight_str = input().split()
      return name_str, int(price_str), int(weight_str)


  def main():
      """Main function"""
      max_weight, num_of_things = map(int, input().split())
      all_things = []
      for _ in range(num_of_things):
          all_things.append(Thing(*input_thing()))
      all_things.sort(key=lambda x: x.value, reverse=True)
      total_weight = 0
      total_price = 0
      for thing in all_things:
          if total_weight + thing.weight <= max_weight:
              print(f'The thief takes {thing.name}')
              total_weight += thing.weight
              total_price += thing.price
      print(f'Total value: {total_price} dollars')


  if __name__ == '__main__':
      main()
  ```
