## Deployment and Performance Tuning

### Before Deployment

Important checks:

```bash
python manage.py check --deploy
```

Update production settings:

```python
DEBUG = False
ALLOWED_HOSTS = ['*']
```

Security-related settings often include:

- HSTS
- HTTPS redirect
- MIME sniffing protection
- XSS filter support
- secure cookies
- clickjacking protection

Sensitive values should be stored in environment variables or external config files:

```python
SECRET_KEY = os.environ['SECRET_KEY']
DB_USER = os.environ['DB_USER']
DB_PASS = os.environ['DB_PASS']
```

### Environment Preparation

The original lesson includes practical server steps such as:

- installing system dependencies
- compiling or upgrading Python
- preparing web-server and runtime components

### Performance Tuning Themes

Performance work usually includes:

1. database optimization
2. caching
3. reducing unnecessary ORM queries
4. static-asset handling
5. process and concurrency tuning
6. monitoring and profiling

Deployment is not just "make it run." It is about making it safe, repeatable, observable, and fast enough under load.
