## MySQL Performance Optimization

MySQL performance tuning usually focuses on a few areas:

1. schema design
2. indexing
3. query optimization
4. caching
5. hardware and configuration

### Practical Topics

- avoid unnecessary full table scans
- create useful indexes, but not too many
- inspect execution plans with `EXPLAIN`
- reduce N+1 query patterns in application code
- use appropriate data types
- paginate large queries
- separate hot reads from heavy writes when architecture requires it

Performance optimization is rarely just one trick. It is usually a combination of good schema design, careful SQL, and good application behavior.
