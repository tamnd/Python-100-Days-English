## Key Technical Points of E-Commerce Websites

### Business Models

Common e-commerce models:

- B2B
- C2C
- B2C
- C2B
- O2O
- B2B2C

### Requirement Highlights

User-facing side:

- homepage
- login / registration
- profile and self-service
- product categories, details, search
- cart
- orders
- reviews and favorites

Admin side:

- CRUD for core entities
- scheduled tasks
- report generation
- permission control
- workflow handling
- third-party integrations such as maps, logistics, payments, SMS, and cloud storage

### Product Modeling

Important concepts:

- `SPU`: standard product unit
- `SKU`: stock keeping unit

For example:

- SPU: iPhone 6s
- SKU: iPhone 6s 64G Gold

### Third-Party Login

Third-party login typically uses OAuth 2.0.

General OAuth flow:

1. user grants authorization
2. client receives authorization
3. client requests an access token
4. auth server issues the token
5. client uses the token to request protected resources

### Cache Warm-Up and Query Caching

E-commerce systems often benefit from:

- cache warm-up during startup
- caching of hot lookups
- layered caching strategies

Because e-commerce traffic is bursty and reads are heavy, careful caching is often central to performance.
