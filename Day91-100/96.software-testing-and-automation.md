## Software Testing and Automated Testing

Software testing evaluates correctness, completeness, security, and quality.

### Testing Methods

Two broad styles:

1. black-box testing
2. white-box testing

Black-box testing focuses on functionality. White-box testing focuses on internal logic.

Common test-design ideas:

- equivalence classes
- boundary values
- branch coverage
- condition coverage
- error guessing

### Testing Stages

- unit testing
- integration testing
- system testing
- regression testing

Regression testing is especially important because code changes can easily reintroduce old bugs.

### Test-Driven Development

TDD usually follows:

1. write a failing automated test
2. write the minimum code to pass it
3. refactor

### Tools

For Python:

- `unittest`
- `pytest`
- `nose2`
- `mock`
- `testfixtures`
- `tox`

For UI automation:

- desktop: `PyAutoGUI`
- mobile: `Appium`
- web: `Selenium`

Automation does not replace thinking. It scales good testing practices; it does not invent them.
