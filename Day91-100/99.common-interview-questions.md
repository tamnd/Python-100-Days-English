## Common Interview Questions

This lesson is a checklist of common interview topics.

### Computer Fundamentals

Typical questions:

1. TCP/IP model
2. HTTP and HTTPS
3. Linux commands and services
4. threads vs processes
5. relational databases: ACID, isolation levels, locks, SQL optimization
6. NoSQL topics: CAP, BASE, and use cases

### Python Basics

Typical questions:

1. standard-library and third-party libraries you have used
2. decorators
3. magic methods
4. comprehensions, generators, and iterators
5. internal implementation ideas of lists, sets, and dicts
6. garbage collection
7. concurrency
8. coroutines and async I/O

### Django and Flask

Typical questions:

1. what problem MVC/MTV solves
2. middleware execution flow
3. REST API design
4. ORM CRUD and performance issues such as N+1 queries
5. async tasks and scheduled tasks
6. page caching, query caching, and cache warm-up

### Crawlers

Typical questions:

1. Scrapy components and flow
2. the purpose of crawling in your project
3. tools used for capture, cleaning, storage, analysis, and visualization
4. data sources
5. anti-anti-crawling measures
6. total data volume collected
7. post-processing and persistence

### Data Analysis

Typical questions:

1. common NumPy and SciPy operations
2. common pandas techniques
3. common model types and when to use them
4. which metrics you extracted
5. how to evaluate a model
