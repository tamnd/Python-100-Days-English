## DML in Detail

In this lesson we continue using the `school` database created in the previous lesson. DML is used to insert, delete, and update data in tables. Before running the examples, switch to the correct database.

```SQL
USE `school`;
```

### `INSERT`

`insert` adds rows to a table. You can insert a full row, part of a row, multiple rows at once, or the result of a query.

Insert one college:

```SQL
INSERT INTO `tb_college` 
VALUES
    (DEFAULT, 'College of Computer Science', 'A place to study computer science and technology');
```

Because the primary key is auto-incrementing, `DEFAULT` lets MySQL generate the value. The following version is usually preferred:

```SQL
INSERT INTO `tb_college` (`col_name`, `col_intro`) 
VALUES 
    ('College of Computer Science', 'A place to study computer science and technology');
```

Specifying the target columns is safer and more flexible. It lets you write values in the same order as the listed columns instead of the physical table definition order.

Insert multiple rows in one statement:

```SQL
INSERT INTO `tb_college` 
    (`col_name`, `col_intro`) 
VALUES 
    ('College of Foreign Languages', 'A college for studying foreign languages'),
    ('College of Economics and Management', 'Economics, governance, and management'),
    ('College of Physical Education', 'Develop sports and improve physical fitness');
```

If you insert a duplicate primary key, MySQL raises a duplicate entry error. If you omit a column, that column must either allow `null` or have a default value.

To insert query results into a table:

```SQL
INSERT INTO `tb_college`
    (`col_name`, `col_intro`)
SELECT `a`, `b` 
  FROM `tb_temp`;
```

### `DELETE`

Use `delete` to remove rows from a table.

Delete the college whose ID is `1`:

```SQL
DELETE
  FROM `tb_college`
 WHERE col_id=1;
```

The `where` clause is critical. Without it:

```SQL
DELETE
  FROM `tb_college`;
```

all rows in the table will be deleted.

`delete` removes data, but it does not drop the table itself and does not reset the `AUTO_INCREMENT` counter. If you want to remove all rows and reset the sequence, you can use `truncate table`. Internally that is closer to dropping and recreating the table, so it is faster, but also much riskier.

### `UPDATE`

Use `update` to modify existing rows.

Change student `1001` from `Yang Guo` to `Yang Xiao`:

```SQL
UPDATE `tb_student`
   SET `stu_name`='Yang Xiao'
 WHERE `stu_id`=1001;
```

We use the student ID in the `where` clause because names may not be unique. You can update multiple columns at once:

```SQL
UPDATE `tb_student`
   SET `stu_name`='Yang Xiao'
     , `stu_birth`='1975-12-29'
 WHERE `stu_id`=1001;
```

In real projects, `update` statements almost always include a `where` clause. Updating an entire table is rarely the right thing to do.
