## Relational Databases and MySQL Overview

### Relational Database Overview

1. Data persistence means saving data to a storage medium that can retain it for a long time, so that the data will not be lost even if the power is cut off.

2. A brief history of database development includes network databases, hierarchical databases, relational databases, NoSQL databases, and NewSQL databases.

   > In 1970, IBM researcher E. F. Codd published the paper *A Relational Model of Data for Large Shared Data Banks* in *Communications of the ACM*. In that paper he proposed the **relational model**, laying the theoretical foundation of relational databases. Later, Codd published several more articles on normalization theory and the twelve rules for evaluating relational systems, further grounding relational databases in mathematical theory.

3. Characteristics of relational databases

   - Theoretical foundation: **relational algebra**, including set theory, first-order predicate logic, and relational operations
   - Concrete representation: data is organized in **two-dimensional tables** with rows and columns
   - Programming language: **Structured Query Language**, or SQL
     - DDL: Data Definition Language
     - DML: Data Manipulation Language
     - DCL: Data Control Language
     - TCL: Transaction Control Language

4. The ER model, Entity-Relationship Model, and conceptual model diagrams

   The **ER model**, short for **Entity-Relationship Model**, was proposed by the Chinese-American computer scientist Peter Chen. It is a high-level way of describing conceptual data models, as shown below.

   - entity: rectangle
   - attribute: ellipse
   - relationship: diamond
   - cardinality: 1:1, one-to-one / 1:N, one-to-many / M:N, many-to-many

   In actual project development, we can use database-modeling tools such as PowerDesigner to draw conceptual data models, then set the target database system, convert the conceptual model into a physical model, and finally generate the SQL used to create the two-dimensional tables. Many tools can export SQL directly or create tables from the physical model we design.

5. Relational database products

   - [Oracle](https://www.oracle.com/index.html): currently the most widely used database-management system in the world. As a general-purpose database system, it has complete data-management capabilities. As a relational database, it is a full-featured product. As a distributed database, it supports distributed processing. In newer versions, Oracle has also introduced a multitenant architecture, which makes it easier to deploy and manage database clouds.
   - [DB2](https://www.ibm.com/analytics/us/en/db2/): a relational database product developed by IBM, primarily running on Unix, including IBM's own AIX, Linux, and Windows Server. DB2 has a long history and is regarded as one of the earliest SQL-based database products. It also has strong business-intelligence capabilities.
   - [SQL Server](https://www.microsoft.com/en-us/sql-server/): a relational database product developed and promoted by Microsoft. It was originally suitable mainly for data management in small and medium-sized businesses, but in recent years its usage has expanded, and some large enterprises and even multinational companies have begun to build their own data-management systems on top of it.
   - [MySQL](https://www.mysql.com/): MySQL is open source, and anyone can download it under the GPL, General Public License, and modify it to suit their own needs. MySQL has attracted attention because of its speed, reliability, and adaptability.
   - [PostgreSQL](https://www.postgresql.org/): an open-source relational database product distributed under the BSD license.

### An Introduction to MySQL

MySQL was originally developed by the Swedish company MySQL AB as an open-source relational database management system. That company was acquired by Sun Microsystems in 2008. In 2009, Oracle acquired Sun Microsystems, so MySQL is now also an Oracle product.

Because of its high performance, low cost, and reliability, MySQL became the most popular open-source database in the past and was therefore widely used in the development of small and medium-sized websites. As MySQL continued to mature, it was gradually adopted by more large-scale websites and applications. Wikipedia, Google, Facebook, Baidu, Taobao, Tencent, Sina, Qunar, and many others have used MySQL to provide data persistence services.

After Oracle acquired Sun Microsystems, the price of MySQL's commercial edition was raised significantly, and Oracle also stopped supporting the development of another free-software project, OpenSolaris. As a result, the free-software community became concerned about whether Oracle would continue to support MySQL Community Edition, the only free edition among MySQL's various releases. MySQL creator Michael Widenius therefore created the [MariaDB](https://en.wikipedia.org/wiki/MariaDB) branch based on MySQL, naming it after his daughter. Many organizations that once used MySQL, such as Wikipedia, have since completed migrations from MySQL to MariaDB.

### Installing MySQL

#### Windows

1. Download the MySQL Community Server installer from the [official website](https://www.mysql.com/) through its download links. It is generally recommended to use the offline version of MySQL Installer.
2. Run the installer and proceed through the installation steps.
   - choose a custom installation
   - select the components to install
   - install dependencies first if they are missing
   - begin the installation
   - complete the installation
   - prepare to run the configuration wizard
3. Run the post-installation configuration wizard.
   - configure server type and networking
   - configure the authentication method, in other words how passwords are protected
   - configure users and roles
   - configure the Windows service name and whether it starts at boot
   - configure logs
   - configure advanced options
   - apply the configuration
4. MySQL can then be started and stopped from the Windows Services window.
5. Configure the `PATH` environment variable so that MySQL command-line tools can be used directly from Command Prompt.
   - open the Windows System window and click Advanced System Settings
   - in the Advanced tab of System Properties, click Environment Variables
   - edit the `PATH` environment variable and add the path to the `bin` folder under the MySQL installation directory
   - after configuration, try running MySQL command-line tools from Command Prompt

#### Linux

The example below uses CentOS 7.x to demonstrate how to install MySQL 5.7.x. If you need to install another version of MySQL on another Linux system, you should look up the corresponding installation instructions yourself.

1. Install MySQL.

   Download the installation files from the [official MySQL website](https://www.mysql.com/). On the download page, select the platform and version, then find the appropriate download link and directly download the archive bundle that contains all installation files. After extracting it, use the package manager to install the packages.

   ```bash
   wget https://dev.mysql.com/get/Downloads/MySQL-5.7/mysql-5.7.26-1.el7.x86_64.rpm-bundle.tar
   tar -xvf mysql-5.7.26-1.el7.x86_64.rpm-bundle.tar
   ```

   If the system already has MariaDB-related packages, remove them first.

   ```bash
   yum list installed | grep mariadb | awk '{print $1}' | xargs yum erase -y
   ```

   Update the system and install the low-level libraries that may be needed.

   ```bash
   yum update
   yum install -y libaio libaio-devel
   ```

   Next, install MySQL with RPM, Red Hat Package Manager, in the order shown below.

   ```bash
   rpm -ivh mysql-community-common-5.7.26-1.el7.x86_64.rpm
   rpm -ivh mysql-community-libs-5.7.26-1.el7.x86_64.rpm
   rpm -ivh mysql-community-libs-compat-5.7.26-1.el7.x86_64.rpm
   rpm -ivh mysql-community-devel-5.7.26-1.el7.x86_64.rpm
   rpm -ivh mysql-community-client-5.7.26-1.el7.x86_64.rpm
   rpm -ivh mysql-community-server-5.7.26-1.el7.x86_64.rpm
   ```

   You can use the following command to see which MySQL-related packages have been installed.

   ```bash
   rpm -qa | grep mysql
   ```

2. Configure MySQL.

   MySQL's configuration file is located in `/etc` and is named `my.cnf`. Its default contents are shown below.

   ```bash
   cat /etc/my.cnf
   ```

   ```ini
   # For advice on how to change settings please see
   # http://dev.mysql.com/doc/refman/5.7/en/server-configuration-defaults.html

   [mysqld]
   #
   # Remove leading # and set to the amount of RAM for the most important data
   # cache in MySQL. Start at 70% of total RAM for dedicated server, else 10%.
   # innodb_buffer_pool_size = 128M
   #
   # Remove leading # to turn on a very important data integrity option: logging
   # changes to the binary log between backups.
   # log_bin
   #
   # Remove leading # to set options mainly useful for reporting servers.
   # The server defaults are faster for transactions and fast SELECTs.
   # Adjust sizes as needed, experiment to find the optimal values.
   # join_buffer_size = 128M
   # sort_buffer_size = 2M
   # read_rnd_buffer_size = 2M
   datadir=/var/lib/mysql
   socket=/var/lib/mysql/mysql.sock

   # Disabling symbolic-links is recommended to prevent assorted security risks
   symbolic-links=0

   log-error=/var/log/mysqld.log
   pid-file=/var/run/mysqld/mysqld.pid
   ```

   Through this configuration file, we can modify settings such as the port MySQL uses, the character set, the maximum number of connections, socket queue size, maximum packet size, log file location, and log expiration time. Of course, we can also use it for performance tuning and security controls.

3. Start the MySQL service.

   You can use the following command to start MySQL.

   ```bash
   service mysqld start
   ```

   On CentOS 7, the following command is recommended instead.

   ```bash
   systemctl start mysqld
   ```

   Once MySQL starts successfully, you can use the following command to check network-port usage. By default, MySQL uses port `3306`.

   ```bash
   netstat -ntlp | grep mysql
   ```

   You can also search for a process named `mysqld`.

   ```bash
   pgrep mysqld
   ```

4. Use the MySQL client tool to connect to the server.

   Command-line tool:

   ```bash
   mysql -u root -p
   ```

   > **Note**: When starting the client, `-u` specifies the username, and MySQL's default superuser is `root`. `-p` indicates that you will enter a password. If you are connecting to another machine instead of the local host, you can use `-h` to specify the host name or IP address.

   If this is a first-time installation of MySQL, you can use the following command to find the default initial password.

   ```bash
   cat /var/log/mysqld.log | grep password
   ```

   The part after `root@localhost:` in the matching log line is the initial password.

   After entering the client, you can use the commands below to change the superuser password for `root` to `123456`.

   ```sql
   set global validate_password_policy=0;
   set global validate_password_length=6;
   alter user 'root'@'localhost' identified by '123456';
   ```

   > **Note**: Newer MySQL versions do not allow weak passwords by default, so the commands above first change the password-validation policy and minimum password length. In reality, however, we should not use weak passwords, because they carry the risk of brute-force attacks. In recent years, attacks that steal data from databases or hijack databases for Bitcoin ransom have become increasingly common. The most important step to reduce these risks is **not exposing the database server directly to the public internet**. The best practice is to place the database on an internal network. At a minimum, the database port should not be opened to the public. In addition, the `root` account password must be protected carefully. Application systems normally should not access the database using `root`; instead, **other accounts with only the necessary permissions should be created**.

   When connecting to the MySQL server again with the client, you can use the newly set password. In real development, for convenience, users often connect with graphical tools such as:

   - MySQL Workbench, the official tool
   - Navicat for MySQL, which has a simple and friendly interface

#### macOS

Installing MySQL on macOS is relatively simple. You only need to download the DMG installer from the official website mentioned above and run it. When downloading, choose the correct package depending on whether your machine uses an Intel chip or Apple's M1 chip.

After installation succeeds, you can find MySQL in System Preferences. From there, you can start and stop the MySQL server and configure the path to MySQL's core files.

### Basic MySQL Commands

#### Commands for Viewing Information

1. View all databases

```sql
show databases;
```

2. View all character sets

```sql
show character set;
```

3. View all collations

```sql
show collation;
```

4. View all engines

```sql
show engines;
```

5. View all binary logs

```sql
show binary logs;
```

6. View all tables in the current database

```sql
show tables;
```

#### Help Commands

```sql
? show
? contents
? functions
? data types
```

#### Other Useful Commands

- `connect` / `resetconnection`
- `\c`, clear the current input
- `delimiter`, change the statement terminator
- `edit`
- `status`
- `prompt`
- `system` or `\!`
- `source`
- `tee` / `notee`
- `use`
- `warnings`
- `quit` / `exit`

### Summary

Relational databases organize data in tables and use SQL as their core language. MySQL is one of the most widely used relational database systems. Knowing how to install it, connect to it, and use its basic commands is an important foundation for backend development.
