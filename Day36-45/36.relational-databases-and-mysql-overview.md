## Relational Databases and MySQL Overview

### Relational Database Overview

1. **Data persistence**: saving data to storage media that retain it even after power loss.
2. **Database evolution**: network databases, hierarchical databases, relational databases, NoSQL databases, and NewSQL databases.

In 1970, IBM researcher E. F. Codd published *A Relational Model of Data for Large Shared Data Banks*, which laid the theoretical foundation for the relational model.

3. **Characteristics of relational databases**

   - theoretical foundation: **relational algebra**
   - data representation: **two-dimensional tables**
   - query language: **SQL**
     - DDL: Data Definition Language
     - DML: Data Manipulation Language
     - DCL: Data Control Language
     - TCL: Transaction Control Language

4. **ER model**

   The **Entity-Relationship Model** is a conceptual modeling approach proposed by Peter Chen.

   <img src="res/er_diagram.png" width="75%">

   - entity: rectangle
   - attribute: ellipse
   - relationship: diamond
   - cardinality: 1:1, 1:N, M:N

   In real projects, developers often use modeling tools to build conceptual models and then convert them into physical database models.

5. **Common relational database products**

   - Oracle
   - DB2
   - SQL Server
   - MySQL
   - PostgreSQL

### Introduction to MySQL

MySQL was originally developed by the Swedish company MySQL AB. In 2008, MySQL AB was acquired by Sun Microsystems, and in 2009 Sun was acquired by Oracle. So MySQL is now an Oracle product.

MySQL became popular because of its performance, low cost, and reliability, and it has been widely used in websites and applications of many sizes.

Concerns about Oracle's stewardship of MySQL eventually led to the creation of **MariaDB**, a fork started by MySQL creator Michael Widenius.

### Installing MySQL

#### Windows

The usual steps are:

1. Download the MySQL Community Server installer from the official website.
2. Run the installer and choose a custom installation if needed.
3. Select components and install dependencies.
4. Run the post-installation configuration wizard.
5. Configure PATH if you want to use MySQL from Command Prompt.

#### Linux

On CentOS 7, a typical installation flow looks like this:

```bash
wget https://dev.mysql.com/get/Downloads/MySQL-5.7/mysql-5.7.26-1.el7.x86_64.rpm-bundle.tar
tar -xvf mysql-5.7.26-1.el7.x86_64.rpm-bundle.tar
```

If MariaDB is already installed, remove it first:

```bash
yum list installed | grep mariadb | awk '{print $1}' | xargs yum erase -y
```

Install dependencies:

```bash
yum update
yum install -y libaio libaio-devel
```

Install MySQL RPM packages in order:

```bash
rpm -ivh mysql-community-common-5.7.26-1.el7.x86_64.rpm
rpm -ivh mysql-community-libs-5.7.26-1.el7.x86_64.rpm
rpm -ivh mysql-community-libs-compat-5.7.26-1.el7.x86_64.rpm
rpm -ivh mysql-community-devel-5.7.26-1.el7.x86_64.rpm
rpm -ivh mysql-community-client-5.7.26-1.el7.x86_64.rpm
rpm -ivh mysql-community-server-5.7.26-1.el7.x86_64.rpm
```

Check installed packages:

```bash
rpm -qa | grep mysql
```

Start MySQL:

```bash
systemctl start mysqld
```

Connect as root:

```bash
mysql -u root -p
```

Find the initial password:

```bash
cat /var/log/mysqld.log | grep password
```

Then change the password:

```sql
set global validate_password_policy=0;
set global validate_password_length=6;
alter user 'root'@'localhost' identified by '123456';
```

> **Note**: Weak passwords are a security risk. In real deployments, do not expose your database server directly to the public internet, and avoid using the `root` account for applications.

#### macOS

On macOS, installation is usually simpler: download the DMG installer from the official site and run it. After installation, MySQL can be started or stopped from System Preferences.

### Basic MySQL Commands

#### Show Commands

```sql
show databases;
show character set;
show collation;
show engines;
show binary logs;
show tables;
```

#### Help

```sql
? show
? contents
? functions
? data types
```

#### Other Useful Commands

- `connect` / `resetconnection`
- `\c` to clear current input
- `delimiter` to change the statement terminator
- `edit`
- `status`
- `prompt`
- `system` or `\!`
- `source`
- `tee` / `notee`
- `use`
- `warnings`
- `quit` / `exit`

### Summary

Relational databases organize data in tables and use SQL as their core language. MySQL is one of the most widely used relational database systems, and knowing how to install it, connect to it, and use its basic commands is an important foundation for backend development.
