## Connecting Python to MySQL

In Python 3, you can use either `mysqlclient` or `pymysql` to connect to MySQL and perform persistence operations. Their APIs are almost the same; the main difference is the imported module name. This course recommends `pymysql` because it is pure Python and usually easier to install.

We will continue using the `hrs` database from the previous lessons.

### Connecting to MySQL

Install dependencies:

```Shell
pip install pymysql cryptography
```

If you are connecting to MySQL 8, `cryptography` is often needed because of the default password authentication mechanism.

The steps for using `pymysql` to operate on MySQL are shown below:

1. Create a connection with `pymysql.connect(...)`.
2. Get a cursor from the connection.
3. Execute SQL through the cursor.
4. Commit or roll back the transaction as needed, or fetch data for queries.
5. Close the connection.

Below, we will use actual code to demonstrate the five steps above.

### Code Examples

#### Insert Data

```Python
import pymysql

no = int(input('Department ID: '))
name = input('Department name: ')
location = input('Department location: ')

# 1. Create a connection
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. Get a cursor
    with conn.cursor() as cursor:
        # 3. Execute SQL
        affected_rows = cursor.execute(
            'insert into `tb_dept` values (%s, %s, %s)',
            (no, name, location)
        )
        if affected_rows == 1:
            print('Department inserted successfully!')
    # 4. Commit the transaction
    conn.commit()
except pymysql.MySQLError as err:
    conn.rollback()
    print(type(err), err)
finally:
    # 5. Close the connection
    conn.close()
```

> **Note**: `127.0.0.1` is the loopback address, meaning the local machine. The `guest` account here is assumed to have `insert`, `delete`, `update`, and `select` privileges on the `hrs` database. In real projects, avoid using the `root` account directly from application code.

Example SQL to create that user:

```SQL
create user 'guest'@'%' identified by 'Guest.618';
grant insert, delete, update, select on `hrs`.* to 'guest'@'%';
```

If you need to insert a large amount of data, it is recommended that you use the cursor's `executemany` method for batch processing, meaning one `insert` statement followed by multiple groups of values. You can try inserting 10,000 rows into a table and compare inserting them one by one with inserting them in batches. The first argument to `executemany` is still the SQL statement, and the second can be a list or tuple containing multiple groups of data.

#### Delete Data

```Python
import pymysql

no = int(input('Department ID: '))

conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4',
                       autocommit=True)
try:
    with conn.cursor() as cursor:
        affected_rows = cursor.execute(
            'delete from `tb_dept` where `dno`=%s',
            (no, )
        )
        if affected_rows == 1:
            print('Department deleted successfully!')
finally:
    conn.close()
```

> **Note**: If you do not want to commit or roll back every SQL operation manually, you can pass an `autocommit=True` argument to `connect`, which means a successful SQL statement is committed automatically. Even so, it is usually better to commit or roll back manually so you can construct a transaction scope that matches the business scenario. If you do not want to catch exceptions at all, you can omit the `except` block and keep only `try` plus `finally`. That means the program will crash directly if an exception occurs, and Python will print the stack trace in the terminal.

#### Update Data

```Python
import pymysql

no = int(input('Department ID: '))
name = input('Department name: ')
location = input('Department location: ')

conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    with conn.cursor() as cursor:
        affected_rows = cursor.execute(
            'update `tb_dept` set `dname`=%s, `dloc`=%s where `dno`=%s',
            (name, location, no)
        )
        if affected_rows == 1:
            print('Department updated successfully!')
    conn.commit()
except pymysql.MySQLError as err:
    conn.rollback()
    print(type(err), err)
finally:
    conn.close()
```

#### Query Data

1. Query the department table:

```Python
import pymysql

conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    with conn.cursor() as cursor:
        cursor.execute('select `dno`, `dname`, `dloc` from `tb_dept`')
        row = cursor.fetchone()
        while row:
            print(row)
            row = cursor.fetchone()
except pymysql.MySQLError as err:
    print(type(err), err)
finally:
    conn.close()
```

> **Note**: The code above uses a `while` loop to fetch the result one row at a time. This approach is especially suitable when the query returns a very large number of rows. If you call `fetchall` and load every record into a nested tuple at once, the memory overhead can be very large, which is not a good idea in many scenarios. If you do not like writing a `while` loop, you can also explore building an iterator with `iter` and fetching row by row that way.

2. Paginated query on the employee table:

```Python
import pymysql

page = int(input('Page: '))
size = int(input('Page size: '))

con = pymysql.connect(host='127.0.0.1', port=3306,
                      user='guest', password='Guest.618',
                      database='hrs', charset='utf8')
try:
    with con.cursor(pymysql.cursors.DictCursor) as cursor:
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal` from `tb_emp` order by `sal` desc limit %s,%s',
            ((page - 1) * size, size)
        )
        for emp_dict in cursor.fetchall():
            print(emp_dict)
finally:
    con.close()
```

### Example: Export Database Data to Excel

First install `openpyxl`:

```Bash
pip install openpyxl
```

The following program exports employee data from the `hrs` database to an Excel file:

```Python
import openpyxl
import pymysql

workbook = openpyxl.Workbook()
sheet = workbook.active
sheet.title = 'Employee Basic Info'
sheet.append(('Employee ID', 'Name', 'Job', 'Salary', 'Allowance', 'Department'))

conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    with conn.cursor() as cursor:
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal`, coalesce(`comm`, 0), `dname` '
            'from `tb_emp` natural join `tb_dept`'
        )
        row = cursor.fetchone()
        while row:
            sheet.append(row)
            row = cursor.fetchone()
    workbook.save('hrs.xlsx')
except pymysql.MySQLError as err:
    print(err)
finally:
    conn.close()
```

You can use the same idea in reverse and try reading rows from an Excel file and importing them into a designated database table to see whether you can make that work as well.
