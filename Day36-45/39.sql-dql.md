## DQL in Detail

Now we will use the school course-selection database to explain query operations. Querying is critical for both developers and data analysts because it determines whether you can retrieve the data you actually need.

It is a good idea to rerun the DDL from the earlier lesson and the DML inserts from the previous lesson before practicing the following queries.

```SQL
USE school;

-- Query all information for all students
SELECT stu_id,
       stu_name,
       stu_sex,
       stu_birth,
       stu_addr,
       col_id
  FROM tb_student;

-- Query student ID, name, and hometown (projection and alias)
SELECT stu_id AS StudentID,
       stu_name AS Name,
       stu_addr AS Hometown
  FROM tb_student;

-- Query all course names and credits
SELECT cou_name AS CourseName,
       cou_credit AS Credits
  FROM tb_course;

-- Query the names and birth dates of all female students
SELECT stu_name,
       stu_birth
  FROM tb_student
 WHERE stu_sex = 0;

-- Female students from Chengdu, Sichuan
SELECT stu_name,
       stu_birth
  FROM tb_student
 WHERE stu_sex = 0
       AND stu_addr = 'Chengdu, Sichuan';

-- Students who are female or from Chengdu, Sichuan
SELECT stu_name,
       stu_birth
  FROM tb_student
 WHERE stu_sex = 0
       OR stu_addr = 'Chengdu, Sichuan';

-- Students born in the 1980s
SELECT stu_name,
       stu_sex,
       stu_birth
  FROM tb_student
 WHERE stu_birth BETWEEN '1980-1-1' AND '1989-12-31';

-- Courses with more than 2 credits
SELECT cou_name,
	   cou_credit
  FROM tb_course
 WHERE cou_credit > 2;

-- Courses with odd-numbered credits
SELECT cou_name,
	   cou_credit
  FROM tb_course
 WHERE cou_credit MOD 2 <> 0;

-- Students who chose course 1111 and scored above 90
SELECT stu_id
  FROM tb_record
 WHERE cou_id = 1111
       AND score > 90;

-- The gender of the student named "Yang Guo"
SELECT stu_name AS Name, 
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS Gender
  FROM tb_student
 WHERE stu_name = 'Yang Guo';

SELECT stu_name AS Name, 
       IF(stu_sex, 'Male', 'Female') AS Gender
  FROM tb_student
 WHERE stu_name = 'Yang Guo';

-- Students whose last name is Yang
SELECT stu_name AS Name, 
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS Gender
  FROM tb_student
 WHERE stu_name LIKE 'Yang%';

-- Students whose names start with "Yang" and have one additional character after it
SELECT stu_name AS Name, 
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS Gender
  FROM tb_student
 WHERE stu_name LIKE 'Yang_';

-- Students whose names start with "Yang" and have two additional characters after it
SELECT stu_name AS Name, 
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS Gender
  FROM tb_student
 WHERE stu_name LIKE 'Yang__';

-- Students whose student ID ends with 3
SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_id LIKE '%3';

-- Students whose names contain "Bu" or "Yan"
SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_name LIKE '%Bu%'
       OR stu_name LIKE '%Yan%';

SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_name LIKE '%Bu%'
 UNION
SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_name LIKE '%Yan%';

-- Names beginning with Yang or Lin, followed by two lowercase letters
SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_name REGEXP '^(Yang|Lin)[a-z]{2}$';

-- Students whose hometown was not entered
SELECT stu_name
  FROM tb_student
 WHERE TRIM(stu_addr) = ''
       OR stu_addr is null;

-- Students whose hometown was entered
SELECT stu_name
  FROM tb_student
 WHERE TRIM(stu_addr) <> ''
       AND stu_addr is not null;

-- All course selection dates (distinct)
SELECT DISTINCT sel_date
  FROM tb_record;

-- Distinct hometowns
SELECT DISTINCT stu_addr
  FROM tb_student
 WHERE TRIM(stu_addr) <> ''
       AND stu_addr is not null;

-- Male students ordered by age, oldest first
SELECT stu_name,
       stu_birth
  FROM tb_student
 WHERE stu_sex = 1
 ORDER BY stu_birth ASC;

-- Convert birthday to age
SELECT stu_name AS Name,
       FLOOR(DATEDIFF(CURDATE(), stu_birth) / 365) AS Age
  FROM tb_student
 WHERE stu_sex = 1
 ORDER BY Age DESC;

-- Oldest student's birth date
SELECT MIN(stu_birth)
  FROM tb_student;

-- Youngest student's birth date
SELECT MAX(stu_birth)
  FROM tb_student;

-- Highest score in course 1111
SELECT MAX(score)
  FROM tb_record
 WHERE cou_id = 1111;

-- Summary statistics for student 1001
SELECT MIN(score) AS MinScore,
       MAX(score) AS MaxScore,
	   ROUND(AVG(score), 1) AS AvgScore,
       STDDEV(score) AS StdDev,
       VARIANCE(score) AS Variance
  FROM tb_record
 WHERE stu_id = 1001;

-- Average score for student 1001, counting null as zero
SELECT ROUND(SUM(score) / COUNT(*), 1) AS AvgScore
  FROM tb_record
 WHERE stu_id = 1001;

-- Number of male and female students
SELECT CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS Gender,
       COUNT(*) AS Total
  FROM tb_student
 GROUP BY stu_sex;

-- Number of students in each college
SELECT col_id AS CollegeID,
       COUNT(*) AS Total
  FROM tb_student
 GROUP BY col_id
  WITH ROLLUP;

-- Number of male/female students in each college
SELECT col_id AS CollegeID,
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS Gender,
       COUNT(*) AS Total
  FROM tb_student
 GROUP BY col_id, stu_sex;

-- Average score for each student
SELECT stu_id AS StudentID,
	   ROUND(AVG(score), 1) AS AvgScore
  FROM tb_record
 GROUP BY stu_id;

-- Students whose average score is at least 90
SELECT stu_id AS StudentID,
	   ROUND(AVG(score), 1) AS AvgScore
  FROM tb_record
 GROUP BY stu_id
HAVING AvgScore >= 90;

-- Average score across courses 1111, 2222, 3333
SELECT stu_id AS StudentID,
	   ROUND(AVG(score), 1) AS AvgScore
  FROM tb_record
 WHERE cou_id in (1111, 2222, 3333)
 GROUP BY stu_id
HAVING AvgScore >= 90
 ORDER BY AvgScore ASC;

-- Name of the oldest student
SELECT stu_name
  FROM tb_student
 WHERE stu_birth = (SELECT MIN(stu_birth)
                      FROM tb_student);

-- Students who selected more than two courses
SELECT stu_name
  FROM tb_student
 WHERE stu_id in (SELECT stu_id
				    FROM tb_record
				   GROUP BY stu_id
				  HAVING COUNT(*) > 2);

-- Student name, birth date, and college name
SELECT stu_name,
       stu_birth,
       col_name
  FROM tb_student AS t1, tb_college AS t2
 WHERE t1.col_id = t2.col_id;

SELECT stu_name,
       stu_birth,
	   col_name
  FROM tb_student INNER JOIN tb_college
       ON tb_student.col_id = tb_college.col_id;

SELECT stu_name,
       stu_birth,
	   col_name
  FROM tb_student NATURAL JOIN tb_college;

SELECT stu_name,
       stu_birth,
	   col_name
  FROM tb_student CROSS JOIN tb_college;

-- Student name, course name, and score
SELECT stu_name,
       cou_name,
	   score
  FROM tb_student, tb_course, tb_record
 WHERE tb_student.stu_id = tb_record.stu_id
       AND tb_course.cou_id = tb_record.cou_id
       AND score is not null;

SELECT stu_name,
       cou_name,
	   score
  FROM tb_student 
       INNER JOIN tb_record
	       ON tb_student.stu_id = tb_record.stu_id
	   INNER JOIN tb_course
	       ON tb_course.cou_id = tb_record.cou_id
 WHERE score is not null;

SELECT stu_name,
       cou_name,
       score
  FROM tb_student 
	   NATURAL JOIN tb_record
       NATURAL JOIN tb_course
 WHERE score is not null;

-- First 5 rows
SELECT stu_name,
       cou_name,
       score
  FROM tb_student 
	   NATURAL JOIN tb_record
       NATURAL JOIN tb_course
 WHERE score is not null
 ORDER BY cou_id ASC, score DESC
 LIMIT 5;

-- Rows 6-10
SELECT stu_name,
       cou_name,
       score
  FROM tb_student 
	   NATURAL JOIN tb_record
       NATURAL JOIN tb_course
 WHERE score is not null
 ORDER BY cou_id ASC, score DESC
 LIMIT 5
OFFSET 5;

-- Rows 11-15
SELECT stu_name,
       cou_name,
       score
  FROM tb_student 
	   NATURAL JOIN tb_record
       NATURAL JOIN tb_course
 WHERE score is not null
 ORDER BY cou_id ASC, score DESC
 LIMIT 10, 5;

-- Name and average score
SELECT stu_name,
	   avg_score
  FROM tb_student
       NATURAL JOIN (SELECT stu_id,
                            ROUND(AVG(score), 1) AS avg_score
                       FROM tb_record
                      GROUP BY stu_id) as tmp;

-- Name and number of selected courses
SELECT stu_name,
	   total
  FROM tb_student
       NATURAL JOIN (SELECT stu_id,
                            COUNT(*) AS total
                       FROM tb_record
                      GROUP BY stu_id) as tmp;

-- Every student and course count, including 0
SELECT stu_name AS Name,
	   COALESCE(total, 0) AS CourseCount
  FROM tb_student AS t1
	   LEFT JOIN (SELECT stu_id,
			             COUNT(*) AS total
		            FROM tb_record
				   GROUP BY stu_id) AS t2
	       ON t1.stu_id = t2.stu_id;
```

A few additional notes:

1. Current MySQL versions do not support full outer joins directly. A common workaround is to combine left and right joins with `union`.
2. MySQL supports arithmetic, comparison, logical, and bitwise operators in DML statements.
3. Functions can be used in `select`, `where`, `order by`, `having`, and similar clauses.

Common string functions:

| Function | Purpose |
| --- | --- |
| `CONCAT` | Join multiple strings |
| `FORMAT` | Format a number as a string |
| `FROM_BASE64` / `TO_BASE64` | Decode / encode BASE64 |
| `BIN` / `OCT` / `HEX` | Convert numbers to binary / octal / hex strings |
| `LOCATE` | Find the position of a substring |
| `LEFT` / `RIGHT` | Return the left/right part of a string |
| `LENGTH` / `CHAR_LENGTH` | Return length in bytes / characters |
| `LOWER` / `UPPER` | Lowercase / uppercase |
| `LPAD` / `RPAD` | Pad a string on the left/right |
| `LTRIM` / `RTRIM` | Trim spaces |
| `ORD` / `CHAR` | Character code / character from code |
| `STRCMP` | Compare strings |
| `SUBSTRING` | Extract part of a string |

Common numeric functions:

| Function | Purpose |
| --- | --- |
| `ABS` | Absolute value |
| `CEILING` / `FLOOR` | Round up / down |
| `CONV` | Base conversion |
| `CRC32` | CRC32 checksum |
| `EXP` / `LOG` / `LOG2` / `LOG10` | Exponential / logarithm |
| `POW` | Power |
| `RAND` | Random number in [0, 1) |
| `ROUND` | Round to nearest |
| `SQRT` | Square root |
| `TRUNCATE` | Truncate to a given precision |
| Trig functions | `SIN`, `COS`, `TAN`, `COT`, `ASIN`, `ACOS`, `ATAN` |

Common date/time functions:

| Function | Purpose |
| --- | --- |
| `CURDATE` / `CURTIME` / `NOW` | Current date / time / timestamp |
| `ADDDATE` / `SUBDATE` | Add / subtract dates |
| `DATE` / `TIME` | Parse date/time |
| `YEAR` / `MONTH` / `DAY` | Extract date parts |
| `HOUR` / `MINUTE` / `SECOND` | Extract time parts |
| `DATEDIFF` / `TIMEDIFF` / `TIMESTAMPDIFF` | Time difference |
| `MAKEDATE` / `MAKETIME` | Build date/time values |

Common control flow functions:

| Function | Purpose |
| --- | --- |
| `IF` | Conditional result |
