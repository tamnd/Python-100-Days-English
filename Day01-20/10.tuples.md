## Common Data Structures: Tuples

In the previous two lessons, we studied lists, which are container types that let us store multiple values and process them in batches with loops. Python also has other container types. In this lesson, we introduce the **tuple**.

### Defining Tuples and Basic Operations

In Python, a tuple is also a sequence composed of multiple elements in a certain order. The difference between a tuple and a list is that **a tuple is an immutable type**. This means that once a variable of tuple type has been defined, elements cannot be added or deleted, and the values of the elements cannot be modified either. If you try to modify an element in a tuple, it raises `TypeError` and causes the program to crash. Tuples are usually defined with literal syntax like `(x, y, z)`, and the operators supported by tuples are the same as those supported by lists.

```python
# A tuple with three elements.
t1 = (35, 12, 98)
# A tuple with four elements.
t2 = ('Luo Hao', 45, True, 'Chengdu, Sichuan')

print(type(t1))  # <class 'tuple'>
print(type(t2))  # <class 'tuple'>

print(len(t1))  # 3
print(len(t2))  # 4

print(t1[0])    # 35
print(t1[2])    # 98
print(t2[-1])   # Chengdu, Sichuan

print(t2[:2])   # ('Luo Hao', 45)
print(t2[::3])  # ('Luo Hao', 'Chengdu, Sichuan')

for elem in t1:
    print(elem)

print(12 in t1)            # True
print(99 in t1)            # False
print('Hao' not in t2)     # True

t3 = t1 + t2
print(t3)

print(t1 == t3)            # False
print(t1 >= t3)            # False
print(t1 <= (35, 11, 99))  # False
```

If a tuple has two elements, we call it a 2-tuple. If it has five elements, we call it a 5-tuple, and so on.

Be careful with single-element tuples. `()` represents the empty tuple, but if a tuple has exactly one element, you must include a trailing comma. Otherwise, Python treats the parentheses as grouping rather than tuple syntax.

```python
a = ()
print(type(a))  # <class 'tuple'>
b = ('hello')
print(type(b))  # <class 'str'>
c = (100)
print(type(c))  # <class 'int'>
d = ('hello', )
print(type(d))  # <class 'tuple'>
e = (100, )
print(type(e))  # <class 'tuple'>
```

### Packing and Unpacking

When we assign multiple values separated by commas to one variable, those multiple values are packed into a tuple type. When we assign a tuple to multiple variables, the tuple is unpacked into multiple values and then assigned to the corresponding variables, as shown below.

```python
# Packing
a = 1, 10, 100
print(type(a))  # <class 'tuple'>
print(a)        # (1, 10, 100)

# Unpacking
i, j, k = a
print(i, j, k)  # 1 10 100
```

If the number of values does not match the number of variables, Python raises `ValueError`.

```python
a = 1, 10, 100, 1000
# i, j, k = a          # ValueError: too many values to unpack
# i, j, k, l, m, n = a # ValueError: not enough values to unpack
```

One solution is to use a starred expression so one variable can collect multiple values:

```python
a = 1, 10, 100, 1000
i, j, *k = a
print(i, j, k)        # 1 10 [100, 1000]
i, *j, k = a
print(i, j, k)        # 1 [10, 100] 1000
*i, j, k = a
print(i, j, k)        # [1, 10] 100 1000
*i, j = a
print(i, j)           # [1, 10, 100] 1000
i, *j = a
print(i, j)           # 1 [10, 100, 1000]
i, j, k, *l = a
print(i, j, k, l)     # 1 10 100 [1000]
i, j, k, l, *m = a
print(i, j, k, l, m)  # 1 10 100 1000 []
```

Two important notes:

- A starred target becomes a list, not a tuple.
- Only one starred expression can appear in one unpacking statement.

Unpacking works with all sequences, not just tuples. That includes lists, ranges, and strings.

```python
a, b, *c = range(1, 10)
print(a, b, c)
a, b, c = [1, 10, 100]
print(a, b, c)
a, *b, c = 'hello'
print(a, b, c)
```

### Swapping Variables

Swapping the values of variables is a very common operation when writing code, but in many programming languages, swapping the values of two variables requires the help of an intermediate variable. If you do not use an intermediate variable, then you need to use rather obscure bitwise operations. In Python, swapping the values of variables `a` and `b` only requires the code below.

```python
a, b = b, a
```

Similarly, if you want to rotate the values of three variables `a`, `b`, and `c`, so that the value of `b` is assigned to `a`, the value of `c` is assigned to `b`, and the value of `a` is assigned to `c`, it can be done in the same way.

```python
a, b, c = b, c, a
```

It should be explained that the operations above do not use packing and unpacking syntax. Python bytecode has instructions such as `ROT_TWO` and `ROT_THREE` that can do this operation directly, so the efficiency is very high. But if the values of more than three variables need to be rotated in order, then there is no directly usable bytecode instruction, and we have to complete the value swap through packing and unpacking.

### Tuples vs Lists

There is another question here that is very worth discussing. Python already has the list type, so why do we still need a type like tuples? For beginners, this question may seem a bit difficult, but it does not matter. Let us first put forward the viewpoint, and everyone can keep learning and slowly develop a feel for it.

1. Tuples are immutable, which makes them better suited to multi-threaded environments because they reduce synchronization overhead.
2. Tuples are immutable, and usually **immutable types are faster to create** than the corresponding mutable types.

We can use the `timeit` module to compare the creation cost of a tuple and a list containing the same elements:

```python
import timeit

print('%.3f seconds' % timeit.timeit('[1, 2, 3, 4, 5, 6, 7, 8, 9]', number=10000000))
print('%.3f seconds' % timeit.timeit('(1, 2, 3, 4, 5, 6, 7, 8, 9)', number=10000000))
```

Sample output:

```text
0.635 seconds
0.078 seconds
```

> **Note**: The results of the code above vary depending on hardware and software. On the computer I am currently using, executing the list-creation operation `10000000` times takes `0.635` seconds, while executing the tuple-creation operation `10000000` times takes `0.078` seconds. Clearly, creating a tuple is faster, and the time difference is about an order of magnitude. You can run this code on your own computer and compare the results.

Of course, tuples and lists can be converted into each other:

```python
infos = ('Luo Hao', 45, True, 'Chengdu, Sichuan')
print(list(infos))  # ['Luo Hao', 45, True, 'Chengdu, Sichuan']

frts = ['apple', 'banana', 'orange']
print(tuple(frts))  # ('apple', 'banana', 'orange')
```

### Summary

**Lists and tuples are both container types**, meaning a single variable can hold multiple values, and both are ordered sequences. **Lists are mutable**, while **tuples are immutable**. That is why lists support adding, deleting, clearing, sorting, and reversing elements, while tuples do not. Lists and tuples both support **concatenation**, **membership testing**, **indexing**, and **slicing**. The string type that we will talk about later also supports these operations, because a string is also a sequence made up of characters in a certain order. In this point, there is no difference between the three. We **recommend using list comprehensions to create lists**, because they are easy to use and very efficient, and this is one of the most distinctive pieces of syntax in Python.
