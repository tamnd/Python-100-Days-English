## Common Data Structures: Dictionaries

So far, we have already introduced three container data types in Python: lists, tuples, and sets. However, these data types are still not enough to help us solve all problems. For example, suppose we need one variable to store multiple pieces of information about a person, including name, age, height, weight, home address, personal mobile number, and emergency contact number. At that point you will find that the list, tuple, and set types we learned before are still not ideal.

```python
person1 = ['Wang Dachui', 55, 168, 60, 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu', '13122334455', '13800998877']
person2 = ('Wang Dachui', 55, 168, 60, 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu', '13122334455', '13800998877')
person3 = {'Wang Dachui', 55, 168, 60, 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu', '13122334455', '13800998877'}
```

Sets are definitely the least suitable, because sets cannot contain duplicate elements. If a person's age and weight happen to be the same, then the set would lose one piece of information. Likewise, if the person's phone number and emergency contact number are the same, the set would lose another piece of information. On the other hand, although lists and tuples can save all of a person's information, when you want to obtain this person's phone number or home address, you first need to know which element position contains that information. In short, in scenarios like the one above, lists, tuples, and sets are not the most suitable choices. At that point we need the **dictionary** type. This data type is best suited to assembling related information together, and it helps us solve the problem of modeling real things in Python programs.

The word "dictionary" should already be familiar. In elementary school, most people had a copy of the *Xinhua Dictionary* in hand, as shown below.

### Creating and Using Dictionaries

You can create a dictionary with `{}` and write each entry as `key: value`.

```python
xinhua = {
    'apple': 'a fruit',
    'route': 'a path from one place to another',
    'mint': 'a fragrant herb',
    'river': 'a natural flowing watercourse'
}
print(xinhua)
person = {
    'name': 'Wang Dachui',
    'age': 55,
    'height': 168,
    'weight': 60,
    'addr': 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu',
    'tel': '13122334455',
    'emergency_contact': '13800998877'
}
print(person)
```

Of course, if we want, we can also use the built-in function `dict` or dictionary-comprehension syntax to create dictionaries, as shown below.

```python
person = dict(name='Wang Dachui', age=55, height=168, weight=60, addr='No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu')
print(person)

items1 = dict(zip('ABCDE', '12345'))
print(items1)
items2 = dict(zip('ABCDE', range(1, 10)))
print(items2)

items3 = {x: x ** 3 for x in range(1, 6)}
print(items3)
```

Use `len` to get the number of key-value pairs. If you iterate over a dictionary with `for`, you iterate over its keys.

```python
person = {
    'name': 'Wang Dachui',
    'age': 55,
    'height': 168,
    'weight': 60,
    'addr': 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu'
}
print(len(person))
for key in person:
    print(key)
```

### Dictionary Operations

For dictionary types, membership operations and indexing operations are certainly very important. The former can determine whether a specified key is in the dictionary, and the latter can use a key to access the corresponding value or add a new key-value pair to the dictionary. It is worth noting that dictionary indexing is different from list indexing. Elements in a list have their own positions, so list indexes are integers; since dictionaries store key-value pairs, dictionaries use keys to index the corresponding values. It is **especially important** to remind everyone that **keys in a dictionary must be immutable types**, such as integers (`int`), floating-point numbers (`float`), strings (`str`), and tuples (`tuple`). This is the same requirement that sets impose on their elements. Clearly, the list (`list`) and set (`set`) types we talked about earlier cannot be used as keys in a dictionary, and the dictionary type itself cannot be used as a key in another dictionary, because dictionaries are mutable. But lists, sets, and dictionaries can all be used as values in a dictionary.

Keys must be immutable types such as `int`, `float`, `str`, or `tuple`. Lists, sets, and dictionaries cannot be keys, but they can be values.

```python
person = {
    'name': 'Wang Dachui',
    'age': 55,
    'height': 168,
    'weight': 60,
    'addr': ['No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu',
             'No.1 Baiwanzhuang Street, Xicheng District, Beijing'],
    'car': {
        'brand': 'BMW X7',
        'max_speed': '250',
        'length': 5170,
        'width': 2000,
        'height': 1835,
        'displacement': 3.0
    }
}
print(person)
```

Example usage:

```python
person = {'name': 'Wang Dachui', 'age': 55, 'height': 168, 'weight': 60, 'addr': 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu'}

print('name' in person)  # True
print('tel' in person)   # False

print(person['name'])
print(person['addr'])
person['age'] = 25
person['height'] = 178
person['tel'] = '13122334455'
person['signature'] = 'Your boyfriend is a total disaster.'
print(person)

for key in person:
    print(f'{key}:\t{person[key]}')
```

If you use a missing key with indexing, Python raises `KeyError`.

### Dictionary Methods

The `get` method returns the value for a key, but if the key does not exist, it returns `None` or a default value instead of raising an exception.

```python
person = {'name': 'Wang Dachui', 'age': 25, 'height': 178, 'addr': 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu'}
print(person.get('name'))
print(person.get('sex'))
print(person.get('sex', True))
```

Use `keys`, `values`, and `items` to access dictionary views.

```python
person = {'name': 'Wang Dachui', 'age': 25, 'height': 178}
print(person.keys())
print(person.values())
print(person.items())
for key, value in person.items():
    print(f'{key}:\t{value}')
```

Use `update` to merge dictionaries:

```python
person1 = {'name': 'Wang Dachui', 'age': 55, 'height': 178}
person2 = {'age': 25, 'addr': 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu'}
person1.update(person2)
print(person1)
```

In Python 3.9 and later, you can also use `|=`:

```python
person1 = {'name': 'Wang Dachui', 'age': 55, 'height': 178}
person2 = {'age': 25, 'addr': 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu'}
person1 |= person2
print(person1)
```

Use `pop`, `popitem`, `clear`, or `del` to remove entries:

```python
person = {'name': 'Wang Dachui', 'age': 25, 'height': 178, 'addr': 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu'}
print(person.pop('age'))
print(person)
print(person.popitem())
print(person)
person.clear()
print(person)
```

```python
person = {'name': 'Wang Dachui', 'age': 25, 'height': 178, 'addr': 'No.101, Building 1, 62 Kehua North Road, Wuhou District, Chengdu'}
del person['age']
del person['addr']
print(person)
```

### Dictionary Applications

Example 1: count the number of occurrences of each English letter in a sentence and print them in descending frequency order.

```python
sentence = input('Enter a sentence: ')
counter = {}
for ch in sentence:
    if 'A' <= ch <= 'Z' or 'a' <= ch <= 'z':
        counter[ch] = counter.get(ch, 0) + 1
sorted_keys = sorted(counter, key=counter.get, reverse=True)
for key in sorted_keys:
    print(f'{key} appears {counter[key]} times.')
```

Example 2: given a dictionary of stock symbols and prices, create a new dictionary containing only stocks priced above 100.

```python
stocks = {
    'AAPL': 191.88,
    'GOOG': 1186.96,
    'IBM': 149.24,
    'ORCL': 48.44,
    'ACN': 166.89,
    'FB': 208.09,
    'SYMC': 21.29
}
stocks2 = {key: value for key, value in stocks.items() if value > 100}
print(stocks2)
```

### Summary

Dictionaries in Python are very similar to dictionaries in real life. They allow us to **store data in the form of key-value pairs**, and then **use keys to access the corresponding values**. A dictionary is a data type that is very **convenient for data retrieval**, but it must be emphasized once again that **keys in a dictionary must be immutable types**. Data of types such as lists, sets, and dictionaries themselves cannot be used as dictionary keys.
