## Your First Python Program

In the previous lesson, we learned about Python's background and prepared the interpreter environment required to run Python programs. At this point you probably want to start coding as soon as possible. The next question is: where should we write Python code, and how do we run it?

### Tools for Writing Code

Let's look at several tools you can use to write and run Python code. You can choose whichever one fits your needs. For beginners, I personally recommend PyCharm because it is powerful and does not require much setup. If you already know you want to use PyCharm, you can skip ahead to that section.

#### The Default Interactive Environment

Open Command Prompt or PowerShell on Windows, type `python`, and press `Enter`. This takes you into an interactive environment. In an interactive environment, you enter one line of code at a time, press `Enter`, and the code is executed immediately. If it produces a result, the result is displayed right away.

```Bash
Python 3.10.10
Type "help", "copyright", "credits" or "license" for more information.
>>> 2 * 3
6
>>> 2 + 3
5
>>>
```

> **Note**: On macOS, open the Terminal app and use `python3` to enter the interactive environment.

To leave the interactive environment, type `quit()`.

```Bash
>>> quit()
```

#### A Better Interactive Environment: IPython

The default interactive environment is serviceable, but the experience is limited. IPython is a better replacement because it offers more powerful editing and interaction features. You can install it with Python's package manager, `pip`.

```bash
pip install ipython
```

After installation, you can launch IPython with the command below.

```bash
ipython
```

> **Note**: There is also a browser-based form of IPython called Jupyter. We will introduce it when we need it.

#### A Great Code Editor: Visual Studio Code

Visual Studio Code is a code editor developed by Microsoft that runs on Windows, Linux, and macOS. It supports syntax highlighting, auto-completion, multi-cursor editing, running and debugging, and many other useful features. It also supports many programming languages. If you want a capable general-purpose editor, Visual Studio Code is an excellent choice. If you are interested, you can explore its [download page](https://code.visualstudio.com/), installation steps, and usage on your own.

### Hello, World

By long-standing convention, the first program you write in a new programming language prints `hello, world`. The tradition comes from *The C Programming Language* by Dennis Ritchie and Brian Kernighan. Here is the Python version.

```python
print('hello, world')
```

> **Note**: The parentheses and quotes in the code above must be entered with an English keyboard layout. If you accidentally use full-width Chinese punctuation, you may get errors such as `SyntaxError: invalid character '（' (U+FF08)` or `SyntaxError: invalid character '‘' (U+2018)`.

The code above contains only one statement. It uses a function named `print`, which outputs the specified content. The text inside the parentheses, `'hello, world'`, is a string. In Python, strings can be written with either single or double quotes. Unlike C, C++, or Java, Python statements do not need semicolons at the end. If you want to add another statement, you can just put it on the next line. Python also does not require a `main` entry function to run a simple program.

```python
print('hello, world')
print('goodbye, world')
```

Even without an IDE like PyCharm, you can run a Python program directly with the interpreter. Save the code above to a file named `example01.py`. On Windows, assuming the file is in `C:\code`, open Command Prompt or PowerShell and run:

```powershell
python C:\code\example01.py
```

On macOS, assuming the file is in `/Users/Hao`, run:

```Bash
python3 /Users/Hao/example01.py
```

> **Tip**: If the file path is long, you can drag the file into Command Prompt or Terminal and the full path will be inserted automatically.

Try changing the code above. Replace `hello, world` with something else or add more `print` statements to see what happens. A good habit is to write only one statement per line. Although Python lets you place multiple statements on one line separated by `;`, doing so makes the code much harder to read.

### Comments in Code

Comments are an important part of programming. They are used to explain what code does and make it easier to understand. You can also comment out code temporarily when you do not want it to run. In short, **comments improve readability but do not affect execution**.

Python supports two common forms of comments:

1. Single-line comments: start with `#` followed by a space and comment out the rest of the line.
2. Multi-line comments: usually written using triple quotes and used for explanatory text spanning multiple lines.

```python
"""
Your first Python program - hello, world

Version: 1.0
Author: Luo Hao
"""
# print('hello, world')
print("Hello, world!")
```
