### Tools for Writing Code

#### The Default Interactive Environment

We open Windows Command Prompt or PowerShell, enter `python`, and then press the `Enter` key. This command will take us into an interactive environment. A so-called interactive environment means that we enter one line of code and press `Enter`, and the code is executed at once. If the code produces a result, then the result will be shown in the window, as shown below.

```Bash
Python 3.10.10
Type "help", "copyright", "credits" or "license" for more information.
>>> 2 * 3
6
>>> 2 + 3
5
>>>
```

> **Note**: Users of macOS need to open Terminal and enter `python3` to enter the interactive environment.

If you want to leave the interactive environment, you can enter `quit()` in the interactive environment, as shown below.

```Bash
>>> quit()
```

#### A Better Interactive Environment - IPython

The user experience of the interactive environment mentioned above is not very good, and everyone can feel this after trying it. We can use IPython to replace it, because IPython provides more powerful editing and interaction functions. We can use Python's package management tool `pip` in Command Prompt or Terminal to install IPython, as shown below.

```bash
pip install ipython
```

> **Tip**: Before using the command above to install IPython, you can first use `pip config set global.index-url https://pypi.doubanio.com/simple` or `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple/` to change the download source to the Douban mirror or Tsinghua mirror in China. Otherwise, the process of downloading and installing may be very slow.

Next, you can use the command below to start IPython and enter the interactive environment.

```bash
ipython
```

> **Note**: There is also a web version of IPython called Jupyter. We will introduce it when we need to use it.

### Hello, World

According to industry practice, the first program we write when learning any programming language is to output `hello, world`, because this line of code was the first piece of code written by the great Dennis Ritchie (the father of the C language, who developed the Unix operating system together with Ken Thompson) and Brian Kernighan (the inventor of the awk language) in their immortal book *The C Programming Language*. Below is the Python version.

```python
print('hello, world')
```

> **Note**: The parentheses and single quotes in the code above are all entered when the input method is in English mode. If you accidentally write Chinese parentheses or Chinese single quotes, error messages such as `SyntaxError: invalid character '（' (U+FF08)` or `SyntaxError: invalid character '‘' (U+2018)` will appear when running the code.

The code above has only one statement. In this statement, we use a function named `print`, and it can help us output the specified content. The `'hello, world'` inside the parentheses of the `print` function is a string, and it represents a piece of text content. In Python, we can use single quotes or double quotes to represent a string. Different from programming languages such as C, C++, or Java, statements in Python code do not need semicolons to show the end. In other words, if we want to write one more statement, we only need to press Enter and start a new line, as shown below. Also, Python code does not need an entry function named `main` to make it run. Providing an entry function is something that must be done when writing executable C, C++, or Java code, and many programmers are familiar with this, but in Python it is not necessary.

```python
print('hello, world')
print('goodbye, world')
```

If we do not use an integrated development environment like PyCharm, we can also directly call the Python interpreter to run a Python program. We can save the code above as a file named `example01.py`. For Windows, let us suppose the file is under `C:\code`. We open Command Prompt or PowerShell and enter the command below, and then we can run it.

```powershell
python C:\code\example01.py
```

For macOS, suppose our file is under `/Users/Hao`, then we can enter the command below in Terminal to run the program.

```Bash
python3 /Users/Hao/example01.py
```

> **Tip**: If the path is long and you do not want to type it by hand, we can drag the file directly into Command Prompt or Terminal, and this will automatically enter the full file path.

Everyone can try changing the code above. For example, replace `hello, world` inside the single quotes with other content, or write a few more statements like this, and see what kind of result will run out. One reminder for everyone is that when writing Python code, it is best to write only one statement on each line. Although we can use `;` as a separator to write multiple statements on one line, doing so will make the code look very ugly and it will no longer have good readability.

### Comment Your Code

Comments are an important part of programming languages. They are used to explain what the code does inside the code, so as to improve the readability of the code. Of course, we can also use comments to remove code that does not need to run for the moment. Then, when you need to use that code again, you only need to remove the comment markers. Simply speaking, **comments make the code easier to understand, but they do not affect the execution result of the code**.

Python has two forms of comments:

1. Single-line comments: start with `#` and a space, and can comment out the whole line of content after `#`.
2. Multi-line comments: start with triple quotes (usually double quotes) and end with triple quotes, and are usually used to add multi-line explanatory content.

```python
"""
Your first Python program - hello, world

Version: 1.0
Author: Luo Hao
"""
# print('hello, world')
print("Hello, world!")
```
