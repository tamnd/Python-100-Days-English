## Branching

So far, every Python program we have written has executed statements one after another from top to bottom. That style is called **sequential structure**. But sequential execution alone cannot solve every problem. Imagine a game where the player needs at least 1000 points to pass the first level. After the level ends, the game must decide whether to send the player to the next level or show `Game Over`. In that situation, the code has two possible paths, and only one of them will be taken. That is what we call a **branching structure** or **selection structure**.

### Building Branches with `if` and `else`

In Python, the keywords most commonly used for branching are `if`, `elif`, and `else`. A **keyword** is a word with special meaning in the language, so it cannot be used as a variable name. Of course, not every branch uses all three keywords. Let us look at an example: a BMI calculator.

BMI, or Body Mass Index, is an internationally used indicator for judging body weight and general health. Its formula is:

$$
BMI = \frac{weight}{height^{2}}
$$

It is usually considered normal when $\small{18.5 \le BMI < 24}$. If $\small{BMI < 18.5}$, the person is underweight. If $\small{BMI \ge 24}$, the person is overweight. If $\small{BMI \ge 27}$, the person is considered obese.

> **Note**: In the formula above, weight is measured in kilograms and height in meters.

```python
"""
BMI calculator

Version: 1.0
Author: Luo Hao
"""
height = float(input('Height (cm): '))
weight = float(input('Weight (kg): '))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')
if 18.5 <= bmi < 24:
    print('Your body shape looks great!')
```

> **Tip**: The `:` at the end of the `if` line must be the normal ASCII colon typed with an English keyboard layout. The same is true for `'`, `"`, `=`, `(`, and `)`. Beginners often overlook this and then run into confusing syntax errors.

In the program above, after calculating and printing BMI, we added a branch. If $\small{18.5 \le BMI < 24}$ is true, the program prints `Your body shape looks great!`. Otherwise, that line is skipped. This shows that code can follow different execution paths. The condition after `if` is the expression `18.5 <= bmi < 24`. As we discussed earlier, comparison operators produce Boolean values. If the condition is `True`, the indented statement below the `if` line will run.

Sample inputs:

First input:

```
Height (cm): 175
Weight (kg): 68
bmi = 22.2
Your body shape looks great!
```

Second input:

```
Height (cm): 175
Weight (kg): 95
bmi = 31.0
```

Third input:

```
Height (cm): 175
Weight (kg): 50
bmi = 16.3
```

Only the first example produces a BMI in the range from 18.5 to 24, so only that case triggers the message. Unlike C, C++, or Java, Python does not use braces to define code blocks. Instead, it **uses indentation to represent code structure**. If multiple statements should run when the condition is true, they must share the same indentation level. By convention, Python code uses **4 spaces** for indentation. Avoid using the Tab key directly if possible.

The expression `18.5 <= bmi < 24` is also one of Python's nice features. In some other languages, you would need to write it as `bmi >= 18.5 && bmi < 24`. Python allows the cleaner chained comparison.

Here is the equivalent Java version of the BMI calculator:

```java
import java.util.Scanner;

class Test {

    public static void main(String[] args) {
        try (Scanner sc = new Scanner(System.in)) {
            System.out.print("Height(cm): ");
            double height = sc.nextDouble();
            System.out.print("Weight(kg): ");
            double weight = sc.nextDouble();
            double bmi = weight / Math.pow(height / 100, 2);
            System.out.printf("bmi = %.1f\n", bmi);
            if (bmi >= 18.5 && bmi < 24) {
                System.out.println("Your body shape looks great!");
            }
        }
    }
}
```

> **Note**: That is the Java version of BMI Calculator 1.0. Python often solves the same problem with less code, which is one reason many people like it.

Next, let us improve the program so it also prints a message when BMI is outside the ideal range. We can add an `else` block.

```python
"""
BMI calculator

Version: 1.1
Author: Luo Hao
"""
height = float(input('Height (cm): '))
weight = float(input('Weight (kg): '))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')
if 18.5 <= bmi < 24:
    print('Your body shape looks great!')
else:
    print('Your body shape is outside the ideal range.')
```

If we want more precise feedback, we can add more branches using `elif`.

```python
"""
BMI calculator

Version: 1.2
Author: Luo Hao
"""
height = float(input('Height (cm): '))
weight = float(input('Weight (kg): '))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')
if bmi < 18.5:
    print('You are underweight!')
elif bmi < 24:
    print('Your body shape looks great!')
elif bmi < 27:
    print('You are overweight!')
elif bmi < 30:
    print('You are mildly obese!')
elif bmi < 35:
    print('You are moderately obese!')
else:
    print('You are severely obese!')
```

### Building Branches with `match` and `case`

Python 3.10 introduced another way to build multi-branch logic: `match` and `case`. The official Python documentation uses HTTP status codes as an example, which is a good fit for this syntax. First, here is the traditional `if-elif-else` version:

```python
status_code = int(input('Status code: '))
if status_code == 400:
    description = 'Bad Request'
elif status_code == 401:
    description = 'Unauthorized'
elif status_code == 403:
    description = 'Forbidden'
elif status_code == 404:
    description = 'Not Found'
elif status_code == 405:
    description = 'Method Not Allowed'
elif status_code == 418:
    description = 'I am a teapot'
elif status_code == 429:
    description = 'Too many requests'
else:
    description = 'Unknown status code'
print('Description:', description)
```

Output:

```
Status code: 403
Description: Forbidden
```

Now here is the `match-case` version. It does the same thing, but the code looks cleaner.

```python
status_code = int(input('Status code: '))
match status_code:
    case 400: description = 'Bad Request'
    case 401: description = 'Unauthorized'
    case 403: description = 'Forbidden'
    case 404: description = 'Not Found'
    case 405: description = 'Method Not Allowed'
    case 418: description = 'I am a teapot'
    case 429: description = 'Too many requests'
    case _: description = 'Unknown status code'
print('Description:', description)
```

> **Note**: The `case _` branch acts like a wildcard. If none of the previous branches match, Python falls back to that case. It is optional, but if you use it, it must appear last.

`match-case` also supports pattern merging. For example:

```python
status_code = int(input('Status code: '))
match status_code:
    case 400 | 405: description = 'Invalid Request'
    case 401 | 403 | 404: description = 'Not Allowed'
    case 418: description = 'I am a teapot'
    case 429: description = 'Too many requests'
    case _: description = 'Unknown status code'
print('Description:', description)
```

Output:

```
Status code: 403
Description: Not Allowed
```

### Applications of Branching

#### Example 1: Piecewise Function Evaluation

Given the piecewise function below, read `x` and compute `y`.

$$
y = \begin{cases} 3x - 5, & (x \gt 1) \\\\ x + 2, & (-1 \le x \le 1) \\\\ 5x + 3, & (x \lt -1) \end{cases}
$$

```python
"""
Evaluate a piecewise function

Version: 1.0
Author: Luo Hao
"""
x = float(input('x = '))
if x > 1:
    y = 3 * x - 5
elif x >= -1:
    y = x + 2
else:
    y = 5 * x + 3
print(f'{y = }')
```

Branching can be nested. That means you can place an `if` statement inside another `if`, `elif`, or `else` block. The same example can be written this way:

```python
"""
Evaluate a piecewise function

Version: 1.1
Author: Luo Hao
"""
x = float(input('x = '))
if x > 1:
    y = 3 * x - 5
else:
    if x >= -1:
        y = x + 2
    else:
        y = 5 * x + 3
print(f'{y = }')
```

> **Note**: The Zen of Python includes the line `Flat is better than nested.` Deep nesting usually makes code harder to read, so the first version is generally better.

#### Example 2: Convert a Numerical Score to a Letter Grade

If the score is at least 90, output `A`. If it is at least 80 but below 90, output `B`. If it is at least 70 but below 80, output `C`. If it is at least 60 but below 70, output `D`. Otherwise output `E`.

```python
"""
Convert a numerical score to a letter grade

Version: 1.0
Author: Luo Hao
"""
score = float(input('Enter the score: '))
if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'
elif score >= 70:
    grade = 'C'
elif score >= 60:
    grade = 'D'
else:
    grade = 'E'
print(f'{grade = }')
```

#### Example 3: Calculate the Perimeter and Area of a Triangle

Read the lengths of three sides. If they can form a triangle, calculate the perimeter and area. Otherwise, print a message saying that a triangle cannot be formed.

```python
"""
Calculate the perimeter and area of a triangle

Version: 1.0
Author: Luo Hao
"""
a = float(input('a = '))
b = float(input('b = '))
c = float(input('c = '))
if a + b > c and a + c > b and b + c > a:
    perimeter = a + b + c
    print(f'Perimeter: {perimeter}')
    s = perimeter / 2
    area = (s * (s - a) * (s - b) * (s - c)) ** 0.5
    print(f'Area: {area}')
else:
    print('A triangle cannot be formed')
```

> **Note**: The condition in the `if` statement checks whether the sum of any two sides is greater than the third side, which is the necessary condition for forming a triangle. The area formula used above is Heron's formula.
