## Operators in Python

Python supports many different operators. The table below lists them in order of precedence, from high to low. Once you have variables and operators, you can build expressions to solve real problems. In computer science, **an expression is a syntactic construct made up of constants, variables, functions, and operators that can be evaluated to produce another value**. You do not need to memorize that definition, but you should understand one thing clearly: building expressions is a core skill in every programming language.

| Operator | Description |
| --- | --- |
| `[]`, `[:]` | indexing, slicing |
| `**` | exponentiation |
| `~`, `+`, `-` | bitwise NOT, unary plus, unary minus |
| `*`, `/`, `%`, `//` | multiplication, division, modulo, floor division |
| `+`, `-` | addition, subtraction |
| `>>`, `<<` | right shift, left shift |
| `&` | bitwise AND |
| `^`, `|` | bitwise XOR, bitwise OR |
| `<=`, `<`, `>`, `>=` | comparison operators |
| `==`, `!=` | equal to, not equal to |
| `is`, `is not` | identity operators |
| `in`, `not in` | membership operators |
| `not`, `or`, `and` | logical operators |
| `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `//=`, `**=`, `&=`, `|=`, `^=`, `>>=`, `<<=` | assignment operators |

> **Note**: Precedence determines which operation is evaluated first when an expression contains multiple operators. If you are unsure about precedence, use parentheses to make the evaluation order explicit.

### Arithmetic Operators

Python has a rich set of arithmetic operators. In addition to addition, subtraction, multiplication, and division, it also provides floor division, modulo, and exponentiation.

```python
"""
Arithmetic operators

Version: 1.0
Author: Luo Hao
"""
print(321 + 12)     # addition -> 333
print(321 - 12)     # subtraction -> 309
print(321 * 12)     # multiplication -> 3852
print(321 / 12)     # division -> 26.75
print(321 // 12)    # floor division -> 26
print(321 % 12)     # modulo -> 9
print(321 ** 12)    # exponentiation
```

As in mathematics, multiplication and division are evaluated before addition and subtraction. Exponentiation has higher precedence than multiplication and division. If you want to change the evaluation order, use parentheses.

```python
"""
Operator precedence in arithmetic

Version: 1.0
Author: Luo Hao
"""
print(2 + 3 * 5)           # 17
print((2 + 3) * 5)         # 25
print((2 + 3) * 5 ** 2)    # 125
print(((2 + 3) * 5) ** 2)  # 625
```

### Assignment Operators

Assignment is one of the most common operations in programming. Its purpose is to store the value on the right-hand side in the variable on the left-hand side. Assignment can also be combined with arithmetic operators to form compound assignment operators. For example, `a += b` is equivalent to `a = a + b`, and `a *= a + 2` is equivalent to `a = a * (a + 2)`.

```python
"""
Assignment and compound assignment operators

Version: 1.0
Author: Luo Hao
"""
a = 10
b = 3
a += b        # equivalent to a = a + b
a *= a + 2    # equivalent to a = a * (a + 2)
print(a)      # try to work out the result yourself
```

An assignment expression does not produce a value you can print directly. To address that limitation, Python 3.8 introduced the `:=` operator, commonly called the walrus operator. It both assigns a value and yields that value as the result of the expression.

```python
"""
The walrus operator

Version: 1.0
Author: Luo Hao
"""
# SyntaxError: invalid syntax
# print((a = 10))
print((a := 10))  # 10
print(a)          # 10
```

> **Tip**: If you remove the comment from `print((a = 10))`, Python will raise `SyntaxError: invalid syntax`. If you accidentally write `print(a = 10)`, you will get `TypeError: 'a' is an invalid keyword argument for print()`.

### Comparison and Logical Operators

Comparison operators include `==`, `!=`, `<`, `>`, `<=`, and `>=`. Equality uses `==`, not `=`. Remember that `=` is the assignment operator. The operator `!=` means "not equal to". In Python 2, `<>` was also accepted, but in Python 3 it raises a syntax error. Comparison operators produce Boolean values: either `True` or `False`.

There are three logical operators: `and`, `or`, and `not`.

- `and` returns `True` only if both sides are true.
- `or` returns `True` if at least one side is true.
- `not` reverses a Boolean value.

Both `and` and `or` use short-circuit evaluation. That means Python may skip evaluating the right-hand side if the result is already determined by the left-hand side.

```python
"""
Comparison and logical operators

Version: 1.0
Author: Luo Hao
"""
flag0 = 1 == 1
flag1 = 3 > 2
flag2 = 2 < 1
flag3 = flag1 and flag2
flag4 = flag1 or flag2
flag5 = not flag0
print('flag0 =', flag0)     # flag0 = True
print('flag1 =', flag1)     # flag1 = True
print('flag2 =', flag2)     # flag2 = False
print('flag3 =', flag3)     # flag3 = False
print('flag4 =', flag4)     # flag4 = True
print('flag5 =', flag5)     # flag5 = False
print(flag1 and not flag2)  # True
print(1 > 2 or 2 == 3)      # False
```

> **Note**: Comparison operators have higher precedence than assignment. So in `flag0 = 1 == 1`, Python evaluates `1 == 1` first, gets `True`, and then assigns that value to `flag0`. The `print` function can output multiple values separated by commas, and they are separated by spaces by default.

### Applying Operators and Expressions

#### Example 1: Convert Fahrenheit to Celsius

> **Task**: Read a Fahrenheit temperature and convert it to Celsius using the formula $\small{C = (F - 32) / 1.8}$.

```python
"""
Convert Fahrenheit to Celsius

Version: 1.0
Author: Luo Hao
"""
f = float(input('Enter Fahrenheit: '))
c = (f - 32) / 1.8
print('%.1fF = %.1fC' % (f, c))
```

> **Note**: The `input` function reads data from the keyboard and returns a string. If you want to do arithmetic with the value, you must convert it first, such as with `float`.

The output above uses old-style `%` formatting. The placeholders `%.1f` are replaced with the floating-point values from `(f, c)`, each rounded to one decimal place. `%d` is used for integers and `%s` for strings.

Python also supports f-strings, which are often clearer.

```python
"""
Convert Fahrenheit to Celsius

Version: 1.1
Author: Luo Hao
"""
f = float(input('Enter Fahrenheit: '))
c = (f - 32) / 1.8
print(f'{f:.1f}F = {c:.1f}C')
```

#### Example 2: Calculate the Circumference and Area of a Circle

> **Task**: Read a circle's radius $\small{r}$ and calculate its circumference $\small{2 \pi r}$ and area $\small{\pi r^{2}}$.

```python
"""
Calculate the circumference and area of a circle

Version: 1.0
Author: Luo Hao
"""
radius = float(input('Enter the radius: '))
perimeter = 2 * 3.1416 * radius
area = 3.1416 * radius * radius
print('Perimeter: %.2f' % perimeter)
print('Area: %.2f' % area)
```

Python has a built-in module named `math`, which defines the constant `pi`. If you want to use that value, modify the code as follows:

```python
"""
Calculate the circumference and area of a circle

Version: 1.1
Author: Luo Hao
"""
import math

radius = float(input('Enter the radius: '))
perimeter = 2 * math.pi * radius
area = math.pi * radius ** 2
print(f'Perimeter: {perimeter:.2f}')
print(f'Area: {area:.2f}')
```

> **Note**: `import math` imports the `math` module. Only after importing it can you access `math.pi`.

Python 3.8 also introduced a convenient output format that prints both the variable name and its value.

```python
"""
Calculate the circumference and area of a circle

Version: 1.2
Author: Luo Hao
"""
import math

radius = float(input('Enter the radius: '))  # input: 5.5
perimeter = 2 * math.pi * radius
area = math.pi * radius ** 2
print(f'{perimeter = :.2f}')  # output: perimeter = 34.56
print(f'{area = :.2f}')       # output: area = 95.03
```

> **Note**: If `a = 9.87`, then `f'{a = }'` becomes `a = 9.87`, while `f'{a = :.1f}'` becomes `a = 9.9`.

#### Example 3: Determine Whether a Year Is a Leap Year

Read a year later than 1582 and determine whether it is a leap year.

```python
"""
Read a year and output True for a leap year, False otherwise

Version: 1.0
Author: Luo Hao
"""
year = int(input('Enter a year: '))
is_leap = year % 4 == 0 and year % 100 != 0 or year % 400 == 0
print(f'{is_leap = }')
```

> **Note**: In the Gregorian calendar used today, a year is a leap year if it is divisible by 4 but not by 100, unless it is also divisible by 400. The Gregorian calendar was introduced in October 1582, so keep that in mind when choosing test values.
