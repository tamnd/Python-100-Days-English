## Common Data Structures: Sets

After learning about lists and tuples, let us study another container type, called the **set**. Everyone should already be familiar with the word "set," because it exists in mathematics textbooks. If we **treat a collection of objects within a certain scope that are definite and distinguishable as a whole**, then that whole is a set, and each object in the set is called an **element** of the set.

A set usually has these properties:

1. **Unordered**: elements do not have positions.
2. **Unique**: duplicate elements are not allowed.
3. **Definite membership**: for any given element, it either belongs to the set or it does not.

Sets in Python are not essentially different from sets in mathematics. What especially needs to be emphasized are the unordered and unique properties mentioned above. Unordered means that the elements in a set do not have an order like the elements in a list, so you cannot access arbitrary elements through indexing. **Sets do not support indexing operations**. In addition, the uniqueness of sets determines that **sets cannot contain duplicate elements**, and that is also one way in which sets differ from lists. We cannot add duplicate elements to a set. Sets certainly support the membership operations `in` and `not in`, which make it possible to determine whether an element belongs to a set. That corresponds to the certainty mentioned above. **Membership testing on sets performs better than membership testing on lists**, and that is determined by the underlying storage characteristics of sets. We will not discuss that for the moment; just remember the conclusion.

- A set is **unordered**, so it does not support indexing.
- A set contains **no duplicates**.

### Creating Sets

In Python, you can create a set with the literal syntax `{}`, but there must be at least one element inside `{}`. That is because `{}` without any elements is not an empty set but an empty dictionary, and we will introduce dictionaries in the next lesson. Of course, you can also use Python's built-in `set` function to create a set. More precisely, `set` is not an ordinary function but a constructor that creates set objects. We will introduce this point later when discussing object-oriented programming. We can use the `set` function to create an empty set, and we can also use it to convert other sequences into sets. For example, `set('hello')` gives a set containing `4` characters, because the repeated character `l` appears only once in the set. In addition to these two approaches, you can also use comprehension syntax to create a set, just as we previously used comprehension syntax to create lists.

```python
set1 = {1, 2, 3, 3, 3, 2}
print(set1)

set2 = {'banana', 'pitaya', 'apple', 'apple', 'banana', 'grape'}
print(set2)

set3 = set('hello')
print(set3)

set4 = set([1, 2, 2, 3, 3, 3, 2, 1])
print(set4)

set5 = {num for num in range(1, 20) if num % 3 == 0 or num % 7 == 0}
print(set5)
```

It should be pointed out that elements in a set must be of a **hashable** type. A so-called hashable type is a data type for which a hash code can be computed. Usually, immutable types are hashable, such as integers (`int`), floating-point numbers (`float`), Boolean values (`bool`), strings (`str`), and tuples (`tuple`). Mutable types are not hashable, because mutable types cannot produce a stable hash code, so they cannot be placed into a set. For example, we cannot use a list as an element of a set; similarly, since a set itself is also mutable, a set cannot be used as an element of another set. We can create nested lists, where the elements of a list are also lists, but we cannot create nested sets. This point must be kept in mind when using sets.

### Iterating Over Sets

You can use `len` to get the number of elements in a set, but you cannot access elements by index. To iterate over them, use a `for-in` loop.

```python
set1 = {'Python', 'C++', 'Java', 'Kotlin', 'Swift'}
for elem in set1:
    print(elem)
```

The output order is not guaranteed.

### Set Operations

Python supports rich set operations: membership, intersection, union, difference, symmetric difference, equality, subset, and superset checks.

#### Membership

```python
set1 = {11, 12, 13, 14, 15}
print(10 in set1)      # False
print(15 in set1)      # True
set2 = {'Python', 'Java', 'C++', 'Swift'}
print('Ruby' in set2)  # False
print('Java' in set2)  # True
```

#### Binary Operations

<img src="res/day12/set_operations.png" style="zoom:50%;">

```python
set1 = {1, 2, 3, 4, 5, 6, 7}
set2 = {2, 4, 6, 8, 10}

print(set1 & set2)                      # intersection
print(set1.intersection(set2))

print(set1 | set2)                      # union
print(set1.union(set2))

print(set1 - set2)                      # difference
print(set1.difference(set2))

print(set1 ^ set2)                      # symmetric difference
print(set1.symmetric_difference(set2))
```

These operations also support compound assignment:

```python
set1 = {1, 3, 5, 7}
set2 = {2, 4, 6}
set1 |= set2
print(set1)  # {1, 2, 3, 4, 5, 6, 7}
set3 = {3, 6, 9}
set1 &= set3
print(set1)  # {3, 6}
set2 -= set1
print(set2)  # {2, 4}
```

#### Comparison

Two sets can be compared with `==` and `!=`. You can also check subset and superset relationships with `<`, `<=`, `>`, and `>=`, or with `issubset` and `issuperset`.

```python
set1 = {1, 3, 5}
set2 = {1, 2, 3, 4, 5}
set3 = {5, 4, 3, 2, 1}

print(set1 < set2)   # True
print(set1 <= set2)  # True
print(set2 < set3)   # False
print(set2 <= set3)  # True
print(set2 > set1)   # True
print(set2 == set3)  # True

print(set1.issubset(set2))
print(set2.issuperset(set1))
```

### Set Methods

Sets are mutable, so we can add or remove elements.

```python
set1 = {1, 10, 100}

set1.add(1000)
set1.add(10000)
print(set1)

set1.discard(10)
if 100 in set1:
    set1.remove(100)
print(set1)

set1.clear()
print(set1)  # set()
```

> **Note**: `remove` raises `KeyError` if the element is missing, while `discard` does not. There is also a `pop` method that removes and returns a random element.

Use `isdisjoint` to test whether two sets have no common elements.

```python
set1 = {'Java', 'Python', 'C++', 'Kotlin'}
set2 = {'Kotlin', 'Swift', 'Java', 'Dart'}
set3 = {'HTML', 'CSS', 'JavaScript'}
print(set1.isdisjoint(set2))  # False
print(set1.isdisjoint(set3))  # True
```

### Immutable Sets

Python also has an immutable set type called `frozenset`. Its relationship to `set` is similar to the relationship between `tuple` and `list`.

```python
fset1 = frozenset({1, 3, 5, 7})
fset2 = frozenset(range(1, 6))
print(fset1)
print(fset2)
print(fset1 & fset2)
print(fset1 | fset2)
print(fset1 - fset2)
print(fset1 < fset2)
```

Because `frozenset` is immutable and hashable, it can itself be used as a set element.

### Summary

In Python, the **set type is an unordered container** and **does not allow duplicate elements**. Because the underlying implementation uses hashing, the elements in a set must be hashable types. The biggest difference between a set and a list is that **the elements in a set have no order**, so **you cannot access elements through indexing operations**. However, sets can perform binary operations such as intersection, union, and difference, and can also use relational operators to check whether two sets have subset or superset relationships.
