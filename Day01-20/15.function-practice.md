## Practical Function Examples

### Example 1: Random Verification Code

Design a function that generates a random verification code. The verification code is made up of digits and uppercase/lowercase English letters, and the length can be set through a parameter.

```python
import random
import string

ALL_CHARS = string.digits + string.ascii_letters


def generate_code(*, code_len=4):
    """
    Generate a verification code of the specified length.
    :param code_len: The length of the code (default: 4)
    :return: A random verification code string containing digits and letters
    """
    return ''.join(random.choices(ALL_CHARS, k=code_len))
```

> **Note 1**: `string.digits` is the string `'0123456789'`, and `string.ascii_letters` contains all lowercase and uppercase English letters.
>
> **Note 2**: Both `random.sample` and `random.choices` perform sampling. `sample` performs sampling without replacement, while `choices` performs sampling with replacement. The `k` parameter of `choices` is keyword-only.

We can use the code below to generate 5 groups of random verification codes to test the function above.

```python
for _ in range(5):
    print(generate_code())
```

Or:

```python
for _ in range(5):
    print(generate_code(code_len=6))
```

### Example 2: Check for Prime Numbers

Design a function that determines whether a positive integer greater than 1 is prime. A prime number is a positive integer greater than 1 that is divisible only by 1 and itself. If a positive integer $\small{N}$ greater than 1 is prime, that means there are no factors of it between `2` and $\small{N-1}$.

```python
def is_prime(num: int) -> bool:
    """
    Determine whether a positive integer is prime.
    :param num: A positive integer greater than 1
    :return: True if num is prime, otherwise False
    """
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False
    return True
```

> **Note 1**: The `: int` after the parameter `num` above is used to annotate the parameter type. Although it does not affect the execution result of the code, it greatly improves readability. Likewise, the `-> bool` after the parameter list is used to annotate the return type of the function. It also does not affect the execution result, but it makes it clear that calling the function returns a Boolean value, either `True` or `False`.
>
> **Note 2**: The loop above does not need to go from `2` all the way to $\small{N-1}$, because if by the time the loop reaches $\small{\sqrt{N}}$ we still have not found a factor of $\small{N}$, then no factor of $\small{N}$ will appear after $\small{\sqrt{N}}$. You can think for yourself about why that is.

### Example 3: Greatest Common Divisor and Least Common Multiple

Design functions to compute the greatest common divisor and the least common multiple of two positive integers. The greatest common divisor of $\small{x}$ and $\small{y}$ is the largest integer that can divide both $\small{x}$ and $\small{y}$ exactly. If $\small{x}$ and $\small{y}$ are coprime, then their greatest common divisor is 1. The least common multiple of $\small{x}$ and $\small{y}$ is the smallest positive integer that is divisible by both $\small{x}$ and $\small{y}$. If $\small{x}$ and $\small{y}$ are coprime, then their least common multiple is $\small{x \times y}$. It should be noted that computing the greatest common divisor and computing the least common multiple are two different functions, so we should design them as two functions, instead of putting both functions into one function.

```python
def lcm(x: int, y: int) -> int:
    """Compute the least common multiple."""
    return x * y // gcd(x, y)


def gcd(x: int, y: int) -> int:
    """Compute the greatest common divisor."""
    while y % x != 0:
        x, y = y % x, x
    return x
```

> **Note**: Functions can call each other. The `lcm` function above calls the `gcd` function and uses $\frac{x \times y}{gcd(x, y)}$ to calculate the least common multiple.

### Example 4: Data Statistics

Suppose sample data is saved in a list. Design functions to compute the descriptive statistics of sample data. Descriptive statistics usually include arithmetic mean, median, range, variance, standard deviation, coefficient of variation, and so on.

```python
def ptp(data):
    """Range."""
    return max(data) - min(data)


def mean(data):
    """Arithmetic mean."""
    return sum(data) / len(data)


def median(data):
    """Median."""
    temp, size = sorted(data), len(data)
    if size % 2 != 0:
        return temp[size // 2]
    else:
        return mean(temp[size // 2 - 1:size // 2 + 1])


def var(data, ddof=1):
    """Variance."""
    x_bar = mean(data)
    temp = [(num - x_bar) ** 2 for num in data]
    return sum(temp) / (len(temp) - ddof)


def std(data, ddof=1):
    """Standard deviation."""
    return var(data, ddof) ** 0.5


def cv(data, ddof=1):
    """Coefficient of variation."""
    return std(data, ddof) / mean(data)


def describe(data):
    """Print descriptive statistics."""
    print(f'Mean: {mean(data)}')
    print(f'Median: {median(data)}')
    print(f'Range: {ptp(data)}')
    print(f'Variance: {var(data)}')
    print(f'Standard deviation: {std(data)}')
    print(f'Coefficient of variation: {cv(data)}')
```

> **Note 1**: The median is the number in the middle after sorting the data in ascending or descending order, and it describes the middle level of the data. There are two cases when calculating the median: when the number of data points $\small{n}$ is odd, the median is the element at position $\frac{n + 1}{2}$; when the number of data points $\small{n}$ is even, the median is the average of the elements at positions $\frac{n}{2}$ and $\frac{n}{2} + 1`.
>
> **Note 2**: The parameter `ddof` stands for delta degrees of freedom. For sample variance and sample standard deviation, the default correction is `1`. For population statistics, you can set it to `0`.
>
> **Note 3**: The `describe` function puts the statistics functions above together and is used to output the descriptive statistics of the data. In fact, Python's standard library has a module named `statistics`, and it has already packaged functions for getting descriptive statistics. Interested readers can look into it by themselves.

### Example 5: Double Color Ball Lottery Number Generator

Let us use functions to refactor the Double Color Ball example from an earlier lesson by packaging the function for generating random numbers and the function for outputting one group of numbers into two functions, and then realize the function of randomly generating `N` bets by calling functions.

```python
"""
Random number generator for Double Color Ball

Author: Luo Hao
Version: 1.3
"""
import random

RED_BALLS = [i for i in range(1, 34)]
BLUE_BALLS = [i for i in range(1, 17)]


def choose():
    """
    Generate one random ticket.
    :return: A list containing the selected numbers
    """
    selected_balls = random.sample(RED_BALLS, 6)
    selected_balls.sort()
    selected_balls.append(random.choice(BLUE_BALLS))
    return selected_balls


def display(balls):
    """
    Print one ticket in a formatted way.
    :param balls: A list containing the selected numbers
    """
    for ball in balls[:-1]:
        print(f'\033[031m{ball:0>2d}\033[0m', end=' ')
    print(f'\033[034m{balls[-1]:0>2d}\033[0m')


n = int(input('How many tickets to generate: '))
for _ in range(n):
    display(choose())
```

> **Note**: Look at the line `display(choose())`. Here, we first use the `choose` function to get one group of random numbers, and then we pass the return value of the `choose` function as the argument of the `display` function, and use the `display` function to show the selected random numbers. After refactoring, the code logic becomes very clear, and the readability of the code becomes stronger. If someone has packaged these two functions for you, and you are only the caller of the functions, then in fact you do not need to care about the internal implementation of the `choose` function and the `display` function at all. You only need to know that calling the `choose` function can generate one group of random numbers, and calling the `display` function with a list can output that group of numbers. In the future, when we use all kinds of third-party Python libraries, we also do not care about their underlying implementation. What we need to know is only which function to call to solve the problem.

### Summary

When writing code, especially when developing commercial projects, we should consciously **package relatively independent functions that will be used repeatedly into functions**. In this way, whether it is you or other team members, everyone can use these functions by calling them, and this can reduce repeated and boring work in development.
