## Practical Function Examples

### Example 1: Random Verification Code

Design a function that generates a random verification code made of digits and uppercase/lowercase English letters. The length should be configurable through a parameter.

```python
import random
import string

ALL_CHARS = string.digits + string.ascii_letters


def generate_code(*, code_len=4):
    """
    Generate a verification code of the specified length.
    :param code_len: The length of the code (default: 4)
    :return: A random verification code string containing digits and letters
    """
    return ''.join(random.choices(ALL_CHARS, k=code_len))
```

> **Note 1**: `string.digits` is the string `'0123456789'`, and `string.ascii_letters` contains all lowercase and uppercase English letters.
>
> **Note 2**: Both `random.sample` and `random.choices` perform sampling. `sample` performs sampling without replacement, while `choices` performs sampling with replacement. The `k` parameter of `choices` is keyword-only.

You can test the function like this:

```python
for _ in range(5):
    print(generate_code())
```

Or:

```python
for _ in range(5):
    print(generate_code(code_len=6))
```

### Example 2: Check for Prime Numbers

Design a function that determines whether a positive integer greater than 1 is prime. A prime number is a positive integer greater than 1 that is divisible only by 1 and itself. If a positive integer $\small{N}$ greater than 1 is prime, that means there are no factors of it between `2` and $\small{N-1}$.

```python
def is_prime(num: int) -> bool:
    """
    Determine whether a positive integer is prime.
    :param num: A positive integer greater than 1
    :return: True if num is prime, otherwise False
    """
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False
    return True
```

> **Note 1**: The `: int` after the parameter `num` above is used to annotate the parameter type. Although it does not affect the execution result of the code, it greatly improves readability. Likewise, the `-> bool` after the parameter list is used to annotate the return type of the function. It also does not affect the execution result, but it makes it clear that calling the function returns a Boolean value, either `True` or `False`.
>
> **Note 2**: The loop above does not need to go from `2` all the way to $\small{N-1}$, because if by the time the loop reaches $\small{\sqrt{N}}$ we still have not found a factor of $\small{N}$, then no factor of $\small{N}$ will appear after $\small{\sqrt{N}}$. You can think for yourself about why that is.

### Example 3: Greatest Common Divisor and Least Common Multiple

Design functions to compute the greatest common divisor and the least common multiple of two positive integers. The greatest common divisor of $\small{x}$ and $\small{y}$ is the largest integer that can divide both $\small{x}$ and $\small{y}$ exactly. If $\small{x}$ and $\small{y}$ are coprime, then their greatest common divisor is 1. The least common multiple of $\small{x}$ and $\small{y}$ is the smallest positive integer that is divisible by both $\small{x}$ and $\small{y}$. If $\small{x}$ and $\small{y}$ are coprime, then their least common multiple is $\small{x \times y}$. It should be noted that computing the greatest common divisor and computing the least common multiple are two different functions, so they should be designed as two functions rather than being mixed into one.

```python
def lcm(x: int, y: int) -> int:
    """Compute the least common multiple."""
    return x * y // gcd(x, y)


def gcd(x: int, y: int) -> int:
    """Compute the greatest common divisor."""
    while y % x != 0:
        x, y = y % x, x
    return x
```

> **Note**: Functions can call each other. The `lcm` function above calls the `gcd` function and uses $\frac{x \times y}{gcd(x, y)}$ to calculate the least common multiple.

### Example 4: Data Statistics

Assume sample data is stored in a list. Design functions that compute descriptive statistics such as the mean, median, range, variance, standard deviation, and coefficient of variation.

```python
def ptp(data):
    """Range."""
    return max(data) - min(data)


def mean(data):
    """Arithmetic mean."""
    return sum(data) / len(data)


def median(data):
    """Median."""
    temp, size = sorted(data), len(data)
    if size % 2 != 0:
        return temp[size // 2]
    else:
        return mean(temp[size // 2 - 1:size // 2 + 1])


def var(data, ddof=1):
    """Variance."""
    x_bar = mean(data)
    temp = [(num - x_bar) ** 2 for num in data]
    return sum(temp) / (len(temp) - ddof)


def std(data, ddof=1):
    """Standard deviation."""
    return var(data, ddof) ** 0.5


def cv(data, ddof=1):
    """Coefficient of variation."""
    return std(data, ddof) / mean(data)


def describe(data):
    """Print descriptive statistics."""
    print(f'Mean: {mean(data)}')
    print(f'Median: {median(data)}')
    print(f'Range: {ptp(data)}')
    print(f'Variance: {var(data)}')
    print(f'Standard deviation: {std(data)}')
    print(f'Coefficient of variation: {cv(data)}')
```

> **Note 1**: The median is the middle value after sorting. If the number of data points is even, it is the average of the two middle values.
>
> **Note 2**: The parameter `ddof` stands for delta degrees of freedom. For sample variance and sample standard deviation, the default correction is `1`. For population statistics, you can set it to `0`.

### Example 5: Double Color Ball Lottery Number Generator

Let us refactor the lottery-number example from an earlier lesson by splitting the logic into two functions: one that generates a ticket and one that displays it.

```python
"""
Random number generator for Double Color Ball

Author: Luo Hao
Version: 1.3
"""
import random

RED_BALLS = [i for i in range(1, 34)]
BLUE_BALLS = [i for i in range(1, 17)]


def choose():
    """
    Generate one random ticket.
    :return: A list containing the selected numbers
    """
    selected_balls = random.sample(RED_BALLS, 6)
    selected_balls.sort()
    selected_balls.append(random.choice(BLUE_BALLS))
    return selected_balls


def display(balls):
    """
    Print one ticket in a formatted way.
    :param balls: A list containing the selected numbers
    """
    for ball in balls[:-1]:
        print(f'\033[031m{ball:0>2d}\033[0m', end=' ')
    print(f'\033[034m{balls[-1]:0>2d}\033[0m')


n = int(input('How many tickets to generate: '))
for _ in range(n):
    display(choose())
```

> **Note**: In `display(choose())`, the result returned by `choose` is passed directly to `display`. After refactoring, the logic becomes clearer and the code becomes easier to read and reuse.

### Summary

When writing code, especially when developing commercial projects, you should consciously **package relatively independent and reusable functionality into functions**. In this way, whether it is you or other members of the team, everyone can use those capabilities simply by calling functions, reducing repetitive and tedious work.
