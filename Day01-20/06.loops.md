## Loops

When writing programs, you will often run into situations where one or more instructions must be executed repeatedly. For example, suppose you want to print `hello, world` once every second for an entire hour. The following code performs that action once. If you wanted to keep it running for one hour, would you really write the same code 3600 times?

```python
import time

print('hello, world')
time.sleep(1)
```

> **Note**: The built-in `time` module provides the `sleep` function, which pauses the program. The argument `1` means one second. It can be an `int` or a `float`, so `0.05` means `50` milliseconds. We will cover functions and modules in more detail later.

To handle situations like this, Python provides **loop structures**. A loop is a structure that controls repeated execution of one or more instructions. Instead of writing the same code 3600 times, we write it once and place it inside a loop. In Python, there are two main looping constructs: `for-in` loops and `while` loops.

### `for-in` Loops

If you know in advance how many times the loop should run, we recommend using a `for-in` loop. For the "repeat 3600 times" example, we can write:

```python
"""
Print "hello, world" once per second for one hour

Author: Luo Hao
Version: 1.0
"""
import time

for i in range(3600):
    print('hello, world')
    time.sleep(1)
```

The expression `range(3600)` generates the integers from `0` to `3599`. When used in a `for-in` loop, the loop variable `i` takes those values one by one, causing the loop body to execute 3600 times.

The `range` function is flexible. Here are some common examples:

- `range(101)`: generates integers from `0` to `100`.
- `range(1, 101)`: generates integers from `1` to `100`, equivalent to the half-open interval `[1, 101)`.
- `range(1, 101, 2)`: generates odd numbers from `1` to `99`, with a step of `2`.
- `range(100, 0, -2)`: generates even numbers from `100` down to `2`, with a step of `-2`.

You may have noticed that the program above never actually uses the loop variable `i`. By Python convention, when the loop variable is unused, we usually name it `_`.

```python
"""
Print "hello, world" once per second for one hour

Author: Luo Hao
Version: 1.1
"""
import time

for _ in range(3600):
    print('hello, world')
    time.sleep(1)
```

The output is the same, but this version better communicates that the loop variable is intentionally unused.

The code above would run for an hour. If you want to stop it early, click the stop button in PyCharm or press `Ctrl+C` in a terminal.

Now let us use a `for-in` loop to compute the sum of the integers from 1 to 100.

```python
"""
Sum the integers from 1 to 100

Version: 1.0
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    total += i
print(total)
```

In this example, the variable `total` stores the running sum. During the loop, `i` takes the values from `1` through `100`. Each time, `total += i` adds the current value of `i` to the accumulated result. When the loop ends, `total` is `5050`.

Next, let us compute the sum of the even numbers from 1 to 100.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.0
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    if i % 2 == 0:
        total += i
print(total)
```

> **Note**: This loop uses a branch to check whether `i` is even.

We can write that more simply by adjusting the arguments passed to `range`.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.1
Author: Luo Hao
"""
total = 0
for i in range(2, 101, 2):
    total += i
print(total)
```

An even simpler approach is to use Python's built-in `sum` function:

```python
"""
Sum the even numbers from 1 to 100

Version: 1.2
Author: Luo Hao
"""
print(sum(range(2, 101, 2)))
```

### `while` Loops

If you need a loop but do not know in advance how many times it should run, a `while` loop is usually the better choice. A `while` loop keeps executing its body as long as the condition after `while` evaluates to `True`.

Here is a `while` loop that computes the sum from 1 to 100:

```python
"""
Sum the integers from 1 to 100

Version: 1.1
Author: Luo Hao
"""
total = 0
i = 1
while i <= 100:
    total += i
    i += 1
print(total)
```

Compared with the `for-in` version, this code introduces a variable `i` before the loop begins and uses it to control the loop. The condition `i <= 100` determines whether the loop continues. Inside the loop, we not only accumulate the total but also increment `i`. When `i` becomes `101`, the condition is false, the loop ends, and `total` contains `5050`.

To compute the sum of even numbers from 1 to 100, we can modify the code slightly:

```python
"""
Sum the even numbers from 1 to 100

Version: 1.3
Author: Luo Hao
"""
total = 0
i = 2
while i <= 100:
    total += i
    i += 2
print(total)
```

### `break` and `continue`

What happens if the condition in a `while` loop is always `True`? Consider the following code:

```python
"""
Sum the even numbers from 1 to 100

Version: 1.4
Author: Luo Hao
"""
total = 0
i = 2
while True:
    total += i
    i += 2
    if i > 100:
        break
print(total)
```

The loop condition is `True` forever, so without special handling this would become an infinite loop. We use the `break` keyword to terminate it when `i` exceeds `100`. Keep in mind that `break` only terminates the loop it directly belongs to.

Another useful keyword is `continue`, which skips the rest of the current iteration and jumps directly to the next one.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.5
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    if i % 2 != 0:
        continue
    total += i
print(total)
```

> **Note**: In this example, `continue` skips all odd values of `i`, so `total += i` runs only for even numbers.

### Nested Loops

Like branching, loops can also be nested. That means one loop can appear inside another. The following example prints the multiplication table from `1x1` to `9x9`.

```python
"""
Print the multiplication table

Version: 1.0
Author: Luo Hao
"""
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f'{i}×{j}={i * j}', end='\t')
    print()
```

In this code, the outer loop controls which row we are printing, and the inner loop controls the columns in that row. After the inner loop finishes, `print()` moves the output to the next line.

### Applications of Loops

#### Example 1: Determine Whether a Number Is Prime

Task: read a positive integer greater than 1 and determine whether it is prime.

> **Tip**: A prime number is an integer greater than 1 that is divisible only by 1 and itself. For a positive integer $\small{n}$, we can test whether it has any divisors between `2` and $\small{\sqrt{n}}$.

```python
"""
Read a positive integer greater than 1 and determine whether it is prime

Version: 1.0
Author: Luo Hao
"""
num = int(input('Enter a positive integer: '))
end = int(num ** 0.5)
is_prime = True
for i in range(2, end + 1):
    if num % i == 0:
        is_prime = False
        break
if is_prime:
    print(f'{num} is a prime number')
else:
    print(f'{num} is not a prime number')
```
