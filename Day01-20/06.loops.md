## Loops

When we write programs, we are very likely to run into scenarios where one or more instructions need to be executed repeatedly. For example, suppose we need to output `hello, world` on the screen once every second and keep doing so for one hour. The code below can complete such an operation once. If we wanted it to keep printing for an hour, we would need to write that code 3600 times. Are you willing to do that?

```python
import time

print('hello, world')
time.sleep(1)
```

> **Note**: The built-in `time` module provides the `sleep` function, which pauses the program. The argument `1` means one second. It can be an `int` or a `float`, so `0.05` means `50` milliseconds. We will cover functions and modules in more detail later.

To deal with the problem in the scenario above, we can use loop structures in Python programs. A loop structure is a structure in a program that controls one or more instructions to be executed repeatedly. With such a structure, the code just now does not need to be written 3600 times. We write it once and place it inside a loop so it repeats 3600 times. In Python, there are two ways to construct a loop structure: one is the `for-in` loop, and the other is the `while` loop.

### `for-in` Loops

If you clearly know how many times the loop will run, we recommend using a `for-in` loop. For the scenario of repeating 3600 times mentioned above, we can use the following code. Note that the code block controlled by the `for-in` loop is also constructed through indentation, exactly the same way code blocks are constructed in branching structures. We call the code block controlled by the `for-in` loop the loop body, and the statements in the loop body are usually executed repeatedly according to the loop settings.

```python
"""
Print "hello, world" once per second for one hour

Author: Luo Hao
Version: 1.0
"""
import time

for i in range(3600):
    print('hello, world')
    time.sleep(1)
```

It should be explained that `range(3600)` in the code above constructs a range from `0` to `3599`. When we place such a range in a `for-in` loop, the loop variable `i` can take the integers from `0` to `3599` one by one, and that causes the statements in the `for-in` loop body to repeat 3600 times.

The `range` function is flexible. Here are some common examples:

- `range(101)`: generates integers from `0` to `100`.
- `range(1, 101)`: generates integers from `1` to `100`, equivalent to the half-open interval `[1, 101)`.
- `range(1, 101, 2)`: generates odd numbers from `1` to `99`, with a step of `2`.
- `range(100, 0, -2)`: generates even numbers from `100` down to `2`, with a step of `-2`.

You may have noticed that the program above never actually uses the loop variable `i`. By Python convention, when the loop variable is unused, we usually name it `_`.

```python
"""
Print "hello, world" once per second for one hour

Author: Luo Hao
Version: 1.1
"""
import time

for _ in range(3600):
    print('hello, world')
    time.sleep(1)
```

Although the result does not change much, writing it this way makes you look more professional.

The code above would run for an hour. If you want to stop it early, click the stop button in PyCharm or press `Ctrl+C` in a terminal.

Now let us use a `for-in` loop to compute the sum of the integers from 1 to 100.

```python
"""
Sum the integers from 1 to 100

Version: 1.0
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    total += i
print(total)
```

In the code above, the role of variable `total` is to save the accumulated result. During the loop, the value of loop variable `i` goes from `1` all the way to `100`. For each value of `i`, we execute `total += i`, which is equivalent to `total = total + i`; this statement performs the accumulation. So when the loop ends and we output `total`, its value is the result of summing the integers from `1` to `100`, namely `5050`. Notice that the statement `print(total)` is not indented, so it is not controlled by the `for-in` loop and will not be executed repeatedly.

Next, let us compute the sum of the even numbers from 1 to 100.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.0
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    if i % 2 == 0:
        total += i
print(total)
```

> **Note**: This loop uses a branch to check whether `i` is even.

We can write that more simply by adjusting the arguments passed to `range`.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.1
Author: Luo Hao
"""
total = 0
for i in range(2, 101, 2):
    total += i
print(total)
```

An even simpler approach is to use Python's built-in `sum` function:

```python
"""
Sum the even numbers from 1 to 100

Version: 1.2
Author: Luo Hao
"""
print(sum(range(2, 101, 2)))
```

### `while` Loops

If we need to build a loop structure but cannot determine in advance how many times it should repeat, we recommend using a `while` loop. A `while` loop controls the loop through a Boolean value or an expression that produces a Boolean value. When the value of the Boolean value or expression is `True`, the statements in the loop body, that is, the code block below the `while` statement with consistent indentation, are executed repeatedly. When the value of the expression becomes `False`, the loop ends.

Here is a `while` loop that computes the sum from 1 to 100:

```python
"""
Sum the integers from 1 to 100

Version: 1.1
Author: Luo Hao
"""
total = 0
i = 1
while i <= 100:
    total += i
    i += 1
print(total)
```

Compared with the `for-in` loop, in the code above we added a variable `i` before the loop begins and use this variable to control the loop, so the condition `i <= 100` is placed after `while`. In the loop body of `while`, in addition to accumulation, we also need to increase the value of variable `i`, so we add the statement `i += 1`. In this way, the value of `i` becomes `1`, `2`, `3`, and so on, until `101`. When `i` becomes `101`, the condition of the `while` loop is no longer satisfied, the code leaves the `while` loop, and at that point the value of variable `total` is the result of summing from `1` to `100`, namely `5050`.

To compute the sum of even numbers from 1 to 100, we can modify the code slightly:

```python
"""
Sum the even numbers from 1 to 100

Version: 1.3
Author: Luo Hao
"""
total = 0
i = 2
while i <= 100:
    total += i
    i += 2
print(total)
```

### `break` and `continue`

What happens if the condition of a `while` loop is set to `True`, so that the condition is always satisfied? Let us look at the code below, which still uses `while` to build a loop structure and compute the sum of the even numbers from `1` to `100`.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.4
Author: Luo Hao
"""
total = 0
i = 2
while True:
    total += i
    i += 2
    if i > 100:
        break
print(total)
```

In the code above, `while True` constructs a loop whose condition is always true, which means that if no special handling is done, the loop will never end. This is what we often call an infinite loop. In order to stop the loop after `i` exceeds `100`, we use the keyword `break`, whose purpose is to terminate the execution of the loop structure. It should be noted that `break` can only terminate the loop in which it is located. This point needs attention when using nested loop structures, and we will talk about what nested loop structures are shortly.

Besides `break`, there is another keyword that can be used inside loop structures: `continue`. It can be used to abandon the remaining code in the current iteration and make the loop directly enter the next round, as shown below.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.5
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    if i % 2 != 0:
        continue
    total += i
print(total)
```

> **Note**: In this example, `continue` skips all odd values of `i`, so `total += i` runs only for even numbers.

### Nested Loops

Like branching, loops can also be nested. That means one loop can appear inside another. The following example prints the multiplication table from `1x1` to `9x9`.

```python
"""
Print the multiplication table

Version: 1.0
Author: Luo Hao
"""
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f'{i}×{j}={i * j}', end='\t')
    print()
```

In the code above, another `for-in` loop appears inside the loop body of a `for-in` loop. The outer loop is used to control the output of row `i`, while the inner loop is used to control the output of column `j` within one row. Obviously, the output of the inner `for-in` loop is one entire row in the multiplication table. So when the inner loop finishes, we use `print()` to achieve the effect of a line break, allowing the following output to start again on a new line.

### Applications of Loops

#### Example 1: Determine Whether a Number Is Prime

Task: input a positive integer greater than `1` and determine whether it is a prime number.

> **Tip**: A prime number is an integer greater than 1 that is divisible only by 1 and itself. For a positive integer $\small{n}$, we can test whether it has any divisors between `2` and $\small{\sqrt{n}}$.

```python
"""
Read a positive integer greater than 1 and determine whether it is prime

Version: 1.0
Author: Luo Hao
"""
num = int(input('Enter a positive integer: '))
end = int(num ** 0.5)
is_prime = True
for i in range(2, end + 1):
    if num % i == 0:
        is_prime = False
        break
if is_prime:
    print(f'{num} is a prime number')
else:
    print(f'{num} is not a prime number')
```
