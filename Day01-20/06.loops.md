## Loops

When we write programs, we are very likely to meet scenes where one instruction or some instructions need to be executed again and again. For example, suppose we need to output `hello, world` on the screen once every second and keep doing it for one hour. The code below can complete such an operation one time. If we want to keep outputting it for one hour, we need to write this code 3600 times. Are you willing to do that?

```python
import time

print('hello, world')
time.sleep(1)
```

> **Note**: The built-in `time` module provides the `sleep` function, which pauses the program. The argument `1` means one second. It can be an `int` or a `float`, so `0.05` means `50` milliseconds. We will cover functions and modules in more detail later.

To deal with the problem in the scene above, we can use loop structures in Python programs. A loop structure is a structure in a program that controls one instruction or some instructions to be executed repeatedly. With such a structure, the code just now does not need to be written 3600 times. We write it once, and then put it into a loop structure to repeat 3600 times. In Python, there are two ways to build a loop structure: one is the `for-in` loop, and the other is the `while` loop.

### `for-in` Loops

If we clearly know how many times the loop will run, we recommend using a `for-in` loop. For example, for the scene of repeating 3600 times mentioned above, we can use the following code to do it. Note that the code block controlled by the `for-in` loop is also built through indentation. This is the same as how code blocks are built in branching structures. We call the code block controlled by the `for-in` loop the loop body. Usually, the statements in the loop body will be executed repeatedly according to the loop setting.

```python
"""
Print "hello, world" once per second for one hour

Author: Luo Hao
Version: 1.0
"""
import time

for i in range(3600):
    print('hello, world')
    time.sleep(1)
```

It should be explained that `range(3600)` in the code above builds a range from `0` to `3599`. When we put such a range into a `for-in` loop, the loop variable `i` can take out the integers from `0` to `3599` one by one, and this makes the statements in the `for-in` loop body repeat 3600 times.

The `range` function is flexible. Here are some common examples:

- `range(101)`: generates integers from `0` to `100`.
- `range(1, 101)`: generates integers from `1` to `100`, equivalent to the half-open interval `[1, 101)`.
- `range(1, 101, 2)`: generates odd numbers from `1` to `99`, with a step of `2`.
- `range(100, 0, -2)`: generates even numbers from `100` down to `2`, with a step of `-2`.

You may have noticed that the program above never actually uses the loop variable `i`. By Python convention, when the loop variable is unused, we usually name it `_`.

```python
"""
Print "hello, world" once per second for one hour

Author: Luo Hao
Version: 1.1
"""
import time

for _ in range(3600):
    print('hello, world')
    time.sleep(1)
```

Although the result does not change, writing it this way makes you look more professional.

The code above would run for an hour. If you want to stop it early, click the stop button in PyCharm or press `Ctrl+C` in a terminal.

Now let us use a `for-in` loop to compute the sum of the integers from 1 to 100.

```python
"""
Sum the integers from 1 to 100

Version: 1.0
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    total += i
print(total)
```

In the code above, the role of variable `total` is to save the accumulated result. During the loop, the value of loop variable `i` goes from `1` all the way to `100`. For each value of `i`, we execute `total += i`, which is equal to `total = total + i`. This statement does the accumulation. So when the loop ends and we output `total`, its value is the result of adding from `1` to `100`, which is `5050`. Please note that the statement `print(total)` is not indented, so it is not controlled by the `for-in` loop and will not be executed repeatedly.

Next, let us compute the sum of the even numbers from 1 to 100.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.0
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    if i % 2 == 0:
        total += i
print(total)
```

> **Note**: This loop uses a branch to check whether `i` is even.

We can write that more simply by adjusting the arguments passed to `range`.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.1
Author: Luo Hao
"""
total = 0
for i in range(2, 101, 2):
    total += i
print(total)
```

An even simpler approach is to use Python's built-in `sum` function:

```python
"""
Sum the even numbers from 1 to 100

Version: 1.2
Author: Luo Hao
"""
print(sum(range(2, 101, 2)))
```

### `while` Loops

If we need to build a loop structure but cannot determine in advance how many times it should repeat, we recommend using a `while` loop. A `while` loop controls the loop through a Boolean value or an expression that can produce a Boolean value. When the value of the Boolean value or expression is `True`, the statements in the loop body, that is, the code block below the `while` statement with the same indentation, are executed repeatedly. When the value of the expression becomes `False`, the loop ends.

Here is a `while` loop that computes the sum from 1 to 100:

```python
"""
Sum the integers from 1 to 100

Version: 1.1
Author: Luo Hao
"""
total = 0
i = 1
while i <= 100:
    total += i
    i += 1
print(total)
```

Compared with the `for-in` loop, in the code above we added a variable `i` before the loop begins, and we use this variable to control the loop, so `while` is followed by the condition `i <= 100`. In the loop body of `while`, besides accumulation, we also need to make the value of variable `i` increase, so we add the statement `i += 1`. In this way, the value of `i` will become `1`, `2`, `3`, and so on, until `101`. When `i` becomes `101`, the condition of the `while` loop is no longer true, the code leaves the `while` loop, and at this time the value of variable `total` is the result of summing from `1` to `100`, which is `5050`.

To compute the sum of even numbers from 1 to 100, we can modify the code slightly:

```python
"""
Sum the even numbers from 1 to 100

Version: 1.3
Author: Luo Hao
"""
total = 0
i = 2
while i <= 100:
    total += i
    i += 2
print(total)
```

### `break` and `continue`

What happens if the condition of a `while` loop is set to `True`, so that the condition is always satisfied? Let us look at the code below, which still uses `while` to build a loop structure and compute the sum of the even numbers from `1` to `100`.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.4
Author: Luo Hao
"""
total = 0
i = 2
while True:
    total += i
    i += 2
    if i > 100:
        break
print(total)
```

In the code above, `while True` builds a loop whose condition is always true. This means that if no special handling is done, the loop will never end. This is what we often call an infinite loop. In order to stop the loop after `i` becomes greater than `100`, we use the keyword `break`. Its job is to terminate the execution of the loop structure. It should be noted that `break` can only terminate the loop where it is located. This point needs attention when using nested loop structures, and we will talk about what nested loop structures are soon.

Besides `break`, there is another keyword that can be used inside loop structures: `continue`. It can be used to give up the remaining code in the current round of the loop and let the loop directly enter the next round, as shown below.

```python
"""
Sum the even numbers from 1 to 100

Version: 1.5
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    if i % 2 != 0:
        continue
    total += i
print(total)
```

> **Note**: In this example, `continue` skips all odd values of `i`, so `total += i` runs only for even numbers.

### Nested Loops

Like branching structures, loop structures can also be nested. This means a loop can appear inside another loop. The following example shows how to print the multiplication table from `1x1` to `9x9`.

```python
"""
Print the multiplication table

Version: 1.0
Author: Luo Hao
"""
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f'{i}×{j}={i * j}', end='\t')
    print()
```

In the code above, the loop body of a `for-in` loop uses another `for-in` loop again. The outer loop is used to control the output of row `i`, while the inner loop is used to control the output of column `j` in one row. Clearly, the output of the inner `for-in` loop is one whole row in the multiplication table. So when the inner loop finishes, we use `print()` to make a line break, so the following output starts again on a new line.

### Applications of Loops

#### Example 1: Determine Whether a Number Is Prime

Task: input a positive integer greater than `1` and determine whether it is a prime number.

> **Tip**: A prime number is an integer greater than 1 that can only be divided by 1 and itself. For a positive integer $\small{n}$, we can check whether it has any factor between `2` and $\small{\sqrt{n}}$.

```python
"""
Read a positive integer greater than 1 and determine whether it is prime

Version: 1.0
Author: Luo Hao
"""
num = int(input('Enter a positive integer: '))
end = int(num ** 0.5)
is_prime = True
for i in range(2, end + 1):
    if num % i == 0:
        is_prime = False
        break
if is_prime:
    print(f'{num} is a prime number')
else:
    print(f'{num} is not a prime number')
```

> **Note**: In the code above, we used the Boolean variable `is_prime`. We first assign it the value `True`, assuming that `num` is a prime number. Next, we look for factors of `num` in the range from `2` to `num ** 0.5`. If we find a factor of `num`, then it is definitely not a prime number. At this time, we assign `False` to `is_prime`, and at the same time use the `break` keyword to terminate the loop structure. Finally, according to whether the value of `is_prime` is `True` or `False`, we give different output.

#### Example 2: Greatest Common Divisor

Task: input two positive integers greater than `0` and find the greatest common divisor of the two numbers.

> **Tip**: The greatest common divisor of two numbers is the largest one among their common factors.

```python
"""
Input two positive integers and find their greatest common divisor

Version: 1.0
Author: Luo Hao
"""
x = int(input('x = '))
y = int(input('y = '))
for i in range(x, 0, -1):
    if x % i == 0 and y % i == 0:
        print(f'Greatest common divisor: {i}')
        break
```

> **Note**: In the code above, the loop variable values in the `for-in` loop go from large to small. In this way, the factor `i` we find that can divide both `x` and `y` is the greatest common divisor of `x` and `y`, and at this time we use `break` to terminate the loop. If `x` and `y` are coprime, then the loop will run until `i` becomes `1`, because `1` is a factor of all positive integers. At this time, the greatest common divisor of `x` and `y` is `1`.

There is an efficiency problem with using the code above to find the greatest common divisor. If the value of `x` is `999999999998` and the value of `y` is `999999999999`, then obviously the two numbers are coprime and the greatest common divisor is `1`. But if we use the code above, the loop will repeat `999999999998` times, which is usually unacceptable. We can use the Euclidean algorithm to find the greatest common divisor, and it can help us get the result we want much faster. The code is shown below.

```python
"""
Input two positive integers and find their greatest common divisor

Version: 1.1
Author: Luo Hao
"""
x = int(input('x = '))
y = int(input('y = '))
while y % x != 0:
    x, y = y % x, x
print(f'Greatest common divisor: {x}')
```

> **Note**: The method and steps for solving a problem can be called an algorithm. For the same problem, we can design different algorithms. Different algorithms will differ in occupied storage space and execution efficiency, and these differences represent the quality of the algorithms. You can compare the two code sections above and feel why we say the Euclidean algorithm is a better choice. In the code above, the statement `x, y = y % x, x` means assigning the value of `y % x` to `x`, and assigning the original value of `x` to `y`.

#### Example 3: Guess the Number Game

Task: the computer gives a random number between `1` and `100`. The player enters the number they guess, and the computer gives the corresponding hint message, `A little bigger`, `A little smaller`, or `You got it right`. If the player guesses the number correctly, the computer tells the user how many times they guessed in total, the game ends; otherwise, the game continues.

```python
"""
A small guess-the-number game

Version: 1.0
Author: Luo Hao
"""
import random

answer = random.randrange(1, 101)
counter = 0
while True:
    counter += 1
    num = int(input('Please enter: '))
    if num < answer:
        print('A little bigger.')
    elif num > answer:
        print('A little smaller.')
    else:
        print('You got it right.')
        break
print(f'You guessed {counter} times in total.')
```

> **Note**: The code above uses `import random` to import the `random` module from the Python standard library. The `randrange` function of this module helps us generate a random number in the range from `1` to `100`. The variable `counter` is used to record how many times the loop executes, that is, how many times the user guessed in total. Every time the loop runs, the value of `counter` increases by `1`.

### Summary

After learning branching structures and loop structures in Python, we can solve many practical problems. Through this lesson, everyone should already know that we can use the keywords `for` and `while` to build loop structures. **If we know in advance how many times the loop structure repeats, we usually use** `for` **loops**; **if the number of repetitions of the loop structure cannot be determined, we can use** `while` **loops**. In addition, we can **use** `break` **inside a loop structure to terminate the loop**, and **we can also use the** `continue` **keyword inside a loop structure to let the loop structure directly enter the next round**.
