## Variables in Python

People who are new to programming often want to know two things: what a computer program actually is, and what writing programs can help us do. My short answer is this: **a program is an ordered collection of data and instructions**, and **writing programs means using data and instructions to make the computer do what we want**. Many people choose Python because it is both simple and powerful. Compared with languages such as C, C++, and Java, Python is friendlier to beginners and non-specialists, and many problems can be solved in a clean and elegant way. In this lesson, we begin with the most basic language elements and learn how to use them.

### A Few Basics

Before studying Python systematically, it helps to understand a little about computers. A computer hardware system is usually described as having five major components: the **arithmetic unit**, **control unit**, **memory**, **input devices**, and **output devices**. The arithmetic unit and control unit together form what we usually call the **central processing unit** (CPU), which executes calculations and control instructions. As mentioned earlier, a program is a collection of instructions. Writing a program means organizing those instructions so the computer performs the tasks we want. Memory can be divided into **internal memory** and **external storage**. Internal memory is what we usually call RAM, and it is directly addressable by the CPU. During execution, a program's instructions and data must be loaded into memory. Input and output devices are often referred to collectively as I/O devices. Keyboards, mice, microphones, and cameras are common input devices, while monitors, printers, and speakers are common output devices. Most modern computers follow the **von Neumann architecture**, which has two essential characteristics: **memory and the CPU are separated**, and **data is encoded in binary**.

Binary is a numbering system that carries after every two values, just as decimal carries after every ten values. Humans traditionally use decimal because we have ten fingers. Once all ten are used, we carry to the next place value. For computers, binary is especially easy to implement physically because high voltage can represent `1` and low voltage can represent `0`. Not everyone who writes programs needs deep binary knowledge, and in many cases you can write software without understanding conversions between decimal, binary, octal, and hexadecimal. Still, one thing is essential: computers count and store data in binary, and every kind of data exists in memory in binary form.

> **Note**: If you want to learn more about binary and number system conversion, introductory computer science books usually cover it in detail.

### Variables and Types

To store data in computer memory, we first need to understand variables. In programming languages, **a variable is a carrier for data**. Put simply, it is a piece of memory used to store data, and **its value can be read and modified**. That is the foundation of computation and control. Computers can process many kinds of data. Numbers are the most familiar example, but there are also strings, images, audio, video, and more. Even though all data exists in binary form inside the computer, we use different variable types to represent these differences. Python comes with many built-in data types and also lets us define custom types later on. For now, let's focus on the most common built-in types.

1. Integer (`int`): Python can handle integers of arbitrary size and supports binary (`0b100`, which is `4` in decimal), octal (`0o100`, which is `64`), decimal (`100`), and hexadecimal (`0x100`, which is `256`) representations.

    ```python
    print(0b100)  # binary integer
    print(0o100)  # octal integer
    print(100)    # decimal integer
    print(0x100)  # hexadecimal integer
    ```

2. Floating-point (`float`): Floating-point numbers are numbers with decimal fractions. They are called "floating-point" because the decimal point can move when the value is represented in scientific notation. In Python, floats can be written in ordinary decimal form, such as `123.456`, or in scientific notation, such as `1.23456e2`, which means $\small{1.23456 \times 10^{2}}$.

    ```python
    print(123.456)    # standard decimal notation
    print(1.23456e2)  # scientific notation
    ```

3. String (`str`): A string is any piece of text enclosed in single or double quotes, such as `'hello'` or `"hello"`.

4. Boolean (`bool`): A Boolean value is either `True` or `False`. It can represent yes/no, true/false, good/bad, high/low, and any other situation with exactly two states.

### Naming Variables

Every variable needs a name, just like every person does. In Python, variable names should follow these rules and conventions.

- Rules:
  - Rule 1: A variable name can contain **letters**, **digits**, and **underscores**, but it cannot start with a digit. Technically, the "letters" here are Unicode characters, so Chinese, Japanese, Greek, and others are allowed. In practice, you should **prefer English letters**.
  - Rule 2: Python is **case-sensitive**, so `A` and `a` are different names.
  - Rule 3: A variable name **must not be the same as a Python keyword** and should avoid Python reserved names whenever possible. Keywords are words with special meaning in the language, such as `if`, `else`, `for`, `while`, `True`, and `False`. Reserved names often include built-in functions or modules such as `int`, `print`, `input`, `str`, `math`, and `os`.
- Conventions:
  - Convention 1: Use **lowercase English letters**, and join multiple words with underscores.
  - Convention 2: Protected variables usually begin with a single underscore.
  - Convention 3: Private variables usually begin with two underscores.

You do not need to worry too much about conventions 2 and 3 yet. They will make more sense later. One professional habit already worth developing is choosing names that clearly express meaning.

### Using Variables

The examples below show how variables work and how different types are used.

```python
"""
Use variables to store data and perform arithmetic

Version: 1.0
Author: Luo Hao
"""
a = 45        # define variable a and assign 45
b = 12        # define variable b and assign 12
print(a, b)   # 45 12
print(a + b)  # 57
print(a - b)  # 33
print(a * b)  # 540
print(a / b)  # 3.75
```

In Python, you can use the `type` function to check a variable's type. The concept of a function in programming is similar to the one in mathematics. If that idea is not yet clear, that is fine. We will cover functions in detail later.

```python
"""
Use the type function to inspect variable types

Version: 1.0
Author: Luo Hao
"""
a = 100
b = 123.45
c = 'hello, world'
d = True
print(type(a))  # <class 'int'>
print(type(b))  # <class 'float'>
print(type(c))  # <class 'str'>
print(type(d))  # <class 'bool'>
```

Python also provides built-in functions for changing variable types. Here are some common ones:

- `int()`: convert a number or string to an integer, optionally specifying the base.
- `float()`: convert a string to a floating-point number when possible.
- `str()`: convert an object to a string.
- `chr()`: convert an integer character code to a one-character string.
- `ord()`: convert a one-character string to its integer character code.

The following example demonstrates type conversion in Python.

```python
"""
Type conversion for variables

Version: 1.0
Author: Luo Hao
"""
a = 100
b = 123.45
c = '123'
d = '100'
e = '123.45'
f = 'hello, world'
g = True
print(float(a))         # convert int 100 to float -> 100.0
print(int(b))           # convert float 123.45 to int -> 123
print(int(c))           # convert string '123' to int -> 123
print(int(c, base=16))  # treat string '123' as hexadecimal -> 291
print(int(d, base=2))   # treat string '100' as binary -> 4
print(float(e))         # convert string '123.45' to float -> 123.45
print(bool(f))          # non-empty string converts to True
print(int(g))           # True converts to 1
print(chr(a))           # integer 100 converts to 'd'
print(ord('d'))         # character 'd' converts to 100
```

> **Note**: When converting a `str` to `int`, you can use the `base` parameter to specify the numeral system. When converting a `str` to `bool`, any non-empty string becomes `True`. When converting `bool` to `int`, `True` becomes `1` and `False` becomes `0`. In both ASCII and Unicode, the character `'d'` has the code `100`.

In Python, we **use variables to store data**, and **variables have types**. Common types include `int`, `float`, `str`, and `bool`. When needed, you can convert between types using Python's built-in functions. Variables can participate in computation, which is a prerequisite for solving real problems.
