## Advanced Function Usage

Let us continue exploring functions. We already know that functions have parameters and return values, and both can be of any type. That leads to an interesting question: can a function itself be used as a parameter or as a return value? The answer is yes. **In Python, functions are first-class objects.** That means a function can be assigned to a variable, passed to another function, or returned from one. Functions that take functions as arguments or return them are usually called **higher-order functions**.

### Higher-Order Functions

Consider a function that takes any number of arguments and sums only the values whose types are `int` or `float`.

```python
def calc(*args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = 0
    for item in items:
        if type(item) in (int, float):
            result += item
    return result
```

What if we want this function to do more than just addition? Right now, it is tightly coupled to `+`. We can decouple it by turning the operation itself into a function parameter.

```python
def calc(init_value, op_func, *args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = init_value
    for item in items:
        if type(item) in (int, float):
            result = op_func(result, item)
    return result
```

Here, `init_value` is the initial value, and `op_func` is a binary operation function.

```python
def add(x, y):
    return x + y


def mul(x, y):
    return x * y
```

Now we can use `calc` for different operations:

```python
print(calc(0, add, 1, 2, 3, 4, 5))  # 15
print(calc(1, mul, 1, 2, 3, 4, 5))  # 120
```

If you do not want to define `add` and `mul` yourself, the standard `operator` module already provides them:

```python
import operator

print(calc(0, operator.add, 1, 2, 3, 4, 5))  # 15
print(calc(1, operator.mul, 1, 2, 3, 4, 5))  # 120
```

Python also includes several built-in higher-order functions. Two important ones are `filter` and `map`.

```python
def is_even(num):
    return num % 2 == 0


def square(num):
    return num ** 2


old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(square, filter(is_even, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

The same result can be achieved more elegantly with a list comprehension:

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = [num ** 2 for num in old_nums if num % 2 == 0]
print(new_nums)  # [144, 64, 3600, 2704]
```

Another useful built-in is `sorted`, which returns a new sorted list instead of modifying the original container.

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings)
print(new_strings)
```

You can customize sorting rules with the `key` parameter:

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings, key=len)
print(new_strings)  # ['in', 'zoo', 'pear', 'apple', 'waxberry']
```

### Lambda Functions

When using higher-order functions, sometimes the function being passed in is so simple that it does not need a name. In that case, Python provides **lambda functions**, also called **anonymous functions**. A lambda function can contain only one expression, and the value of that expression becomes the return value.

The previous example can be rewritten as:

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

We can even define more complex one-line functions:

```python
import functools
import operator

fac = lambda n: functools.reduce(operator.mul, range(2, n + 1), 1)
is_prime = lambda x: all(map(lambda f: x % f, range(2, int(x ** 0.5) + 1)))

print(fac(6))        # 720
print(is_prime(37))  # True
```

> **Tip 1**: `functools.reduce` performs a reduction over a sequence. Together with `filter` and `map`, it forms a powerful trio for data processing: **filtering**, **mapping**, and **reducing**.
>
> **Tip 2**: `all` returns `True` only if all Boolean values in the input are true.

### Partial Functions

A partial function fixes some arguments of an existing function and returns a new function. In Python, you can create partial functions with `functools.partial`.

For example, the built-in `int` function normally interprets strings as decimal integers. By fixing its `base` argument, we can create new functions for binary, octal, and hexadecimal conversion.

```python
import functools

int2 = functools.partial(int, base=2)
int8 = functools.partial(int, base=8)
int16 = functools.partial(int, base=16)

print(int('1001'))    # 1001

print(int2('1001'))   # 9
print(int8('1001'))   # 513
print(int16('1001'))  # 4097
```

The first argument to `partial` is a function, and the result it returns is also a function.

### Summary

In Python, functions are first-class objects, which means they can be assigned to variables, used as parameters, and returned from other functions. That gives Python great flexibility through higher-order functions. When a function is simple enough, you can use a lambda function instead of defining it separately.
