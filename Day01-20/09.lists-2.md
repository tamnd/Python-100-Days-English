## Common Data Structures: Lists, Part 2

### List Methods

Variables of list type have many methods that can help us operate on a list. Suppose we have a list named `foos`, and that list has a method named `bar`, then the syntax for using the list method is `foos.bar()`. This is a syntax for calling an object's method through an object reference. Later, when we talk about object-oriented programming, we will explain this syntax in more detail. This syntax can also be described as sending a message to an object.

#### Adding and Removing Elements

A list is a **mutable container**, which means we can add elements to it, remove elements from it, and modify existing elements.

We can append an element with `append` and insert one at a specific position with `insert`.

```python
languages = ['Python', 'Java', 'C++']
languages.append('JavaScript')
print(languages)  # ['Python', 'Java', 'C++', 'JavaScript']
languages.insert(1, 'SQL')
print(languages)  # ['Python', 'SQL', 'Java', 'C++', 'JavaScript']
```

We can use the `remove` method of a list to delete a specified element from the list. It should be noted that if the element to be deleted is not in the list, it raises `ValueError` and causes the program to crash, so it is recommended that when deleting an element, you first use the membership operation introduced earlier to do a check. We can also use the `pop` method to remove elements from the list. By default, `pop` deletes the last element in the list, but of course you can also give it a position and delete the element at the specified position. When using `pop`, if the index value is out of range, it raises `IndexError` and causes the program to crash. In addition, the list has a `clear` method, which can clear all elements in the list, as shown below.

```python
languages = ['Python', 'SQL', 'Java', 'C++', 'JavaScript']
if 'Java' in languages:
    languages.remove('Java')
if 'Swift' in languages:
    languages.remove('Swift')
print(languages)  # ['Python', 'SQL', 'C++', 'JavaScript']
languages.pop()
temp = languages.pop(1)
print(temp)       # SQL
languages.append(temp)
print(languages)  # ['Python', 'C++', 'SQL']
languages.clear()
print(languages)  # []
```

> **Note**: `pop` returns the removed element. In the example above, the result is stored in `temp`, and then appended back later.

If a list contains multiple `'Python'` values, `languages.remove('Python')` only removes the first one.

There is still a small question here. For example, if the `languages` list contains multiple `'Python'` values, then when we use `languages.remove('Python')`, does it delete all occurrences of `'Python'`, or only the first one? You can guess first and then try it yourself.

There is actually another way to delete elements from a list: use Python's `del` keyword followed by the element to be deleted. In essence, this is not different from using `pop` with a specified index to delete an element, but the latter returns the deleted element, while the former is slightly better in performance. That is because the underlying bytecode instruction corresponding to `del` is `DELETE_SUBSCR`, while the underlying bytecode instructions corresponding to `pop` are `CALL_METHOD` and `POP_TOP`. If that makes no sense yet, just ignore it.

```python
items = ['Python', 'Java', 'C++']
del items[1]
print(items)  # ['Python', 'C++']
```

#### Finding Positions and Counts

The `index` method returns the index of an element. If the element is missing, it raises `ValueError`. The `count` method returns how many times an element appears.

```python
items = ['Python', 'Java', 'Java', 'C++', 'Kotlin', 'Python']
print(items.index('Python'))     # 0
print(items.index('Python', 1))  # 5
print(items.count('Python'))     # 2
print(items.count('Kotlin'))     # 1
print(items.count('Swift'))      # 0
# print(items.index('Java', 3))  # ValueError: 'Java' is not in list
```

#### Sorting and Reversing

The `sort` method sorts a list in place, and `reverse` reverses it.

```python
items = ['Python', 'Java', 'C++', 'Kotlin', 'Swift']
items.sort()
print(items)  # ['C++', 'Java', 'Kotlin', 'Python', 'Swift']
items.reverse()
print(items)  # ['Swift', 'Python', 'Kotlin', 'Java', 'C++']
```

### List Comprehensions

In Python, a list can also be created through a special literal syntax called a comprehension. Below, let us use examples to explain exactly what benefits list comprehensions bring.

Scenario 1: create a list of numbers from `1` to `99` that are divisible by `3` or `5`.

```python
items = []
for i in range(1, 100):
    if i % 3 == 0 or i % 5 == 0:
        items.append(i)
print(items)
```

Using a list comprehension:

```python
items = [i for i in range(1, 100) if i % 3 == 0 or i % 5 == 0]
print(items)
```

Scenario 2: given a list of integers `nums1`, create a new list `nums2` containing their squares.

```python
nums1 = [35, 12, 97, 64, 55]
nums2 = []
for num in nums1:
    nums2.append(num ** 2)
print(nums2)
```

Using a list comprehension:

```python
nums1 = [35, 12, 97, 64, 55]
nums2 = [num ** 2 for num in nums1]
print(nums2)
```

Scenario 3: given a list of integers `nums1`, create a new list `nums2` containing only the elements greater than `50`.

```python
nums1 = [35, 12, 97, 64, 55]
nums2 = []
for num in nums1:
    if num > 50:
        nums2.append(num)
print(nums2)
```

Using a list comprehension:

```python
nums1 = [35, 12, 97, 64, 55]
nums2 = [num for num in nums1 if num > 50]
print(nums2)
```

Using list comprehensions to create lists is not only simple and elegant, but also faster than using a `for-in` loop and repeatedly calling `append` on an empty list. Why does a comprehension perform better? Because the Python interpreter has bytecode instructions specifically for comprehensions, such as the `LIST_APPEND` instruction. By contrast, a `for` loop adds elements to a list through method calls, represented by instructions like `LOAD_METHOD` and `CALL_METHOD`, and method calls themselves are relatively time-consuming operations. It does not matter if you do not understand that for the moment. Just remember the conclusion: **it is strongly recommended to use comprehension syntax to create lists**.

### Nested Lists

Python does not require the elements in a list to have the same data type. In other words, the elements in a list can be of arbitrary data types, including lists themselves. If the elements of a list are also lists, then we can call it a **nested list**. A nested list can be used to represent a table or, in mathematics, a matrix.

For example, to store the scores of 5 students in 3 courses:

```python
scores = [[95, 83, 92], [80, 75, 82], [92, 97, 90], [80, 78, 69], [65, 66, 89]]
print(scores[0])
print(scores[0][1])
```

If you want to enter those scores from the keyboard:

```python
scores = []
for _ in range(5):
    temp = []
    for _ in range(3):
        score = int(input('Enter score: '))
        temp.append(score)
    scores.append(temp)
print(scores)
```

If you want to generate them randomly:

```python
import random

scores = [[random.randrange(60, 101) for _ in range(3)] for _ in range(5)]
print(scores)
```

> **Note**: The inner list comprehension creates one list of 3 random scores. The outer comprehension repeats that 5 times, producing a nested list.

Now, let us use a Python program to generate one set of random numbers.

```python
"""
Random number generator for Double Color Ball

Author: Luo Hao
Version: 1.0
"""
import random

red_balls = list(range(1, 34))
selected_balls = []
# Add 6 red balls to the selected list.
for _ in range(6):
    index = random.randrange(len(red_balls))
    selected_balls.append(red_balls.pop(index))
# Sort the selected red balls.
selected_balls.sort()
# Print the red balls.
for ball in selected_balls:
    print(f'\033[031m{ball:0>2d}\033[0m', end=' ')
# Randomly choose 1 blue ball.
blue_ball = random.randrange(1, 17)
# Print the blue ball.
print(f'\033[034m{blue_ball:0>2d}\033[0m')
```

> **Note**: The control sequences like `\033[031m` are used to print colored output in the terminal.

We can simplify this with `random.sample` and `random.choice`:

```python
"""
Random number generator for Double Color Ball

Author: Luo Hao
Version: 1.1
"""
import random

red_balls = [i for i in range(1, 34)]
blue_balls = [i for i in range(1, 17)]
selected_balls = random.sample(red_balls, 6)
selected_balls.sort()
for ball in selected_balls:
    print(f'\033[031m{ball:0>2d}\033[0m', end=' ')
blue_ball = random.choice(blue_balls)
print(f'\033[034m{blue_ball:0>2d}\033[0m')
```

If you want to generate `N` tickets, place the same logic inside a loop:

```python
"""
Random number generator for Double Color Ball

Author: Luo Hao
Version: 1.2
"""
import random

n = int(input('How many tickets to generate: '))
red_balls = [i for i in range(1, 34)]
blue_balls = [i for i in range(1, 17)]
for _ in range(n):
    selected_balls = random.sample(red_balls, 6)
    selected_balls.sort()
    for ball in selected_balls:
        print(f'\033[031m{ball:0>2d}\033[0m', end=' ')
    blue_ball = random.choice(blue_balls)
    print(f'\033[034m{blue_ball:0>2d}\033[0m')
```
