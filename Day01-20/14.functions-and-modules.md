## Functions and Modules

Before we start this lesson, consider the following math problem: how many positive integer solutions does the equation below have?

$$
x_{1} + x_{2} + x_{3} + x_{4} = 8
$$

This is equivalent to dividing 8 apples into 4 groups, with at least one apple in each group. The answer is $\small{C_{7}^{3} = 35}$, where:

$$
C_m^n = \frac {m!} {n!(m-n)!}
$$

Using what we already know, we can compute this by calculating $\small{m!}$, $\small{n!}$, and $\small{(m-n)!}$ separately.

```python
"""
Read m and n, then compute C(m, n)

Version: 1.0
Author: Luo Hao
"""

m = int(input('m = '))
n = int(input('n = '))
fm = 1
for num in range(1, m + 1):
    fm *= num
fn = 1
for num in range(1, n + 1):
    fn *= num
fk = 1
for num in range(1, m - n + 1):
    fk *= num
print(fm // fn // fk)
```

You may already have noticed that in the code above we performed the factorial calculation three times. Although the values of $\small{m}$, $\small{n}$, and $\small{m-n}$ are different, the three blocks of code are not essentially different and therefore count as duplicate code. The world-class programming master Martin Fowler once said: "**Code has many bad smells, and duplication is one of the worst!**" To write high-quality code, the first thing to solve is duplicate code. For the code above, we can encapsulate the factorial operation into a code block called a **function**, and then, wherever we need a factorial, we simply **call the function** to reuse that functionality.

### Defining Functions

In mathematics, we often write functions as $\small{y = f(x)}$ or $\small{z = g(x, y)}$. Python functions follow the same general pattern: each function has a name, inputs, and a result. In Python, we usually call the inputs **parameters** and the result the **return value**.

In Python, functions can be defined with the `def` keyword. Just like variables, every function should also have a good name, and the naming rules are the same as the naming rules for variables. Inside the parentheses after the function name, we can define the parameters of the function, which correspond to the independent variables we mentioned earlier. After the function finishes executing, we use the `return` keyword to return the execution result of the function, which corresponds to the dependent variable we mentioned earlier. If there is no `return` statement in a function, the function returns `None`, which represents an empty value. In addition, a function can also have no independent variables, that is, no parameters, but the parentheses after the function name are still required.

```python
"""
Read m and n, then compute C(m, n)

Version: 1.1
Author: Luo Hao
"""


def fac(num):
    """Return the factorial of a non-negative integer."""
    result = 1
    for n in range(2, num + 1):
        result *= n
    return result


m = int(input('m = '))
n = int(input('n = '))
print(fac(m) // fac(n) // fac(m - n))
```

You can feel that the code above is simpler and more elegant than the earlier version. More importantly, the factorial function `fac` we defined can also be reused in other code that needs factorials. Therefore, **using functions helps us package code that is relatively independent in functionality and will be reused**, and when we need that code, instead of writing it again, we **reuse existing code by calling a function**.

Python's standard library already includes a factorial function in the `math` module:

```python
"""
Read m and n, then compute C(m, n)

Version: 1.2
Author: Luo Hao
"""
from math import factorial

m = int(input('m = '))
n = int(input('n = '))
print(factorial(m) // factorial(n) // factorial(m - n))
```

If the name feels too long, you can import it with an alias:

```python
"""
Read m and n, then compute C(m, n)

Version: 1.3
Author: Luo Hao
"""
from math import factorial as f

m = int(input('m = '))
n = int(input('n = '))
print(f(m) // f(n) // f(m - n))
```

### Function Parameters

#### Positional and Keyword Arguments

Here is a function that checks whether three side lengths can form a triangle:

```python
def make_judgement(a, b, c):
    """Return whether three sides can form a triangle."""
    return a + b > c and b + c > a and a + c > b
```

These are positional parameters, so arguments are usually passed from left to right:

```python
print(make_judgement(1, 2, 3))  # False
print(make_judgement(4, 5, 6))  # True
```

You can also use keyword arguments:

```python
print(make_judgement(b=2, c=3, a=1))  # False
print(make_judgement(c=6, b=4, a=5))  # True
```

Python also supports positional-only parameters with `/` and keyword-only parameters with `*`.

```python
def make_judgement(a, b, c, /):
    return a + b > c and b + c > a and a + c > b
```

```python
def make_judgement(*, a, b, c):
    return a + b > c and b + c > a and a + c > b
```

#### Default Values

Python allows parameters to have default values.

```python
from random import randrange


def roll_dice(n=2):
    """Roll n dice and return the total."""
    total = 0
    for _ in range(n):
        total += randrange(1, 7)
    return total


print(roll_dice())
print(roll_dice(3))
```

Another example:

```python
def add(a=0, b=0, c=0):
    """Add three numbers."""
    return a + b + c


print(add())         # 0
print(add(1))        # 1
print(add(1, 2))     # 3
print(add(1, 2, 3))  # 6
```

Parameters with default values must come after parameters without defaults.

#### Variable-Length Arguments

Python supports variable-length arguments with star expressions.

```python
def add(*args):
    total = 0
    for val in args:
        if type(val) in (int, float):
            total += val
    return total


print(add())                      # 0
print(add(1))                     # 1
print(add(1, 2, 3))               # 6
print(add(1, 2, 'hello', 3.45, 6))  # 12.45
```

If you want to receive an unknown number of keyword arguments, use `**kwargs`.

```python
def foo(*args, **kwargs):
    print(args)
    print(kwargs)


foo(3, 2.1, True, name='Luo Hao', age=43, gpa=4.95)
```

Output:

```python
(3, 2.1, True)
{'name': 'Luo Hao', 'age': 43, 'gpa': 4.95}
```

### Managing Functions with Modules

In any programming language, naming things can lead to conflicts. The simplest case is defining two functions with the same name in one file:

```python
def foo():
    print('hello, world!')


def foo():
    print('goodbye, world!')


foo()
```

In real projects, naming conflicts often happen across files. In Python, each `.py` file is a **module**. Different modules can contain functions with the same name. We can distinguish them by importing the module and then using the fully qualified name `module_name.function_name`.

`module1.py`

```python
def foo():
    print('hello, world!')
```

`module2.py`

```python
def foo():
    print('goodbye, world!')
```

`test.py`

```python
import module1
import module2

module1.foo()
module2.foo()
```

You can also alias modules:

```python
import module1 as m1
import module2 as m2

m1.foo()
m2.foo()
```

Or import functions directly:

```python
from module1 import foo

foo()

from module2 import foo

foo()
```

But if we directly import two functions with the same name, the later import overwrites the earlier one. To avoid that, we can give the imported functions aliases:

```python
from module1 import foo as f1
from module2 import foo as f2

f1()
f2()
```

### Standard Library Modules and Built-In Functions

Python's standard library contains many useful modules and functions. We have already seen:

- `random` for random numbers and sampling
- `time` for time-related operations
- `math` for mathematical functions such as sine, cosine, exponentials, and logarithms

Python also has many **built-in functions** that require no import. Examples include:

| Function | Description |
| --- | --- |
| `abs` | absolute value |
| `bin` | convert an integer to binary |
| `chr` | convert a Unicode code point to a character |
| `hex` | convert an integer to hexadecimal |
| `input` | read one line of input |
| `len` | get the length of a string, list, etc. |
| `max` | return the maximum value |
| `min` | return the minimum value |
| `oct` | convert an integer to octal |
| `open` | open a file |
| `ord` | convert a character to its Unicode code point |
| `pow` | exponentiation |
| `print` | print output |
| `range` | construct a range sequence |
| `round` | round a number |
| `sum` | sum values in a sequence |
| `type` | return the type of an object |

### Summary

**A function is a package of relatively independent, reusable logic.** Once you learn how to define and use functions, your code becomes cleaner and more maintainable. Python's standard library already provides many useful modules and functions, and when they are not enough, you can define your own functions and organize them with modules.
