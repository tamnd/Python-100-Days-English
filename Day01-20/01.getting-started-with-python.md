## Getting Started with Python

### Python Introduction

Python (UK pronunciation: `/ˈpaɪθən/`; US pronunciation: `/ˈpaɪθɑːn/`) is a programming language invented by Guido van Rossum of the Netherlands. It is currently one of the most popular programming languages in the world and one of the languages with the largest number of users. Python emphasizes code readability and concise syntax. Compared with C, C++, and Java, which are also highly influential programming languages, Python allows its users to express their intentions with less code. Below are Python's rankings in several authoritative programming-language indexes. The first chart is provided by the TIOBE Index, and the third chart is provided by IEEE Spectrum. The second chart is especially worth mentioning, because it shows how popular programming languages are on GitHub, the world's largest code-hosting platform. For the last four years, Python has held the championship position there.

#### Python Chronicle

Below are several important points in the development of Python:

1. December 1989: Guido van Rossum decided to develop a new scripting language and its interpreter to pass a boring Christmas holiday. The new language would inherit from ABC and would mainly be used to replace the Unix shell and the C language for system administration. Because Guido himself was a loyal fan of the BBC television series *Monty Python's Flying Circus*, he chose the word Python as the name of the new language.
2. February 1991: Guido van Rossum published the earliest code for the Python interpreter on the `alt.sources` newsgroup, marked as version `0.9.0`.
3. January 1994: Python `1.0` was released, where the dream began.
4. October 2000: Python `2.0` was released. The entire Python development process became more transparent, and the ecosystem slowly began to take shape.
5. December 2008: Python `3.0` was released. It introduced many new features of modern programming languages, but it was not completely backward-compatible.
6. April 2011: `pip` was released for the first time, and Python had its own package-management tool.
7. July 2018: Guido van Rossum announced that he was taking a "permanent vacation" from the position of "BDFL" ("Benevolent Dictator For Life," the person with final decision-making authority when disputes arise in an open-source project community).
8. January 2020: After Python 2 and Python 3 had coexisted for 11 years, official updates and maintenance for Python 2 stopped, and users were urged to switch to Python 3 as soon as possible.
9. At present: Python has been widely used in large models (GPT-3, GPT-4, BERT, and so on), computer vision (image recognition, object detection, image generation, and so on), intelligent recommendations (YouTube, Netflix, ByteDance, and so on), autonomous driving (Waymo, Apollo, and so on), speech recognition, data science, quantitative trading, automated testing, automated operations, and many other fields. Python's ecosystem is also extremely prosperous.

> **Note**: Most software version numbers are generally divided into three parts, in the form `A.B.C`. Here, `A` represents the major version number. It increases only when the software is completely rewritten and upgraded or when backward-incompatible changes appear. `B` represents feature updates and increases when new features appear. `C` represents small changes, such as fixing a bug. As long as there is a modification, `C` increases.

#### Advantages and Disadvantages of Python

Python has many advantages. Here are a few simple ones.

1. It is **simple and elegant**. Compared with many other programming languages, Python is **easier to get started with**.
2. It can do more things with less code, thereby **improving development efficiency**.
3. It is open source and has a **powerful community and ecosystem**.
4. It **can do a great many things** and has extremely strong adaptability.
5. It is a **glue language**, capable of binding together things developed in other languages.
6. As an interpreted language, it is easier to **run across platforms** and can run on many operating systems.

Python's main disadvantage is **low execution efficiency** (a common problem with interpreted languages). If you care more about code execution efficiency, C, C++, or Go may be a better choice for you.

### Installing the Python Environment

If a worker wants to do a good job, they must first sharpen their tools. To begin your Python programming journey, you must first install the Python environment on your computer. Put simply, this means installing the Python interpreter required to run Python programs. We recommend that everyone install the official Python 3 interpreter. It is written in C, and we usually also call it CPython. It is probably the best choice for you at the moment. First, we need to find the download link on the official [downloads page](https://www.python.org/downloads/). After clicking the "Download" button to enter the download page, choose the appropriate Python 3 installer according to your operating system, as shown below.

After entering the download page, some Python versions do not provide installers for Windows and macOS and only provide compressed source-code archives. For readers who are familiar with Linux, installation can be completed by building from source code. For readers using Windows or macOS, however, we still **strongly recommend** using the installer. For example, if you want to install Python 3.10, by choosing Python `3.10.10` or `3.10.11` you can find installation packages for Windows or macOS, while other versions may provide source code only, as shown below.

#### Windows Environment

Below we use Windows 11 as an example to explain how to install the Python environment on Windows. Double-click the installer downloaded from the official website to open the setup wizard, as shown below.

<img src="res/day01/install_python_1.png" style="zoom:50%;">

First, make sure you remember to check `Add python.exe to PATH`. It will help us add the Python interpreter to the Windows `PATH` environment variable. It is fine if you do not understand it; just check it. Second, `Use admin privileges when installing py.exe` is for obtaining administrator privileges during installation, so it is recommended to check it as well. Then choose `Customize Installation` and use the custom installation mode. This is the choice of professionals, and you are (pretending to be) that professional, so `Install Now` (the default installation) is not recommended.

Next, the setup wizard will prompt you to choose the required `Optional Features`. Here we can simply select all of them. It is worth mentioning the second item among them: it is Python's package-management tool `pip`, which can help us install third-party libraries and third-party tools, so be sure to check it, and then click `Next` to proceed to the next step.

<img src="res/day01/install_python_2.png" style="zoom:50%;">

Next comes the selection of `Advanced Options`. Here we recommend checking only `Add Python to environment variables` and `Precompile standard library`. The former will help us configure environment variables automatically, while the latter precompiles the standard library (generating `.pyc` files), so there is no need to compile it temporarily when it is used later. The same thing again: it is fine if you do not understand it; just check it. Below that, `Customize install location` is **strongly recommended** to be changed to a custom path. This path should not contain Chinese characters, spaces, or other special characters. Paying attention to this point will save you from many unnecessary troubles in the future. After the settings are complete, click `Install` to begin installation.

<img src="res/day01/install_python_3.png" style="zoom:50%;">

If the installation succeeds, the screen shown below will appear. The keyword for success is `successful`; if installation fails, the word here will become `failed`.

<img src="res/day01/install_python_4.png" style="zoom:50%;">

After installation is complete, you can open Windows Command Prompt or PowerShell and enter `python --version` or `python -V` to check whether the installation succeeded. This command shows the version number of the Python interpreter. If you see the screen below, congratulations: the Python environment has been installed successfully. Here we also recommend checking whether Python's package-management tool `pip` is available. The corresponding commands are `pip --version` or `pip -V`.

#### Other Installation Methods

Some people may recommend that beginners install [Anaconda](https://www.anaconda.com/download/success) directly, because Anaconda will help us install the Python interpreter together with some commonly used third-party libraries, and in addition it provides some convenient tools that seem especially suitable for absolute beginners. I personally do not recommend this method, because when you install Anaconda, you will inexplicably install a large pile of third-party libraries, whether useful or not, which take up considerable disk space. Then your terminal or command prompt will be altered by Anaconda, because it automatically activates the virtual environment each time it starts. These behaviors do not conform to the **principle of least astonishment** in software design. Other minor issues with Anaconda will not be repeated here. If you insist on using Anaconda, I recommend installing Miniconda, which is on the same download page.

Absolute beginners also often hear or say, "I want to write Python programs, so can't I just install PyCharm?" Here is a simple explanation: PyCharm is only a tool that assists with writing Python code; it does not itself have the ability to run Python code. Running Python code depends on the Python interpreter we installed above. Of course, some versions of PyCharm will also prompt you to download the Python interpreter over the internet when you create a Python project and it detects that your computer does not have a Python environment. We will put the installation and use of PyCharm in the next lesson.

### Summary

To summarize what we learned:

1. Python is a powerful language that can do many things, so it is worth learning.
2. To use Python, you must first install the Python environment, that is, the Python interpreter required to run Python programs.
