## Getting Started with Python

### Python Introduction

Python (UK pronunciation: `/ˈpaɪθən/`; US pronunciation: `/ˈpaɪθɑːn/`) is a programming language invented by the Dutchman Guido van Rossum. It is one of the most popular programming languages in the world today, and also one of the programming languages with the largest number of users. Python emphasizes readable code and simple syntax. Compared with C, C++, and Java, which are also very influential programming languages, Python lets users use less code to express what they want to do. Below are Python's rankings in several authoritative programming language lists. The first chart is from TIOBE Index, and the third chart is from IEEE Spectrum. The second chart is worth mentioning because it shows how popular programming languages are on GitHub, the largest code hosting platform in the world. In the most recent four years, Python has stayed in first place there.

#### Python Chronicle

Below are several important points in the development of Python:

1. December 1989: Guido van Rossum decided to develop a new scripting language and its interpreter to pass a boring Christmas holiday. The new language would inherit from ABC and would mainly be used to replace the Unix shell and the C language for system administration. Because Guido himself was a loyal fan of the BBC television series *Monty Python's Flying Circus*, he chose the word Python as the name of the new language.
2. February 1991: Guido van Rossum published the earliest code for the Python interpreter on the `alt.sources` newsgroup, marked as version `0.9.0`.
3. January 1994: Python `1.0` was released, where the dream began.
4. October 2000: Python `2.0` was released. The entire Python development process became more transparent, and the ecosystem slowly began to take shape.
5. December 2008: Python `3.0` was released. It introduced many new features of modern programming languages, but it was not completely backward-compatible.
6. April 2011: `pip` was released for the first time, and Python had its own package management tool.
7. July 2018: Guido van Rossum announced that he was taking a "permanent vacation" from the position of "BDFL" ("Benevolent Dictator For Life," the person with final decision-making authority when disputes arise in an open-source project community).
8. January 2020: After Python 2 and Python 3 had coexisted for 11 years, official updates and maintenance for Python 2 stopped, and users were urged to switch to Python 3 as soon as possible.
9. At present: Python has been widely used in large models (GPT-3, GPT-4, BERT, and so on), computer vision (image recognition, object detection, image generation, and so on), intelligent recommendation (YouTube, Netflix, ByteDance, and so on), self-driving cars (Waymo, Apollo, and so on), speech recognition, data science, quantitative trading, automated testing, automated operations, and many other fields. The Python ecosystem is also very prosperous.

> **Note**: Most software version numbers are usually divided into three parts, in the form `A.B.C`. Here, `A` means the major version number. It increases only when the software is rewritten and upgraded as a whole, or when backward-incompatible changes appear. `B` means feature updates, and it increases when new features appear. `C` means small changes, such as fixing a bug. As long as there is a change, `C` increases.

#### Advantages and Disadvantages of Python

Python has many advantages. Here I will simply list a few.

1. It is **simple and elegant**. Compared with many other programming languages, Python is **easier to get started with**.
2. It can do more things with less code, thereby **improving development efficiency**.
3. It is open source and has a **powerful community and ecosystem**.
4. It **can do a great many things** and has extremely strong adaptability.
5. It is a **glue language**, capable of binding together things developed in other languages.
6. As an interpreted language, it is easier to **run across platforms** and can run on many operating systems.

Python's main disadvantage is **low execution efficiency** (a common problem with interpreted languages). If you care more about code execution efficiency, C, C++, or Go may be a better choice for you.

### Installing the Python Environment

If a worker wants to do a good job, they must first sharpen their tools. If you want to start your Python programming journey, you must first install the Python environment on your computer. Simply speaking, this means installing the Python interpreter needed to run Python programs. We recommend that everyone install the official Python 3 interpreter. It is written in C, and we usually also call it CPython. It may be your best choice right now. First, we need to find the download link on the official [downloads page](https://www.python.org/downloads/). After clicking the "Download" button and entering the download page, choose a suitable Python 3 installer according to your operating system, as shown below.

<img src="res/day01/python_download_page_1.png" style="zoom:40%;">

After entering the download page, some Python versions do not provide installers for Windows and macOS. They only provide compressed source code files. For readers who are familiar with Linux, installation can be done by building from source code. But for readers using Windows or macOS, we still **strongly recommend** using the installer. For example, if you want to install Python 3.10, then by choosing Python `3.10.10` or `3.10.11`, you can find installation packages for Windows or macOS. Other versions may only provide source code, as shown below.

#### Windows Environment

Below we use Windows 11 as an example to explain how to install the Python environment on Windows. Double-click the installer downloaded from the official website, and an installation wizard will open, as shown below.

<img src="res/day01/install_python_1.png" style="zoom:50%;">

First, be sure to remember to check `Add python.exe to PATH`. It will help us add the Python interpreter to the `PATH` environment variable in Windows. If you do not understand it, that is fine, just check it. Second, `Use admin privileges when installing py.exe` is used to get administrator privileges during installation, and it is also recommended to check it. Then choose `Customize Installation` and use the custom installation mode. This is the choice of professionals, and you are that professional, or at least pretending to be that professional, so `Install Now` (the default installation) is not recommended.

Next, the setup wizard will prompt you to choose the required `Optional Features`. Here we can simply select all of them. It is worth mentioning the second item among them: it is Python's package-management tool `pip`, which can help us install third-party libraries and third-party tools, so be sure to check it, and then click `Next` to proceed to the next step.

<img src="res/day01/install_python_2.png" style="zoom:50%;">

Next comes the selection of `Advanced Options`. Here we recommend checking only `Add Python to environment variables` and `Precompile standard library`. The former will help us automatically configure the environment variables, and the latter will precompile the standard library (generate `.pyc` files), so there is no need to compile it temporarily when using it later. The same sentence again: if you do not understand it, that is fine, just check it. For `Customize install location` below, it is **strongly recommended** to change it to a custom path. This path should not contain Chinese characters, spaces, or other special characters. Paying attention to this point will save you a lot of unnecessary trouble in the future. After the settings are finished, click `Install` to start the installation.

<img src="res/day01/install_python_3.png" style="zoom:50%;">

If the installation succeeds, the screen shown below will appear. The key word for success is `successful`. If the installation fails, the word here will become `failed`.

<img src="res/day01/install_python_4.png" style="zoom:50%;">

After installation is complete, you can open Windows Command Prompt or PowerShell, then enter `python --version` or `python -V` to check whether the installation succeeded. This command shows the version number of the Python interpreter. If you see the screen below, then congratulations, the Python environment has been installed successfully. Here we also recommend checking whether Python's package management tool `pip` is available. The corresponding commands are `pip --version` or `pip -V`.

<img src="res/day01/install_python_5.png" style="zoom:50%;">

#### Other Installation Methods

Some people may recommend that beginners install [Anaconda](https://www.anaconda.com/download/success) directly, because Anaconda will help us install the Python interpreter and some commonly used third-party libraries. Besides that, it also provides some convenient tools and seems especially suitable for complete beginners. I personally do not recommend this way, because when you install Anaconda, you will install a large pile of third-party libraries for no clear reason, whether they are useful or not, and they take up quite a lot of disk space. Then your terminal or command prompt will be changed by Anaconda, because it automatically activates the virtual environment every time it starts. These behaviors do not match the **principle of least astonishment** in software design. I will not repeat Anaconda's other small problems here. If you really want to use Anaconda, I recommend installing Miniconda, which is on the same download page.

Complete beginners also often hear or say, "I want to write Python programs, so can't I just install PyCharm?" Let me explain this simply. PyCharm is only a tool that helps us write Python code. It does not itself have the ability to run Python code. Running Python code depends on the Python interpreter we installed above. Of course, some versions of PyCharm will also prompt you to download the Python interpreter from the internet when you create a Python project and it cannot detect a Python environment on your computer. We will put the installation and use of PyCharm in the next lesson.

### Summary

Let us summarize what we learned:

1. Python is a powerful language that can do many things, so it is worth learning.
2. To use Python, you must first install the Python environment, that is, the Python interpreter required to run Python programs.
3. On Windows, you can enter `python --version` in Command Prompt or PowerShell to check whether the Python environment has been installed successfully. On macOS, you can enter `python3 --version` in Terminal to check it.
