## Common Data Structures: Strings

World War II accelerated the development of modern electronic computers. The first general-purpose electronic computer, ENIAC, was built at the University of Pennsylvania in the United States. It occupied about 167 square meters, weighed around 27 tons, and could perform roughly 5000 floating-point operations per second.

<img src="res/day11/eniac.jpg" style="zoom:50%;">

Over time, numerical computation has remained important, but modern computers also process huge amounts of textual information. If we want to manipulate text in Python, we need to understand the string type and the operations available for it.

### Defining Strings

A **string** is a finite sequence of zero or more characters:

$$
s = a_1a_2 \cdots a_n \,\,\,\,\, (0 \le n \le \infty)
$$

In Python, a string is written by surrounding one or more characters with single quotes or double quotes. Characters may include punctuation, English letters, Chinese characters, Japanese kana, Greek letters, or even emoji.

```python
s1 = 'hello, world!'
s2 = "Hello, world! ❤️"
s3 = '''hello,
wonderful
world!'''
print(s1)
print(s2)
print(s3)
```

#### Escape Characters

In strings, the backslash `\` introduces escape sequences. For example, `\n` means a newline and `\t` means a tab. If the string itself contains special characters like `'`, `"`, or `\`, they must be escaped.

```python
s1 = '\'hello, world!\''
s2 = '\\hello, world!\\'
print(s1)
print(s2)
```

#### Raw Strings

Python also supports raw strings, which start with `r` or `R`. In a raw string, characters keep their literal meaning, so `\n` is not treated as a newline.

```python
s1 = '\it \is \time \to \read \now'
s2 = r'\it \is \time \to \read \now'
print(s1)
print(s2)
```

> **Note**: In `s1`, sequences such as `\t`, `\r`, and `\n` are interpreted as escape characters. Compare the two outputs carefully.

#### Special Character Notation

Python also lets you represent characters using octal, hexadecimal, or Unicode escape sequences.

```python
s1 = '\141\142\143\x61\x62\x63'
s2 = '\u9a86\u660a'
print(s1)
print(s2)
```

### String Operations

Python provides many operators for strings. Several of them work much like the operators we saw for lists.

#### Concatenation and Repetition

```python
s1 = 'hello' + ', ' + 'world'
print(s1)    # hello, world
s2 = '!' * 3
print(s2)    # !!!
s1 += s2
print(s1)    # hello, world!!!
s1 *= 2
print(s1)    # hello, world!!!hello, world!!!
```

The repetition operator `*` is especially convenient. Instead of typing `'aaaaaaaaaa'`, you can simply write `'a' * 10`.

#### Comparison

Strings can be compared directly with comparison operators. The comparison is based on the character codes of each character.

```python
s1 = 'a whole new world'
s2 = 'hello world'
print(s1 == s2)             # False
print(s1 < s2)              # True
print(s1 == 'hello world')  # False
print(s2 == 'hello world')  # True
print(s2 != 'Hello world')  # True
s3 = 'Luo Hao'
s4 = 'Wang Dachui'
print(s3 >= s4)
print(s3 != s4)
```

If you want to inspect a character code, use `ord`.

#### Membership

Use `in` and `not in` to test whether one string contains another.

```python
s1 = 'hello, world'
s2 = 'goodbye, world'
print('wo' in s1)      # True
print('wo' not in s2)  # False
print(s2 in s1)        # False
```

#### Length

Use `len` to get the number of characters in a string.

```python
s = 'hello, world'
print(len(s))                 # 12
print(len('goodbye, world'))  # 14
```

#### Indexing and Slicing

Strings support indexing and slicing just like lists and tuples. However, **strings are immutable**, so you cannot modify them through indexing.

```python
s = 'abc123456'
n = len(s)
print(s[0], s[-n])    # a a
print(s[n-1], s[-1])  # 6 6
print(s[2], s[-7])    # c c
print(s[5], s[-4])    # 3 3
print(s[2:5])         # c12
print(s[-7:-4])       # c12
print(s[2:])          # c123456
print(s[:2])          # ab
print(s[::2])         # ac246
print(s[::-1])        # 654321cba
```

If an index goes out of range, Python raises `IndexError`.

### Iterating Over Characters

You can iterate over a string with `for-in` in two common ways.

Method 1:

```python
s = 'hello'
for i in range(len(s)):
    print(s[i])
```

Method 2:

```python
s = 'hello'
for elem in s:
    print(elem)
```

### String Methods

Strings come with many built-in methods.

#### Case Conversion

```python
s1 = 'hello, world!'
print(s1.capitalize())  # Hello, world!
print(s1.title())       # Hello, World!
print(s1.upper())       # HELLO, WORLD!
s2 = 'GOODBYE'
print(s2.lower())       # goodbye
print(s1)
print(s2)
```

> **Note**: Because strings are immutable, these methods return new strings rather than modifying the original one.

#### Searching

Use `find` or `index` to search from left to right. `find` returns `-1` if the substring is not found, while `index` raises `ValueError`.

```python
s = 'hello, world!'
print(s.find('or'))      # 8
print(s.find('or', 9))   # -1
print(s.find('of'))      # -1
print(s.index('or'))     # 8
```

There are also reverse-search versions: `rfind` and `rindex`.

```python
s = 'hello world!'
print(s.find('o'))       # 4
print(s.rfind('o'))      # 7
print(s.rindex('o'))     # 7
```

#### Property Checks

Use `startswith`, `endswith`, and various `is...` methods to check string properties.

```python
s1 = 'hello, world!'
print(s1.startswith('He'))   # False
print(s1.startswith('hel'))  # True
print(s1.endswith('!'))      # True
s2 = 'abc123456'
print(s2.isdigit())  # False
print(s2.isalpha())  # False
print(s2.isalnum())  # True
```

#### Alignment and Padding

```python
s = 'hello, world'
print(s.center(20, '*'))  # ****hello, world****
print(s.rjust(20))        #         hello, world
print(s.ljust(20, '~'))   # hello, world~~~~~~~~
print('33'.zfill(5))      # 00033
print('-33'.zfill(5))     # -0033
```

#### Formatting

We have already seen `%` formatting:

```python
a = 321
b = 123
print('%d * %d = %d' % (a, b, a * b))
```

You can also use `format`:

```python
a = 321
b = 123
print('{0} * {1} = {2}'.format(a, b, a * b))
```

Since Python 3.6, f-strings are usually the cleanest option:

```python
a = 321
b = 123
print(f'{a} * {b} = {a * b}')
```

Common formatting patterns:

| Value | Placeholder | Result | Meaning |
| --- | --- | --- | --- |
| `3.1415926` | `{:.2f}` | `'3.14'` | 2 decimal places |
| `3.1415926` | `{:+.2f}` | `'+3.14'` | signed, 2 decimal places |
| `-1` | `{:+.2f}` | `'-1.00'` | signed, 2 decimal places |
| `3.1415926` | `{:.0f}` | `'3'` | no decimals |
| `123` | `{:0>10d}` | `'0000000123'` | left-pad with `0` |
| `123` | `{:x<10d}` | `'123xxxxxxx'` | right-pad with `x` |
| `123` | `{:>10d}` | `'       123'` | right-aligned |
| `123` | `{:<10d}` | `'123       '` | left-aligned |
| `123456789` | `{:,}` | `'123,456,789'` | thousands separators |
| `0.123` | `{:.2%}` | `'12.30%'` | percentage |
| `123456789` | `{:.2e}` | `'1.23e+08'` | scientific notation |

#### Trimming

`strip` removes characters from both ends of a string. By default, it removes whitespace. `lstrip` and `rstrip` remove from only one side.

```python
s1 = '   jackfrued@126.com  '
print(s1.strip())      # jackfrued@126.com
s2 = '~Hello, world~'
print(s2.lstrip('~'))  # Hello, world~
print(s2.rstrip('~'))  # ~Hello, world
```

#### Replacing

Use `replace` to replace one substring with another.

```python
s = 'hello, good world'
print(s.replace('o', '@'))     # hell@, g@@d w@rld
print(s.replace('o', '@', 1))  # hell@, good world
```

#### Splitting and Joining

Use `split` to break a string into pieces and `join` to combine strings.

```python
s = 'I love you'
words = s.split()
print(words)            # ['I', 'love', 'you']
print('~'.join(words))  # I~love~you
```

You can specify the separator and the maximum number of splits:

```python
s = 'I#love#you#so#much'
words = s.split('#')
print(words)
words = s.split('#', 2)
print(words)
```

#### Encoding and Decoding

Besides the `str` type, Python also has a `bytes` type for binary data. You can convert strings to bytes with `encode`, and bytes back to strings with `decode`.

```python
a = 'Luo Hao'
b = a.encode('utf-8')
c = a.encode('gbk')
print(b)
print(c)
print(b.decode('utf-8'))
print(c.decode('gbk'))
```

If you use inconsistent encodings, the text may become garbled or raise `UnicodeDecodeError`.

### Summary

Knowing how to represent and manipulate strings is essential because programs often need to process text. In Python, you can work with strings through operators such as concatenation, indexing, and slicing, as well as many built-in methods.
