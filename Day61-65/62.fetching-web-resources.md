## Fetching Network Resources with Python

Python is especially strong for collecting data from the web. Whether the data comes from paid APIs, public APIs, or direct crawling, Python’s standard library and ecosystem make the job convenient.

### The `requests` Library

The recommended library for basic HTTP work is `requests`. It wraps Python’s lower-level networking capabilities and makes HTTP and HTTPS much easier to use.

A simple example:

```python
import requests

resp = requests.get('https://www.sohu.com/')
if resp.status_code == 200:
    print(resp.text)
```

`resp` is a `Response` object:

- `status_code` gives the HTTP status code
- `text` gives the decoded response body as text

### Extracting Data with Regular Expressions

If the response is HTML text, you can parse it using regular expressions, though that approach becomes fragile on complex pages.

Example:

```python
import re
import requests

pattern = re.compile(r'<a.*?href="(.*?)".*?title="(.*?)".*?>')
resp = requests.get('https://www.sohu.com/')
if resp.status_code == 200:
    all_matches = pattern.findall(resp.text)
    for href, title in all_matches:
        print(href)
        print(title)
```

### Downloading Binary Resources

You can also fetch binary data such as images:

```python
import requests

resp = requests.get('https://www.baidu.com/img/PCtm_d9c8750bed0b3c7d089fa7d55720d6cf.png')
with open('baidu.png', 'wb') as file:
    file.write(resp.content)
```

`resp.content` returns raw bytes.

### Example: Crawling Douban Top 250

The original lesson uses Douban Movie Top 250 as an example. Each page contains 25 movies, so 10 pages are needed to retrieve all 250 records.

Example:

```python
import random
import re
import time

import requests

for page in range(1, 11):
    resp = requests.get(
        url=f'https://movie.douban.com/top250?start={(page - 1) * 25}',
        headers={'User-Agent': 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_14_6) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/92.0.4515.159 Safari/537.36'}
    )
    pattern1 = re.compile(r'<span class="title">([^&]*?)</span>')
    titles = pattern1.findall(resp.text)
    pattern2 = re.compile(r'<span class="rating_num".*?>(.*?)</span>')
    ranks = pattern2.findall(resp.text)
    for title, rank in zip(titles, ranks):
        print(title, rank)
    time.sleep(random.random() * 4 + 1)
```

Important practical points:

- many sites reject requests without a browser-like `User-Agent`
- adding a random delay helps avoid overly aggressive crawling

### Proxies

A crawler often needs to hide or rotate its origin IP address. Commercial proxy services can help with that.

Example using a tunnel proxy:

```python
import requests

APP_KEY = 'your-app-key'
PROXY_HOST = 'secondtransfer.moguproxy.com:9001'

resp = requests.get(
    url='https://movie.douban.com/top250?start=0',
    headers={
        'Proxy-Authorization': f'Basic {APP_KEY}',
        'User-Agent': 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_14_6) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/92.0.4515.159 Safari/537.36',
    },
    proxies={
        'http': f'http://{PROXY_HOST}',
        'https': f'https://{PROXY_HOST}'
    },
    verify=False
)
```

### Summary

Python is one of the strongest languages for network data collection. Regular expressions can work, but writing reliable patterns is difficult. The next lesson introduces more structured HTML parsing approaches.
