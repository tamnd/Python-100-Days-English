## Using Selenium to Capture Dynamic Web Content

Many websites render part or all of their content dynamically with JavaScript. In those cases, "View Source" does not show the final content users actually see in the browser. There are two common solutions:

1. find the underlying data API directly
2. drive a real browser with Selenium and read the rendered page

This lesson focuses on Selenium. The other way is to find the data API directly with browser developer tools or packet-capture tools such as Charles, Fiddler, or Wireshark.

### What Selenium Is

Selenium is a browser automation tool. It can drive Chrome, Firefox, Safari, and other browsers, making it useful for:

- testing
- browser automation
- collecting dynamically rendered page content

For Chrome, you need both:

- Chrome itself
- the matching ChromeDriver

### Basic Usage

Install Selenium:

```bash
pip install selenium
```

Open a page:

```python
from selenium import webdriver

browser = webdriver.Chrome()
browser.get('https://www.baidu.com/')
```

If ChromeDriver is not in `PATH`, either:

1. put it in a directory already on `PATH`
2. put it in the virtual environment’s `bin` or `Scripts` directory
3. pass the executable path explicitly

Example:

```python
from selenium import webdriver
from selenium.webdriver.chrome.service import Service

browser = webdriver.Chrome(service=Service(executable_path='venv/bin/chromedriver'))
browser.get('https://www.baidu.com/')
```

### Finding Elements and Simulating User Actions

Example:

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

browser = webdriver.Chrome()
browser.get('https://www.baidu.com/')
kw_input = browser.find_element(By.ID, 'kw')
kw_input.send_keys('Python')
su_button = browser.find_element(By.CSS_SELECTOR, '#su')
su_button.click()
```

You can use many selector strategies:

- ID
- CSS selector
- XPath
- tag name
- class name

### Waiting

Dynamic pages may not finish rendering immediately, so Selenium provides:

- implicit waits
- explicit waits

Example:

```python
from selenium.webdriver.support import expected_conditions
from selenium.webdriver.support.wait import WebDriverWait

browser.implicitly_wait(10)
wait_obj = WebDriverWait(browser, 10)
wait_obj.until(
    expected_conditions.presence_of_element_located(
        (By.CSS_SELECTOR, '#content_left')
    )
)
```

### Executing JavaScript

You can run JavaScript directly:

```python
browser.execute_script('document.documentElement.scrollTop = document.documentElement.scrollHeight')
```

This is useful for pages with infinite scrolling or other dynamic interactions.

### Anti-Selenium Detection

Some sites detect Selenium through `navigator.webdriver`.

Typical workaround:

```python
options = webdriver.ChromeOptions()
options.add_experimental_option('excludeSwitches', ['enable-automation'])
options.add_experimental_option('useAutomationExtension', False)
browser = webdriver.Chrome(options=options)
browser.execute_cdp_cmd(
    'Page.addScriptToEvaluateOnNewDocument',
    {'source': 'Object.defineProperty(navigator, "webdriver", {get: () => undefined})'}
)
```

### Headless Browsers

If you do not need to see the browser window:

```python
options = webdriver.ChromeOptions()
options.add_argument('--headless')
browser = webdriver.Chrome(options=options)
```
