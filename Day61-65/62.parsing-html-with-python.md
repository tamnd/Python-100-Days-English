## Parsing HTML with Python

In the previous lesson, HTML pages were fetched with `requests`. The next step is to extract useful information from the HTML. While regular expressions sometimes work, they quickly become difficult to maintain. More structured parsing methods are often better.

### HTML Structure

A typical HTML page looks like this:

```html
<!doctype html>
<html>
    <head>
        <!-- metadata such as encoding, title, keywords, media queries -->
    </head>
    <body>
        <!-- page content visible in the browser -->
    </body>
</html>
```

The three core building blocks of web pages are:

- HTML tags
- CSS
- JavaScript

To parse HTML, two common approaches are:

- XPath
- CSS selectors

### XPath Parsing

XPath is a query language for XML documents, but it also works well for HTML trees.

Example XML:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<bookstore>
    <book>
      <title lang="eng">Harry Potter</title>
      <price>29.99</price>
    </book>
    <book>
      <title lang="zh">Learning XML</title>
      <price>39.95</price>
    </book>
</bookstore>
```

Typical XPath expressions:

- `/bookstore`
- `//book`
- `//@lang`
- `/bookstore/book[1]`
- `/bookstore/book[last()]`
- `//title[@lang='eng']`

To use XPath in Python, install `lxml`:

```bash
pip install lxml
```

Example parsing Douban Top 250:

```python
from lxml import etree
import requests

for page in range(1, 11):
    resp = requests.get(
        url=f'https://movie.douban.com/top250?start={(page - 1) * 25}',
        headers={'User-Agent': 'BaiduSpider'}
    )
    tree = etree.HTML(resp.text)
    title_spans = tree.xpath('//*[@id="content"]/div/div[1]/ol/li/div/div[2]/div[1]/a/span[1]')
    rank_spans = tree.xpath('//*[@id="content"]/div/div[1]/ol/li/div/div[2]/div[2]/div/span[2]')
    for title_span, rank_span in zip(title_spans, rank_spans):
        print(title_span.text, rank_span.text)
```

### CSS Selector Parsing

If you are already comfortable with CSS selectors, this approach can be simpler.

Popular Python libraries:

- `beautifulsoup4`
- `pyquery`

Install Beautiful Soup:

```bash
pip install beautifulsoup4
```

Example:

```python
import bs4
import requests

for page in range(1, 11):
    resp = requests.get(
        url=f'https://movie.douban.com/top250?start={(page - 1) * 25}',
        headers={'User-Agent': 'BaiduSpider'}
    )
    soup = bs4.BeautifulSoup(resp.text, 'lxml')
    title_spans = soup.select('div.info > div.hd > a > span:nth-child(1)')
    rank_spans = soup.select('div.info > div.bd > div > span.rating_num')
    for title_span, rank_span in zip(title_spans, rank_spans):
        print(title_span.text, rank_span.text)
```

### Comparison

| Method | Module | Speed | Difficulty |
| --- | --- | --- | --- |
| Regular expressions | `re` | Fast | Hard |
| XPath | `lxml` | Fast | Medium |
| CSS selectors | `bs4` / `pyquery` | Varies | Easy |

Each approach is useful. In practice, XPath and CSS selectors are usually much easier to maintain than large regular expressions.
