## Introduction to the Scrapy Framework

After writing many crawlers by hand, it becomes obvious that a lot of the work is repetitive:

- downloading pages
- parsing pages
- scheduling requests
- handling exceptions
- dealing with anti-crawling measures

This is exactly why crawler frameworks exist. Scrapy is one of the most popular and powerful crawler frameworks in Python.

### Scrapy Overview

Scrapy is a Python framework for crawling websites and extracting structured data.

Its core components are:

1. Engine: controls the overall data flow.
2. Scheduler: queues and prioritizes requests.
3. Downloader: fetches web pages.
4. Spiders: user-defined classes that parse responses and define crawling rules.
5. Item Pipeline: cleans, validates, deduplicates, and stores extracted data.
6. Middlewares: hooks between the engine and other components that extend behavior.

### Data Flow

A typical Scrapy workflow looks like this:

1. The engine asks the spider for the initial URLs.
2. The scheduler queues those requests.
3. The engine pulls a request from the scheduler.
4. The downloader fetches it.
5. The response goes back through the engine to the spider.
6. The spider extracts items and new requests.
7. Items go to pipelines.
8. New requests go back to the scheduler.

This repeats until there are no more requests.

### Installing and Starting a Project

Install Scrapy:

```bash
pip install scrapy
```

Create a project:

```bash
scrapy startproject demo
```

Create a spider:

```bash
scrapy genspider douban movie.douban.com
```

### A Simple Example

The sample project crawls Douban Top 250 movie titles, scores, and quotes.

Define items in `items.py`:

```python
import scrapy


class DoubanItem(scrapy.Item):
    title = scrapy.Field()
    score = scrapy.Field()
    motto = scrapy.Field()
```

Spider example:

```python
import scrapy
from scrapy import Selector, Request
from scrapy.http import HtmlResponse

from demo.items import MovieItem


class DoubanSpider(scrapy.Spider):
    name = 'douban'
    allowed_domains = ['movie.douban.com']
    start_urls = ['https://movie.douban.com/top250?start=0&filter=']

    def parse(self, response: HtmlResponse):
        sel = Selector(response)
        movie_items = sel.css('#content > div > div.article > ol > li')
        for movie_sel in movie_items:
            item = MovieItem()
            item['title'] = movie_sel.css('.title::text').extract_first()
            item['score'] = movie_sel.css('.rating_num::text').extract_first()
            item['motto'] = movie_sel.css('.inq::text').extract_first()
            yield item
```

If you need follow-up requests, yield `Request` objects as well.

Run the spider:

```bash
scrapy crawl movie
```

Export to JSON:

```bash
scrapy crawl movie -o result.json
```

### Pipelines

Pipelines can persist scraped data. The original lesson shows an Excel pipeline using `openpyxl`.

Typical pipeline responsibilities:

- clean HTML data
- validate required fields
- remove duplicates
- store the results

### Settings

The lesson ends by adjusting settings such as:

- `USER_AGENT`
- `CONCURRENT_REQUESTS`
- `DOWNLOAD_DELAY`
- randomized download delay
- robots-policy behavior

These settings help make a crawler more polite, more stable, and easier to tune.
