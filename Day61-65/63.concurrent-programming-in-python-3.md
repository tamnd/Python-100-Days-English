## Concurrent Programming in Python, Part 3

Crawlers are classic I/O-bound workloads. When a program waits for network responses, CPU time is wasted unless another task can run. Threads help, but asynchronous I/O is often an even better fit. The lesson treats this as a kind of cooperative concurrency.

### Key Concepts

#### Blocking

A program is blocked when it cannot continue because it is waiting for something:

- network I/O
- disk I/O
- user input
- sleep
- thread joins

#### Non-blocking

A program is non-blocking when it can continue doing other useful work while waiting for an operation to complete.

#### Synchronous

Synchronous execution relies on communication or coordination between program units. It tends to produce ordered behavior.

#### Asynchronous

Asynchronous execution means different program units do not need to coordinate with each other while running, and completion order is not guaranteed.

### Generators and Coroutines

A generator uses `yield`:

```python
def fib(max_count):
    a, b = 0, 1
    for _ in range(max_count):
        a, b = b, a + b
        yield a
```

A pre-activated generator can be used like a coroutine:

```python
def calc_average():
    total, counter = 0, 0
    avg_value = None
    while True:
        curr_value = yield avg_value
        total += curr_value
        counter += 1
        avg_value = total / counter
```

### `async` and `await`

Modern Python simplifies coroutine code with `async` and `await`.

Synchronous version:

```python
import time


def display(num):
    time.sleep(1)
    print(num)
```

Asynchronous version:

```python
import asyncio
import time


async def display(num):
    await asyncio.sleep(1)
    print(num)
```

When a coroutine hits `await`, it can give up control so the event loop can run other coroutines. This is why asynchronous I/O works so well for I/O-bound tasks.

### `aiohttp`

The `requests` library does not support asynchronous I/O. For async HTTP requests, `aiohttp` is a common choice.

Install it:

```bash
pip install aiohttp
```

Example:

```python
import asyncio
import re

import aiohttp

TITLE_PATTERN = re.compile(r'<title.*?>(.*?)</title>', re.DOTALL)


async def fetch_page_title(url):
    async with aiohttp.ClientSession(headers={
        'User-Agent': 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_14_6) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/95.0.4638.69 Safari/537.36',
    }) as session:
        async with session.get(url, ssl=False) as resp:
            if resp.status == 200:
                html_code = await resp.text()
                matcher = TITLE_PATTERN.search(html_code)
                title = matcher.group(1).strip()
                print(title)
```

This pattern lets many requests stay in flight concurrently without creating many threads. The output order of the page titles is unrelated to the URL order in the list, which is exactly what the lesson wants the reader to notice.
